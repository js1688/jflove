## ⚠ 两个已踩过的坑（写文档前必读）

1. **不要读 `jflove-desktop/ui/src/config/placeholders.ts` 当菜单真相**。
   那是"交付节点占位表"，**不是**侧栏实际渲染的项。桌面端真实侧栏在
   `jflove-desktop/ui/src/layouts/DesktopLayout.tsx:30-49` 的 `NAV_ITEMS`。
   两者不一致：`placeholders.ts` 缺「文本编辑器」「远程连接」两项。

2. **Web 端没有「云盘挂载」**。`jflove-web/src/config/routes.tsx:68` 明确注释
   v1.7.0 起 `/sync` 路由已移除（浏览器端不提供同步能力）。官网必须写明这个差异。
