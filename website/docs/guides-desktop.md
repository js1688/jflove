# 桌面端操作指引


桌面端侧栏共 **7 项主导航 + 2 项底部固定项**，管理员额外多出 **4 项管理面板**。

## 1. 侧栏结构

**主导航（从上到下）**：文件管理 → 笔记管理 → 文本编辑器 → 云盘挂载 → 传输任务 → 离线下载 → 远程连接
**底部固定**：安全状态、设置
**管理面板（仅管理员可见）**：用户管理、磁盘管理、权限配置、系统设置

## 2. 文件管理

**在哪**：侧栏第 1 项「文件管理」

1. 首屏是**磁盘卡片列表**，每张卡显示磁盘名与路径。
2. 点任意磁盘 → 进入目录浏览。
3. 顶部两个按钮：**「上传」**、**「新建目录」**。
4. 目录内可直接**把文件拖进来**，拖拽时页面提示 **「松开以上传到当前目录」**。
5. 每个文件/目录行尾有三个点的操作菜单，包含：
   **「下载」「预览」「修复损坏媒体」「重命名」「移动到…」「删除」**。
   - 「修复损坏媒体」只在媒体文件上出现。
6. 删除会弹确认框：标题 **「确认删除」**，正文 **「确定要删除「XXX」吗？此操作不可撤销。」**
7. 目录为空时显示 **「此目录为空」** / **「可上传文件或新建目录」**。

## 3. 笔记管理

**在哪**：侧栏第 2 项「笔记管理」

1. 首屏是笔记列表。行尾操作为 **「重命名」**、**「删除」**。
2. 新建入口弹出 **「新建笔记」** 弹窗。
3. 点进某条笔记 → 进入 Markdown 编辑器，副标题为 **「笔记管理 / Markdown」**。
4. 编辑器工具栏有 **「插入 Mermaid 图表」** 按钮，可在笔记里画流程图。
5. 有未保存内容时离开，会提示 **「未保存的修改」**。

## 4. 文本编辑器（桌面端专属）

**在哪**：侧栏第 3 项「文本编辑器」

- 这是**纯本地**的多标签编辑器，不依赖服务端，用于临时编辑本地文件。
- 侧栏入口带准入判据：**未登录或会话过期时该入口不显示**。
- 能力：12 项工具箱、29 项快捷键、跨标签查找替换。

## 5. 云盘挂载（桌面端专属）

**在哪**：侧栏第 4 项「云盘挂载」

1. 首屏左栏是挂载点列表，右栏是文件区。
2. 还没挂载点时显示 **「还没有挂载点」**；未选中时右侧提示 **「请选择左侧的挂载点」**。
3. 新建/编辑挂载点需要填四个字段：**「名称」「远端磁盘」「远端子目录」「本地缓存目录」**。
4. 挂载点行上有三个操作：**「启用挂载点」「编辑挂载点」「删除挂载点」**。
5. 删除时弹 **「确认删除」**。
6. 挂载后文件区空目录显示 **「还没有文件」**，顶部会显示 **「在线 N」** 之类的状态统计。
7. 特性：目录级挂载、按需缓存、增量同步，**永不自动删远端**。

## 6. 传输任务

**在哪**：侧栏第 5 项「传输任务」

页面顶部有两个页签：**「传输」** 与 **「修复」**。

| 页签 | 页面标题 | 副标题 |
| --- | --- | --- |
| 传输 | 传输任务 | 上传与下载进度 |
| 修复 | 修复中心 | 共享修复任务与产物管理 |

- 上传/下载的实时进度在「传输」页签看。
- 媒体修复任务在「修复」页签看，**三端共享同一份任务列表**。

## 7. 离线下载

**在哪**：侧栏第 6 项「离线下载」

1. 贴入一个无需登录的网页地址。
2. 系统分析出视频 / 音频 / 图片清单。
3. 勾选要下载的项 → 开始下载。
4. 产物直接进入**该账号自己的磁盘目录**，可以在文件管理里看到。
5. 音视频分离的站点会自动合并音轨。

## 8. 远程连接（桌面端专属）

**在哪**：侧栏第 7 项「远程连接」

页面有三个页签：**「会话」「本地」「远程」**。

| 页签 | 用途 |
| --- | --- |
| 会话 | 正在进行的 SSH 会话 |
| 本地 | 本机终端（配置存本地） |
| 远程 | 保存的远程连接配置 |

- 还没有连接时显示 **「还没有远程连接」** / **「点击右上角新建」**。
- 本机配置为空时显示 **「还没有本机配置」**。
- 连接类型有两种：**「远程终端（SSH）」** 与 **「仅 SFTP」**。
- 连接行上的图标按钮：**「打开」「编辑」「复制」「删除」**。
- 结束会话时弹 **「关闭会话」** 确认。
- 支持认证方式：跳板、密码、密钥、密码+密钥、OTP（网关键盘交互第二因子）。

## 9. 安全状态

**在哪**：侧栏底部「安全状态」

- 显示当前会话的加密状态。
- 关键字段：**「会话状态」「Session ID」「密钥交换时间」「当前用户」**。
- **「加密算法」** 显示 **`X25519 ECDH + HKDF-SHA256`**。
- **「前向保密」** 显示 **`已启用（临时密钥、私钥用完即销毁）`**。

## 10. 设置（桌面端 8 个分区）

**在哪**：侧栏底部「设置」

分区顺序（从上到下）：

1. **服务端**
2. **笔记目录**
3. **终端**
4. **账号**
5. **管理面板**（仅管理员）
6. **外观**
7. **文本编辑器**
8. **关于**

页底有 **「退出登录」**。

> 桌面端比其他两端多 **「终端」** 与 **「文本编辑器」** 两个分区。

## 11. 管理面板（仅管理员）

侧栏在「设置」上方会多出 4 项：

| 菜单 | 用途 |
| --- | --- |
| 用户管理 | 创建 / 删除普通用户、改密码、启用禁用 |
| 磁盘管理 | 新增 / 编辑 / 删除虚拟磁盘 |
| 权限配置 | 给用户分配磁盘的读 / 写 / 删权限 |
| 系统设置 | 全局配置项 |
