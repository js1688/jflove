# 移动端操作指引


移动端是**底部导航 6 项**，没有侧栏。

## 1. 底部导航结构（从左到右）

| # | 菜单名 |
| --- | --- |
| 1 | 文件 |
| 2 | 笔记 |
| 3 | 传输任务 |
| 4 | 离线下载 |
| 5 | 相册同步 |
| 6 | 设置 |

> **叫法注意**：第 1、2 项叫 **「文件」**、**「笔记」**（桌面/Web 叫「文件管理」「笔记管理」）。
> 移动端**没有**云盘挂载、没有文本编辑器、没有远程连接。

## 2. 文件

**在哪**：底部第 1 项「文件」

- 与桌面/Web 逻辑一致：先选磁盘 → 再浏览目录。
- 支持上传、下载、预览、重命名、移动、删除。
- 同样走端到端加密通道。

## 3. 笔记

**在哪**：底部第 2 项「笔记」

- Markdown 笔记的查看与编辑。
- 支持 Mermaid 图表。

## 4. 传输任务

**在哪**：底部第 3 项「传输任务」

- 查看上传 / 下载进度。
- 媒体修复任务也在这里（三端共享）。

## 5. 离线下载

**在哪**：底部第 4 项「离线下载」

- 与桌面/Web 同一套逻辑：贴网址 → 分析 → 勾选下载。
- 产物进入你自己的磁盘目录。

## 6. 相册同步（移动端专属）

**在哪**：底部第 5 项「相册同步」

页面标题 **「相册同步」**。

**主开关**：**「自动同步相册」**
副标题：**「默认关闭；关闭后不再产生新的上传任务」**

**目标目录**：**「远端目标目录」**，点 **「选择」** 弹出 **「选择远端目标目录」**。

**两个条件开关**：

| 开关 | 作用 |
| --- | --- |
| 仅 Wi-Fi | 只在 Wi-Fi 下上传 |
| 仅充电时 | 只在充电时上传 |

**运行中**：可以点 **「停止」** 中断本次同步。

**查看结果**：

- **「在文件中查看已上传」** —— 跳到文件页看已备份的照片
- **「去传输任务查看上传明细」** —— 看每个文件的上传情况

**失败处理**：会显示 **「失败原因（N 项）」**，没有失败时显示 **「暂无失败记录」**。

**后台运行**：第一次会弹 **「后台运行设置」** 提示，点 **「知道了」** 关闭。

> 同步逻辑是「**先核对再上传**」：同名文件跳过；远端被删的照片会自动补传。
> 上传前会做完整性校验，带进度、可取消。

## 7. 设置（移动端 5 个分区）

**在哪**：底部第 6 项「设置」

页面标题 **「设置」**，分区顺序：

1. **服务器** —— 里面有 **「修改服务器地址」**
2. **安全状态** —— 里面有 **「会话状态」「Session ID」「密钥交换」**，以及 **「刷新会话密钥」** 按钮
3. **账号** —— 显示 **「用户名」**、**「角色」**、**「Token 过期」**
4. **管理面板**（仅管理员）
5. **关于** —— 显示版本号

> **三端差异**：桌面/Web 把「安全状态」做成**独立菜单**，
> 移动端把它**放进了设置页**。桌面/Web 叫「服务端」，移动端叫「服务器」。

## 8. 管理面板（仅管理员）

设置页里多出「管理面板」分区，共 4 项：

| 菜单 |
| --- |
| 用户管理 |
| 磁盘管理 |
| 权限配置 |
| 系统设置 |
