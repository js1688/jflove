# Web 端操作指引


Web 端侧栏只有 **4 项主导航 + 2 项底部固定项**，比桌面端少三项。

## 1. 侧栏结构

**主导航（从上到下）**：文件管理 → 笔记管理 → 传输任务 → 离线下载
**底部固定**：安全状态、设置
**管理面板（仅管理员可见）**：用户管理、磁盘管理、权限配置、系统设置

> **Web 端没有**：文本编辑器、云盘挂载、远程连接 —— 这三项是桌面端专属能力。
> 如果你在桌面端用过云盘挂载，在浏览器里找不到它，这是**设计如此**，不是缺陷。

## 2. 文件管理

**在哪**：侧栏第 1 项「文件管理」

页面标题 **「文件管理」**，副标题 **「选择磁盘开始浏览」**。

1. 首屏列出你可访问的磁盘卡片，点一张进入目录。
2. 如果你的账号没有任何磁盘权限，会显示 **「暂无可用磁盘」** / **「请联系管理员为你分配磁盘权限」**。
3. 页面底部常驻提示 **「所有文件传输均走端到端加密」**。
4. 进入目录后，顶部按钮：**「上传」**、**「新建目录」**。
5. 列头有 **「排序」** 入口。
6. **PC 端支持拖拽上传**，拖动文件到页面会出现 **「松开以上传到当前目录」**。
7. 目录为空显示 **「此目录为空」** / **「可上传文件或新建目录」**。

**每个文件的操作**（行尾菜单）：

| 操作 | 说明 |
| --- | --- |
| 下载 | 走加密流下载 |
| 预览 | 图片 / 视频 / 音频 / 文本 / Markdown |
| 修复损坏媒体 | 只在媒体文件上出现，提交到修复中心 |
| 重命名 | 弹「重命名」弹窗 |
| 移动到… | 选择目标目录 |
| 删除 | 弹「确认删除」+「此操作不可撤销」 |

## 3. 笔记管理

**在哪**：侧栏第 2 项「笔记管理」

页面标题 **「笔记管理」**。

1. 列表页每行的操作：**「重命名」**、**「删除」**。
2. 新建走 **「新建笔记」** 弹窗。
3. 点进笔记 → Markdown 编辑器，副标题 **「笔记管理 / Markdown」**。
4. 编辑器支持实时预览、代码高亮、Mermaid 图表（工具栏按钮 **「插入 Mermaid 图表」**）。
5. 未保存就离开会提示 **「未保存的修改」**。
6. 每个用户有自己隔离的笔记存放目录，在 **「设置 → 笔记目录」** 里配置。

## 4. 传输任务

**在哪**：侧栏第 3 项「传输任务」

- 与桌面端一致，这里是**上传 / 下载进度**与**媒体修复**的合并页（标签切换）。
- 修复任务三端共享。

## 5. 离线下载

**在哪**：侧栏第 4 项「离线下载」

页面标题 **「离线下载」**，副标题 **「粘贴网址，抓取视频 / 音频 / 图片」**。

1. 贴网址 → 点分析。
2. 分析出清单后勾选要下载的项。
3. 顶部有 **「刷新」** 按钮更新任务列表。
4. 没有任务时显示 **「暂无离线下载任务」**。
5. 删除一条记录会弹 **「删除任务记录」** 确认（**只删记录，不删已下载的文件**）。
6. 部分任务会标记 **「只读」**。

## 6. 安全状态

**在哪**：侧栏底部「安全状态」

页面标题 **「安全状态」**，副标题 **「会话与加密通道」**。

显示的字段：

| 字段 | 含义 |
| --- | --- |
| 会话状态 | 当前会话是否有效 |
| Session ID | 本次会话标识 |
| 密钥交换时间 | 什么时候完成的 ECDH |
| 当前用户 | 登录账号 |
| 加密算法 | `X25519 ECDH + HKDF-SHA256` |
| 前向保密 | `已启用（临时密钥、私钥用完即销毁）` |

## 7. 设置（PC 浏览器 5 个分区 / 手机浏览器 6 个）

**在哪**：侧栏底部「设置」

页面标题 **「设置」**。分区顺序（**按 PC 浏览器实际渲染**）：

1. **服务端** —— 里面有 **「修改服务器地址」**
2. **笔记目录**
3. **账号**
4. **外观**
5. **关于**

页底 **「退出登录」**。选磁盘时会弹 **「选择磁盘」** 弹窗。

> **PC 浏览器只有上面 5 个分区**。`管理面板` 分区被 `isAdmin && !isPC` 条件挡住
> （`SettingsPage.tsx:215` 注释「仅移动端显示；PC 端侧边栏已有入口，避免重复」），
> 1440 宽实测确认只有 5 节。
> **手机浏览器（<768px）** 才会多出第 4 节 **「管理面板」**，变成 6 个分区。

## 8. 管理面板（仅管理员）

侧栏在「设置」上方多出 4 项：**用户管理、磁盘管理、权限配置、系统设置**。
功能与桌面端一致。
