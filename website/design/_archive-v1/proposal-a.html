  -p 8989:8989 \
  -v ~/jflove/data:/data \
  -v /mnt:/storage \

# 2) Web 端（18080 端口）
docker run -d --name jflove-web \
  -p 18080:80 \
  ghcr.io/js1688/jflove-web:1.10.21

安全说明 →
01
X25519 ECDH + ChaCha20-Poly1305

每次会话生成临时密钥对，session_key 只存内存，私钥用完即销毁 —— 具备前向保密

02
文件传输同样端到端加密

下载按 64KB 分片，每片独立加密成帧，不使用裸文件流直返

03
JWT 只走加密 body

令牌放在加密请求体内，不从 Authorization 头读取；URL 上不携带任何业务参数值

04
三条明文接口

仅 /health、/api/v1/auth/key-exchange、/api/v1/auth/admin-exists 为明文
