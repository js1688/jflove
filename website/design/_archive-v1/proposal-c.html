三步开始约 2 分钟
1 起服务端 端口 8989
docker run -d --name jflove-server -p 8989:8989 -v ~/jflove/data:/data -v /mnt:/storage ghcr.io/js1688/jflove-server:1.10.21
2 起 Web 端 端口 18080
docker run -d --name jflove-web -p 18080:80 ghcr.io/js1688/jflove-web:1.10.21
3 打开浏览器 首次访问初始化管理员
http://localhost:18080 打开 ↗
数据落在 ~/jflove/data，宿主 /mnt 映射为服务端 /storage；桌面端与移动端在客户端里填同一个服务地址。

API 一览

共 74 个接口，分 11 组。除以下三条明文白名单外，请求体、成功响应、错误响应一律走 ChaCha20-Poly1305 加密信封。

明文白名单仅 3 条
GET/health
POST/api/v1/auth/key-exchange
GET/api/v1/auth/admin-exists
JWT 只走加密 body 的 token 字段，URL 上不携带任何业务参数值。
