# lessons（跨角色通用经验库 · 入口）

**唯一真相（必须读全文）**：`.agents/skills/lessons/LESSONS.md`（与本文件同目录，约 660 行）。

- 加载本技能后**立即** `read` 上面这个文件：开工前按场景扫相关类别，交付前对照「五、交付前自查清单」。
- **新增条目写进 `LESSONS.md`**（现象 → 根因 → 正确做法 → 复现/验证方式），不要写在本入口文件里。
  **编号一律取下一个未用编号**（当前到 L46），**不要为"连号好看"重排** —— `文档记录/` 下的历史快照
  大量按原编号引用本文件条目，重排会让冻结文档的引用全部错位（`LESSONS.md` L21 / L46）。
- 只读了本入口文件就当技能已生效 = 违规（`AGENTS.md` §6.2 第 3 条 / `LESSONS.md` L44）。
- 全文较长，**按条目读相关章节**即可，不必整篇塞进上下文（`AGENTS.md` §6.2 第 5 条）。
- **行数不要写死**：本文件与 `AGENTS.md` §6.2 只写"约 N 行"，避免每次增删条目都要回来改数字（数字会腐烂）。
- **易腐烂的数字尽量少写**：`N 个用例 / N 个文件 / 第 N 行` 这类统计值会随每次提交变化。
  只在本角色 SKILL.md 里保留**当前值**（`testing` 技能不再重复 Web 端文件数），且优先写"以实际目录为准"。
