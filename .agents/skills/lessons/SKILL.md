# lessons（跨角色通用经验库 · 入口）

**唯一真相**：`.agents/skills/lessons/LESSONS.md`（与本文件同目录）。

## 怎么加载（按场景，不要整篇塞上下文）

先读本入口 → 按下面索引定位条目号 → 只 `read` 命中的那几节 → 交付前过一遍第五节。

| 场景 | 先读 |
| --- | --- |
| 一切任务开工前（最高频） | 第五节「交付前自查清单」 |
| 现象是"不报错但结果错"、测试全绿却没用 | 一（静默失败） |
| 编码 / 无头环境 / 线程 / 子进程 / CI 接线 | 二（平台与环境陷阱） |
| **要跑测试或自验证，但不确定本机能验哪些端** | **L48（环境自适应验证）+ L49（Flutter/Android 工具链硬坑）** |
| 要出 UAT/体验构建物，纠结要不要打 tag | **L58（UAT 用 dispatch，不用发布 tag）** |
| 文档、测试、门禁、评审、交付语义 | 三（流程与协作） |
| 界面 / 视觉效果 / 真机验收 | 四（UI 与验证） |

> 第五节按交付物类型分段（通用 / 检查校验迁移类 / 渲染环境类 / UI 视觉类 / 门禁与 CI / 技能与委派），
> **只读与本次交付物对应的那一段**。

## 维护规则

- **新增条目写进 `LESSONS.md`**（现象 → 根因 → 正确做法 → 复现/验证方式），不要写在本入口文件里。
- **编号取下一个未用编号，不要为"连号好看"重排**：`文档记录/` 下的正式文档会按原编号引用条目，
  重排会让那些引用全部错位。需要合并同类条目时，**改写其中一条并交叉引用另一条**，不挪号。
- **条目只写"当前是什么、怎么判"，不写"哪个版本踩的"**（`AGENTS.md §6.1`）。历史沿革归 `文档记录/`。
- **已被门禁兜住的条目要收缩**：若某个坑现在由脚本 / CI 机械拦住，把该条压成
  「现象一句话 + 判据在哪个门禁」，不必保留整套取证过程。
- **行数与统计数字不要写死**（会腐烂）；只说"约"或"以实际目录为准"。
- 只读了本入口文件就当技能已生效 = 违规（`AGENTS.md` §6.2 第 3 条）。
