## 6. v1.10.1 补丁验证（Windows 启动崩溃）

**问题**：v1.10.0 Windows 安装包启动即崩溃：

```text
File "src\services\local_terminal_service.py", line 14, in <module>
  import pty
File "tty.py", line 5, in <module>
ModuleNotFoundError: No module named 'termios'
```

**根因**：`local_terminal_service.py` 顶层 `import pty`；Windows 无 `pty` / `termios`，导致**整个应用无法启动**（不只是本机终端）。

**修复**：`import pty` 移入 `_open_posix()`，仅 POSIX 分支执行。

| 输入测试 | CDP `Input.dispatchKeyEvent` 输入 `echo HELLO` 后 `.xterm-rows` 仍为空 |

根因线索：`local_term.session_failed` 事件前端**没有监听**（失败被吞掉，只显示黑屏），且 `_open_windows` 没有日志，无法区分 pywinpty 启动失败/读取阻塞。v1.10.6 已补：
- `LocalSession.open`/`_open_windows` 诊断日志（shell/cwd/spawn 结果）；
- `SessionPage` 监听 `local_term.session_ready/failed` 并显示错误；
- pywinpty `spawn` 不支持 cwd/env 时降级为仅命令。
