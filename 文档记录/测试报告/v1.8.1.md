## 4. 覆盖率与缺陷

- 覆盖率：本版未接入覆盖率统计工具（沿用项目现状），以**用例数 + 实机链路**作为判据；
- 本版缺陷（开发 / 审查阶段发现并已修复）：

| 级别 | 问题 | 根因 | 修复 |
|---|---|---|---|
| 中等 | 移动端「新建任务」点击无反应 | `MaterialApp.router` 下误用 `Navigator.pushNamed`，没有 named routes | 改 `context.push<bool>(AppRoutes.offlineNew)`；补 GoRouter 回归用例 |
| 中等 | 移动端分析中切后台后轮询不恢复 | `resumed` 只补一次详情、未重启定时器 | `resumed` 时 `_startPolling()` + 立即补拉 |
| 中等 | 分析轮询失败被静默吞掉 | catch 只 `log.fine` | 连续失败 3 次 → 失败态 + 中文提示；补回归用例 |
| 中等 | 目录选择器未使用服务端返回的 `path` | `_enter` 只用 `name` 拼接（审查 M-2） | 优先用服务端 `path`，缺失才回退拼接 |
| 轻微 | 三端「2000」文案硬编码 | 与 `SERVER_DIR_LIMIT` 分离 | 已知项，留待有 `limit` 字段时统一 |

- 上一版本缺陷回归：v1.8.0 审查修复项（重分析并发闸门、进度双计、空标题覆盖）所在服务端全量用例
  `468 passed, 1 skipped` 继续全绿；本版未修改下载主链路。
