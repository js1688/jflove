**已知缺口（不隐藏）**：
1. 3GB 级真实大文件上传/合并在本机未做端到端计时（单测以 3 片小文件 + 服务端异步流程覆盖；容量建议见开发记录）。
2. AC-359（弱服务端 N2840/8GB 上传期间播放不卡）未在真实 N2840 环境实测；本机性能较强，未构造限流环境。
3. 三端设置页实机只验证了 App 登录/文件页；桌面/Web 设置页由组件单测覆盖，未逐项点击（UAT 由用户确认）。
4. Windows 端跳过（见 §5）。
5. `upload/status` 未被三端主动调用（init 已返回已收分片）；接口有后端用例覆盖。
6. 清理「合并执行数/排队数/耗时」可观测 API 未实现（设计与需求列为可选）。
