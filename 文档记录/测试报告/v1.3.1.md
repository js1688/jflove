## 三、安全用例独立小节（§9.6 testing 硬约束）

### ① 加密信封往返

- **覆盖**：`crypto.test.ts`（7 用例）+ `http-client.test.ts`（8 用例）+ `stream-frame.test.ts`（openEncryptedStream 用例）
- **用例**：密钥生成 → ECDH+HKDF 派生 session_key → `encryptEnvelope` 加密请求 → `decryptEnvelope`
  解密响应 → 字段一致；流式帧逐帧解密逐字节一致（含中文/二进制）
- **结果**：✅ 通过

### ② 路径参数权限绕过

- **覆盖**：`auth-store.test.ts`（路由守卫依赖的认证状态）+ 代码审查（§9.3.10 逐条核查）
- **用例**：无 token 不恢复登录态 → 重定向 /login；非 admin → 重定向；token 过期 → 登出
- **流式专项**：流 URL 为 128bit 不透明 token，SW 映射到已鉴权页面设定的 disk/path，后端每请求
  `check_disk_permission`；审查确认「换 token 无法绕过」（见 `代码审查报告/v1.3.1.md` §一/§9.3.10）
- **结果**：✅ 通过
- **说明**：服务端路径参数归属校验（伪造 user_id 得 403）属后端测试范畴，本版本后端无变更，沿用 v1.1.6 已验证用例。

### ③ 文件下载/流式可解密、篡改后认证失败

- **覆盖**：`stream-frame.test.ts`
- **用例**：
  - 多帧加密 → 流式解析 → 逐字节一致 ✅
  - 网络分片（跨帧边界 100B 拆包）→ 正确重组 ✅
  - 篡改密文帧 → Poly1305 认证失败抛错 ✅
  - 错误 session_key → 解密失败 ✅
  - 空明文帧边界（32B）→ 正常解析 ✅
  - **parseRangeHeader**（bytes=X-Y / X- / -N / 超界钳制）✅
  - **openEncryptedStream**（meta 帧 + 数据帧、单分片到达不丢帧）✅
  - **路径归一化**（完整路径→目录，避免 404；目录传法保持不变）✅
- **结果**：✅ 通过（**覆盖本轮两处修复：404 路径归一化 + 单分片丢帧**）

### ④ 错误响应加密

- **覆盖**：`http-client.test.ts`（错误响应解密用例）
- **结果**：✅ 通过（无后端变更，沿用已验证用例）
