### 3.1 新增文件

| 文件 | 职责 |
|---|---|

### 3.2 依赖引入

| 依赖 | 用途 |
|---|---|
| `photo_manager` | 读取系统相册（MediaStore）与权限申请 |
| `sqflite` | 已备份记录（上万条，JSON 不适合） |
| `connectivity_plus` | 「仅 Wi-Fi」条件判断 |
| `battery_plus` | 「仅充电」条件判断 |
| `device_info_plus` | 厂商识别（后台保活引导文案） |
| `android_intent_plus` | 预留：跳转系统设置（当前用中文指引代替） |
| `path` | 拼接 sqflite 数据库路径 |

### 3.3 行为

1. **默认关闭**：新建/升级后开关为关，不产生任何上传。
2. **必须选目标**：未选远端目录时打开开关 ⇒ 中文提示，不启动。
3. **权限**：Android 13+ 走 `PhotoManager.requestPermissionExtend()`；拒绝时中文引导。
4. **范围**：图片（默认开）/ 视频（默认开）；仅 Wi-Fi（默认开）/ 仅充电（默认关）。
5. **去重**：按 `asset_id` 记录，已备份直接跳过。
6. **上传**：复用 `TransferService.submitUpload`（加密分片通道），任务带 `album:<asset_id>` 标签。
7. **结果回写**：订阅 `taskStream`，成功写 `album_backup`、失败写 `album_backup_fail`。
8. **远端结构**：`<选定根>/YYYY/MM/<原文件名>`（AC-123）。
9. **永不删除**：手机删照片不影响远端（AC-118）。
10. **管理员警告**：管理员账号在卡片内显示中文警告（AC-120）。
11. **厂商引导**：按 `manufacturer` 给出小米 / 华为·荣耀 / OPPO·realme / vivo·iQOO 的中文设置路径（AC-121）。

### 3.4 调用的后端接口

全部复用既有接口，**无新增后端接口**：

| 接口 | 用途 |
|---|---|
| `POST /api/v1/files/upload/init` | 初始化分片上传（校验写权限） |
| `POST /api/v1/files/upload/chunk` | 上传分片（加密信封内 Base64） |
| `POST /api/v1/files/upload/complete` | 合并 + SHA256 校验 |
| `GET /api/v1/files/disks` | 选择目标磁盘（只列可访问） |
| `GET /api/v1/files/list` | 预览目录（选择子目录时） |

## 6. 已知限制（如实登记）

1. **后台保活未接入 WorkManager**：当前为「App 进程存活时每 60 秒扫描一次」。App 被系统杀死后不会自动备份；重新打开 App 后继续（已备份的不重复）。后续可接 `workmanager` 周期任务。
2. **`android_intent_plus` 已引入但暂未使用**：厂商引导当前为中文指引文案，跳转系统设置的按钮留待后续。
3. **无真机验证**：本环境仅完成静态分析与单测，`flutter build apk --debug` 与真机相册备份需在 Phase 8 冒烟时验证。
4. **视频大文件**：沿用现有分片上传（1 MB/片），无字节级断点续传；失败后整文件重传。

## 7. 冒烟缺陷修复（发布前，2026-10-19）

> 来源：`文档记录/测试报告/v1.7.0.md` §6 设备级冒烟。版本号仍为 1.7.0（尚未正式发布）。

| 编号 | 问题 | 修复 |
|---|---|---|
| M-1 | 传输页相册摘要暖导航缓存（开启后仍显示「未开启」） | `album_backup_card.dart` 保存配置后 `ref.invalidate(albumBackupConfigProvider)` |
| M-2 | 上传失败展示英文原始异常，违反 AC-128 | 新增 `utils/exception.dart::userFacingError()`；Dio 错误按类型映射中文，传输/下载/相册备份统一使用 |
| M-3 | 同一失败资源被定时扫描重复提交 | `album_backup_service.dart::scanAndUpload` 同时排除已备份、已失败、上传中的 asset |
| M-4 | 修改笔记目录后笔记页仍显示旧的「未配置」 | `settings_page.dart` 保存目录后 `ref.invalidate(noteListProvider)` |
