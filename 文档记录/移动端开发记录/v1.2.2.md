# jflove-app v1.2.2 移动端开发记录

## 版本概述

- **版本号**：v1.2.2
- **开发角色**：cross-platform-mobile
- **目标**：补全移动端传输任务可视化与立即同步功能

---

## 本次变更的页面/组件

| 文件 | 变更 | 说明 |
|------|------|------|
| `lib/app.dart` | 修改 | TransferFloatingCard 移到 _AppScaffold，全局可见 |
| `lib/pages/home/home_page.dart` | 修改 | 移除 TransferFloatingCard |
| `lib/services/transfer_service.dart` | 重写 | 增强下载/上传/并发/取消 |
| `lib/pages/files/disk_browser_page.dart` | 修改 | 下载改用 TransferService |
| `lib/pages/sync/sync_page.dart` | 修改 | 添加立即同步按钮 + 状态显示 |

### 变更详情

**1. 传输任务浮窗全局化**

| 改进点 | 之前 | 之后 |
|--------|------|------|
| TransferFloatingCard 位置 | HomePage 的 Stack 中 | _AppScaffold 的 Stack 中 |
| 可见范围 | 仅首页 | 所有底部导航页面 |

**2. 传输服务增强（`transfer_service.dart`）**

| 改进点 | 之前 | 之后 |
|--------|------|------|
| 下载 | 只读取流更新进度，不保存文件 | 创建 `File` + `IOSink` 写入本地，边收边写 |
| 上传 | 空壳，标记为 completed | 分片读取本地文件，Base64 编码后通过 `encryptedPost` 上传 |
| 并发控制 | 无 | 最大 3 个并发任务，超额任务排队等待 |
| 取消支持 | 仅改状态，不中止实际传输 | 添加 `_cancelledTasks` Set，取消后清理不完整文件 |

**3. 文件页下载使用传输任务**

`DiskBrowserPage._downloadFile` 改为调用 `TransferService.submitDownload()`，创建传输任务并由 `TransferFloatingCard` 展示进度。

**4. 同步管理 - 立即同步按钮**

`_SyncConfigCard` 从 `StatelessWidget` 重构为 `ConsumerStatefulWidget`，添加 `onSyncNow` 回调 + 同步按钮，监听 `SyncEngineService.eventStream` 实时反映同步状态，状态文字 3~5 秒后自动清除。

## 与上一版本的逻辑差异

| 维度 | v1.2.1 | v1.2.2 |
|------|--------|--------|
| 传输任务浮窗 | 仅首页可见 | 全局底部导航可见 |
| 文件下载 | 直接下载，无进度提示 | 创建传输任务，实时显示进度 |
| 文件上传 | 未实现 | 分片上传，支持并发和取消 |
| 同步管理 | 无立即同步入口 | 配置卡片上添加"立即同步"按钮 |
