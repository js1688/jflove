## 预览流式化修复（hotfix3，2026-07-29）

### BUG 根因

视频/音频预览使用了 `/api/v1/files/download` 全量下载到临时文件后才开始播放，未流式化；文本预览同样全量入内存，大文件可能 OOM。桌面端已通过 `StreamProxy`（视频）和 `StreamTextLoader`（文本）实现流式读取。

### 修复方案

| # | 问题 | 根因 | 修复方案 |
|---|------|------|----------|
| 1 | 视频/音频需全量下载后才播放 | `_MediaPreview` 使用 `download()` + `VideoPlayerController.file()` | 新增 `StreamProxy`（`lib/utils/stream_proxy.dart`），本地 HTTP 代理 → `VideoPlayerController.network()` 边下边播 |
| 2 | 文本预览全量入内存 | `_TextPreview` 使用 `download()` 下载全部 | 改用 `/api/v1/files/stream` 流式加载，>8MB 截断旧内容 |
| 3 | 扩展名支持不完整 | 仅支持 ~45 种 | 对齐桌面端 `TEXT_EXTS`，扩展至 60+ 种 |

### 新增文件

| 文件 | 说明 |
|------|------|
| `lib/utils/stream_proxy.dart` | 本地流式 HTTP 代理。对标桌面端 `stream_proxy.py`：在 `127.0.0.1` 启动 `HttpServer`，解析 Range 请求头，转换为 `/api/v1/files/stream` 参数，逐帧解密后写回。 |

### 修改文件

| 文件 | 变更 | 说明 |
|------|------|------|
| `lib/services/file_service.dart` | +`streamRange()` | 新增流式范围读取方法，调用 `GET /api/v1/files/stream` |
| `lib/pages/files/file_preview_page.dart` | 重写 `_MediaPreview` + `_TextPreview` | 视频/音频使用 StreamProxy 流式播放；文本使用 streamRange 流式加载；扩展名列表对齐桌面端 |
| `pubspec.yaml` | 版本号 `1.2.3+2` → `1.2.3+3` | 构建号递增 |

## 自动登录修复（hotfix4，2026-07-29）

### BUG 根因

`isLoggedIn` 依赖 `sessionId`/`sessionKey`（仅内存，前向保密设计），但应用重启后无人触发 ECDH 重新握手。`loadFromStorage()` 只能恢复 token，无法恢复加密通道，因此 `isLoggedIn` 永远为 `false` → 跳转到登录页。

### 修复方案

在 `main.dart` 中，`loadFromStorage()` 之后检测 token 是否有效（距过期≥60s），自动执行 `keyExchange()` 恢复 `sessionKey`/`sessionId`，使 `isLoggedIn` 在 `runApp()` 前变为 `true`。

### 对齐桌面端

对标桌面端 `try_restore_session()` + `_try_auto_login()` 逻辑。

### 修改文件

| 文件 | 变更 | 说明 |
|------|------|------|
| `lib/main.dart` | 修改 | 启动时检测 token 有效→自动 ECDH 恢复会话 |
| `lib/utils/session.dart` | 修改 | 修正 `serverUrl` 分类注释；`clear()` 保留历史与 TTL |
| `lib/pages/login/login_page.dart` | 修改 | 预填充 serverUrl / TTL / username |

## 视频流 HTTP method 修复（hotfix5，2026-07-29）

### BUG 根因

`StreamProxy._fetchStreamRange()` 用 `dio.post()` 调用服务端 `/api/v1/files/stream` 端点，但该端点是 **GET**。服务端返回 405/路由不匹配，导致 ExoPlayer 收到无效响应 → `ExoPlaybackException`。

### 修复

`lib/utils/stream_proxy.dart`：`dio.post` → `dio.get`（`data` 参数携带加密 body）。

### 修改文件

| 文件 | 变更 | 说明 |
|------|------|------|
| `lib/utils/stream_proxy.dart` | 修改 | `dio.post()` → `dio.get()` |
