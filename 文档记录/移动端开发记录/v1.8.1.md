## 2. 接口对齐（以 controller 为准）

| 方法 | 接口 | 字段 |
|---|---|---|
| `analyze` | `POST /api/v1/offline/analyze` | `url` |
| `select` | `POST /api/v1/offline/select` | `task_id`、`item_ids`、`disk_id`、`target_path`、`pack_zip` |
| `nextPage` | `POST /api/v1/offline/next-page` | `task_id` |
| `cancel` / `retry` / `deleteRecord` | `POST /api/v1/offline/cancel\|retry\|delete-record` | `task_id` |
| `saveSettings` | `POST /api/v1/offline/settings` | `disk_id`、`rel_path`、`create` |

- `task_id` / `url` / `rel_path` 全部在加密 body，不进 URL；
- 未新增任何加密算法 / 密钥 / KDF（安全宪法 §9.5）。

## 3. 页面与交互

### 3.1 任务中心（`/offline`）

- AppBar：设置（默认目录）、刷新；
- FAB / 空态按钮：「新建任务」→ `/offline/new`，成功返回后立即刷新；
- 卡片：状态、进度、来源域名、产物名、目标、失败原因（中文 + 建议）；
- 操作（按状态）：
  - `queued/analyzing/downloading/merging` → 取消；
  - `failed/canceled` 且错误码可重试 → 重试（`disk_full` / DRM / 需登录 / 目录失效等不可重试）；
  - 终态 / `ready` → 删除记录（只删记录，不删磁盘文件）；
  - `ready` → 去选择（打开勾选弹层）。

### 3.2 新建任务页（`/offline/new`）

- 默认目录未配置 / 目录失效 / 无写权限磁盘 / 总开关关闭 → 顶部中文提示 + 「去设置」，**分析按钮禁用且不发起请求**（AC-253）；
- URL 仅接受 `http/https`；
- 分析中 2.5s 轮询详情，提供「取消」；
- `ready`：清单勾选（默认全选）+ 快捷选择（全选 / 只要音频 / 只要图片 / 最高清）+ 已选汇总 + 目标目录（选择器）+ 打包 zip + 开始下载；
- 失败：中文原因 + 建议，保留已选状态。

### 3.3 详情弹层

- 展示任务字段 + 清单项；
- `ready` 时可勾选、选目标目录、打包 zip、开始下载；
- `has_more_images=true` 且 `ready` → 追加下一页（成功后刷新清单与列表）；
- 取消 / 重试 / 删除记录。

### 3.4 默认目录设置

- 磁盘下拉仅 `meta.writable_disks`；
- 「选择目录」→ `VirtualDiskDirPicker`；
- 「目录不存在时自动创建」开关（默认关）；
- 保存 / 清除；保存后刷新列表与 meta；无可写磁盘整块禁用并给中文说明。

### 3.5 目录选择器

| 组件 | 用途 | 接口 |
|---|---|---|
| `VirtualDiskDirPicker` | 磁盘内相对路径（离线目标 / 默认目录、相册备份远端） | `GET /virtual-disks/{disk_id}/browse` |
| `ServerDirPickerDialog` | 管理员选择服务端真实路径（添加 / 编辑磁盘） | `GET /virtual-disks/server-dirs` |

- 只列目录、不读文件；隐藏目录由服务端过滤；
- 请求 / 响应全部加密；`task_id` / `path` 不进 URL。

## 4. 测试改写（AC-254）

原 `test/offline_download_page_test.dart` 逐条断言「0 命中新建 / 取消 / 重试」，

| 原只读断言 | v1.8.1 断言 |
|---|---|
| 无任何按钮 / 勾选控件 | 有「新建任务」「设置」「取消」「重试」「删除记录」入口 |
| 详情无任何操作控件 | 失败详情有重试 / 删除记录；`ready` 详情有勾选 + 开始下载 |
| 元信息不可用只显示提示 | 仍显示原因，同时可查看已有任务、可进入新建页（新建页再拦截） |

- `offline_new_task_page_test.dart`：未配置目录不发起分析；分析 → 轮询 ready → 勾选 → 开始下载；只要音频；非法 URL；
- `offline_settings_sheet_test.dart`：保存 / 清除 / 无可写磁盘禁用；
- `services/offline_download_service_test.dart`：9 个方法的 method / path / 字段；

## 6. 安全自查（`AGENTS.md §9.6`）

- [x] 所有 HTTP 走 `http_service.dart`，未直接 import dio / 发起明文请求；
- [x] `task_id` / `url` / `path` 在加密 body，不进 URL；
- [x] token / session_key 不进入日志（轮询失败只打 `userFacingError`）；
- [x] 未新增加密算法 / 长期密钥 / 静态盐；
- [x] 服务器目录接口仅管理员（服务端校验 + 单测覆盖）；移动端只消费结果；
- [x] 错误不展示 Dio 原始英文 / 堆栈。

## 7. 已知限制

1. 移动端不提供「本地缓存目录」配置（需求 §1.4 明确不做）；上传走系统文件选择器。
2. 服务端 `select` 仍会二次校验目标目录 / 写权限 / 余量，客户端的前置拦截只是体验优化。
3. 分析页轮询固定 2.5s（不跟随 `poll_interval_ms`），与 v1.8.0 任务中心策略一致。
4. iOS / 鸿蒙仍为预留方向，本版只在 Android 验证。
