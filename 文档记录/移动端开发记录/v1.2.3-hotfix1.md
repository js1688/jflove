## 修复背景

用户反馈移动端文件管理体验差：
- 下载文件后传输任务页面不显示任务
- 文件操作后列表不刷新
- 上传需手动输入文件路径
- "移动到…"功能未实现
- 无写权限控制
- 下载后无反馈、不知道保存位置
- 取消任务按钮未实现
- "清除已完成"按钮点击无反馈

## 问题根因

### P0：transferServiceProvider 重复定义导致传输任务不互通

`file_provider.dart` 和 `transfer_provider.dart` 中都定义了 `transferServiceProvider` 和 `transferTaskStreamProvider`，导致创建了两个独立的 `TransferService` 实例。文件管理页面使用 `file_provider.dart` 的实例提交下载任务，传输任务页面使用 `transfer_provider.dart` 的实例显示任务列表，两者互不相通。

### P0：FutureProvider.family 不响应 setState

`disk_browser_page.dart` 中重命名/删除/新建目录后使用 `setState(() {})` 尝试刷新，但 `fileListProvider` 是 `FutureProvider.family`，不会因为 `setState` 重新请求。必须用 `ref.invalidate()` 使其过期。

## 修复内容

### 修复 1：统一 transferServiceProvider

- **文件**：`lib/providers/file_provider.dart`
- **变更**：删除重复的 `transferServiceProvider` 和 `transferTaskStreamProvider` 定义及对应 import
- **保留**：`transfer_provider.dart` 作为传输相关 provider 唯一来源

### 修复 2：文件列表刷新机制

- **文件**：`lib/pages/files/disk_browser_page.dart`
- **变更**：封装 `_refresh()` 方法，调用 `ref.invalidate(fileListProvider(...))`
- 所有操作（重命名/删除/新建目录/上传）成功后调用 `_refresh()` 替代 `setState(())`

### 修复 3：引入 file_picker 改善上传体验

- **文件**：`pubspec.yaml`、`lib/pages/files/disk_browser_page.dart`
- **变更**：
  - 新增依赖 `file_picker: ^10.0.0`
  - `_uploadFile()` 改用 `FilePicker.platform.pickFiles(allowMultiple: true)` 选择文件
  - 支持多选，批量提交到传输队列（对齐桌面端 `getOpenFileNames`）

### 修复 4：实现"移动到…"功能

- **文件**：`lib/widgets/move_target_dialog.dart`（新增）、`lib/pages/files/disk_browser_page.dart`
- **变更**：
  - 新建 `MoveTargetDialog`，对标桌面端 `MoveTargetDialog`
  - 展示当前磁盘的目录树（仅目录），逐级浏览并选择目标目录
  - 禁止移动到自身或子目录
  - `_moveItem()` 弹出弹窗，选定后调用 `fileService.move()`

### 修复 5：写权限控制

- **文件**：`lib/pages/files/disk_browser_page.dart`
- **变更**：
  - 新增 `_computeCanWrite()` 方法：管理员始终可写，普通用户从 `VirtualDisk.canWrite` 读取
  - 上传/新建目录按钮根据写权限禁用（带 tooltip 提示）
  - 长按菜单中重命名/移动/删除根据写权限禁用或置灰

### 修复 6：下载反馈与跳转

- **文件**：`lib/pages/files/disk_browser_page.dart`
- **变更**：
  - 下载 SnackBar 增加"查看"操作按钮，点击跳转到 `/transfer`
  - 上传 SnackBar 同样增加"查看"按钮

### 修复 7：取消任务

- **文件**：`lib/pages/transfer/transfer_page.dart`
- **变更**：`_TransferTaskCard` 改为 `ConsumerWidget`，取消按钮调用 `transferService.cancel(task.id)`

### 修复 8：清除已完成反馈

- **文件**：`lib/services/transfer_service.dart`、`lib/pages/transfer/transfer_page.dart`
- **变更**：
  - `clearFinished()` 返回清除数量
  - 点击后 SnackBar 提示"已清除 N 个已结束任务"或"没有可清除的任务"
  - 无任务时使用 `context.mounted` 而非 ConsumerWidget 不可用的 `mounted`

### 修复 9：传输浮窗路由修复

- **文件**：`lib/widgets/transfer_floating_card.dart`
- **变更**：`Navigator.pushNamed(context, '/transfer')` → `context.push('/transfer')`
