## 与上一版本的逻辑差异

v1.2.0 是移动端首个版本，无同模块上一版本。与桌面端 v1.1.6 的关键差异：

| 维度 | 桌面端 (v1.1.6) | 移动端 (v1.2.0) |
|------|-----------------|-----------------|
| 框架 | PySide6 + Python | Flutter + Dart |
| 状态管理 | Redux (信号槽) | Riverpod |
| 加密库 | Python cryptography | Dart pointycastle + x25519 |
| 安全存储 | JSON 文件 (用户数据目录) | Android Keystore |
| 导航方式 | 侧边栏 | 底部导航栏 |
| 同步 | 本地↔服务端双向 | 服务端→App 内部存储单向 |
