## 1. 离线下载页

| 文件 | 说明 |
|---|---|
| `src/services/offline-download-service.ts` | 10 个接口：analyze/listTasks/detail/select/nextPage/cancel/retry/deleteRecord/meta/saveSettings；GET 用 `httpClient.get(path, body)`（query 信封）、POST 用 `httpClient.post` |
| `src/types/models.ts` | `OfflineTask` / `OfflineItem` / `OfflineTaskDetail` / `OfflineMeta` / 四态原因等，字段与设计 §2.2 严格一致 |
| `src/utils/offline-download.ts` | 纯函数：轮询间隔兜底/夹边界、快捷选择（最高清/音频/图片）、四态文案、终态判定、进度换算 |
| `src/pages/OfflineDownloadPage.tsx` | 任务中心 + 新建任务分段；任务卡操作（取消/重试/删除记录/去选择/在文件管理中打开）；2.5s 轮询 + `visibilitychange` 停/恢复 + 全终态停 |
| `src/components/offline/NewTaskPanel.tsx` | 粘贴 URL → 分析 → 清单勾选（快捷选择/全选/全不选/继续抓下一页/pack_zip）→ 目录预填（可临时改）→ 开始下载 |
| `src/components/offline/OfflineSettingsModal.tsx` | 我的默认目录：磁盘只取 `meta.writable_disks`；浏览/新建目录；清除 `disk_id=0`；**不写 localStorage** |
| `src/config/routes.tsx`、`layouts/DesktopLayout.tsx`、`layouts/MobileLayout.tsx` | `/offline` 路由；PC 侧栏「离线下载」+ 移动底部菜单「离线」 |
| `src/pages/DiskBrowserPage.tsx` | 支持从 router state 的 `browsePath` 直达产物目录（**路径不放 URL**，§9.4） |

界面语义：
- 无可写磁盘：整页禁用 + 「你没有可写入的磁盘，无法使用离线下载」；
- 未配置/配置失效：引导/「离线下载目录已失效，请重新配置」；
- 任务列表只显示当前账号自己的任务（服务端 D10）；
- 失败原因直接展示服务端中文 `error_message`，不可重试类不显示「重试」。
