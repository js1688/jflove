## 3. 待验清单（按 AC 组织）

### 3.1 桌面端

- [ ] 离线下载任务 `status=success`：进度条满格、显示 `100%`（即使 `bytes_done < bytes_total`）；
- [ ] 磁盘管理 → 添加磁盘 →「浏览…」：可从 `/`（或 roots）逐级进入、上级、根目录，选中后回填；
- [ ] 编辑磁盘时选择器定位到当前 `real_path`；
- [ ] 非管理员账号看不到 / 调不通该接口（403）；
- [ ] 手动输入真实路径仍可用（兜底）。

### 3.2 Web 端

- [ ] 成功任务进度条 100% + 文案 `100%`；
- [ ] 添加 / 编辑磁盘「浏览…」可用，选中回填；
- [ ] 错误路径 / 无权限目录：弹窗不关闭、可重试、toast 中文。

### 3.3 移动端

- [ ] 底部入口 / 设置入口进入离线下载中心，有「新建任务」「设置」；
- [ ] 新设备首次进入：提示未配置目录 →「去设置」→ 选磁盘 + 目录 → 保存 → 返回可分析；
- [ ] 粘贴公开网页 URL → 分析（≤30s）→ 清单 → 勾选 / 快捷选择 → 目标目录 → 开始下载；
- [ ] 任务中心：取消 / 重试 / 删除记录；失败显示中文原因 + 建议；
- [ ] `has_more_images=true` 时可「追加下一页」；
- [ ] 移动端保存的默认目录在桌面 / Web 同账号 2.5s 内可见，反之亦然；
- [ ] 添加 / 编辑磁盘可浏览服务器目录；
- [ ] 相册备份远端目录改为「磁盘 + 目录选择器」后可保存。

### 3.4 回归

- [ ] 三端登录 / 文件 / 笔记基础功能不受影响；
- [ ] 服务端重启后任务状态与默认目录保持。
