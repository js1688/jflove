## 2. 待验清单（按 AC 组织）

### 2.1 离线下载（#9 / #11）

- [ ] B 站（或同类音视频分离站点）新建任务 → 下载 360P/720P → 播放**有画面有声音**；
- [ ] 下载过程中解析/下载耗时符合预期（普通站点不被 90s 预算拖慢）；
- [ ] 管理员把「解析总超时」改为 120s → 保存 → 三端读回一致；解析慢站不再轻易失败；
- [ ] 给一个失效链接：失败文案为中文「解析超时…/音视频合并失败，可重试」，可一键重试；
- [ ] 超时但有部分结果时，任务详情显示「解析超时，已返回部分结果（可重试补充）」。

### 2.2 相册备份（#8 / #12）

- [ ] 卸载重装 App（或清数据）→ 重开相册备份 → 远端已存在的文件**不重复上传**，界面显示「远端已存在跳过 N 项」；
- [ ] 相册备份计数：总数 / 已备份 / 上传中 / 失败 / 不在范围 / 远端跳过 六项自洽；
- [ ] 关闭「备份视频」→ 视频计入「不在范围」，不再显示为永久待备份；
- [ ] 构造/观察一个坏视频 → 其余照片继续完成，失败项可看中文原因、可重试；
- [ ] 「立即检查」「重试失败项」「重新核对远端」三个入口行为符合预期。

### 2.3 Linux 桌面播放（#10）

- [ ] 在**真实桌面会话**（Wayland 或 X11）播放视频 → 拖动主窗 200px，画面**同步跟随、不被遮挡、不黑屏**；
- [ ] 缩放窗口、全屏、退出全屏、关窗到托盘、托盘恢复：浮层位置均正确；
- [ ] 中文输入法仍可正常输入（不被本次改动影响）；
- [ ] `JFLOVE_MEDIA_OVERLAY=window` 启动可回退旧行为（仅排障，不要求日常使用）。

### 2.4 回归

- [ ] 三端登录 / 文件 / 笔记基础功能正常；
- [ ] 管理端「离线下载」7 项配置在桌面 / Web / 移动均可见、可保存；
- [ ] 目录选择器「仅显示前 N 项」文案三端一致（N 来自服务端 `limit`，默认 2000）。
