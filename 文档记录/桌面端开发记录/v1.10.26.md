## 5. 遇到并纠正的坑（记录备查）

同步 Web 端改动时，一度把 Web 的 `http-client.ts` / `FilePreviewPage.tsx` / `DiskBrowserPage.tsx`
**整文件**拷到桌面端，导致：

- `Failed to resolve import "./crypto"`（桌面 http-client 是 113 行桥转发版，Web 是 579 行 fetch 版）
- `Failed to resolve import "../utils/media-source-player"`（该模块桌面端不存在）
- `TS2345 FileList 不能赋给 LocalFile[]`（两端 `uploadFiles` 签名不同）

教训：**两端"同源"只针对 parity 门禁清单内的文件**，其余文件是各自实现，必须定向改。
`npm run build` 在桌面端带 `tsc --noEmit`（Web 端是 `tsc -b`），能抓到这类问题。
