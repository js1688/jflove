## 2. 关键实现点

- **终端通道**：`QWebSocketServer` 只绑 `127.0.0.1:0`；每会话随机 token；下行二进制（UTF-8 原始字节），上行 JSON（input/resize/close）；读线程通过 Qt Signal 投递到 GUI 线程。
- **跳板**：`transport.open_channel("direct-tcpip", ...)` 逐跳串联，最多 16 级；链状态通过 `remote.session_status` 事件推给渲染层。
- **主机指纹**：首次暂停认证、发 `remote.hostkey_ask` 事件等渲染层确认（30s 超时拒绝），确认后由 Python 直接写回服务端；已记录指纹不匹配即中止。
- **凭据红线**：`remote.connections_get` 只返回 `has_password` / `has_private_key` 与指纹；打开会话时 Python 直接取全量，不经渲染层。
- **本机终端**：配置存 `LOCAL_STORAGE_DIR/jflove-local.db`；Windows 缺 `pywinpty` 时入口报错但不影响远程终端。

## 8. v1.10.3：终端闪屏根因 + 本地/远程合并树

### 8.1 SSH 终端闪屏（根因）

`TerminalView` 的 effect 依赖里包含父组件内联的 `onReady`。连上后 `patchTab` 触发重渲染 →
新的 `onReady` → effect 重跑 → WebSocket 断开重连，形成无限循环（表现为闪屏、无法输入）。

修复：`onReady` 改存 `useRef`，effect 依赖固定为 `[sessionId, port, token]`。
新增源码回归测试 `src/__tests__/terminal-view-v1-10-3.test.ts`（3 条）锁死依赖与 `onReadyRef`。

### 8.2 本地 / 远程合并树

- 左侧根节点固定两个：**本地**、**远程**。
- 本地下可建分组与「本机配置」（名称 / shell / 工作目录 / 默认命令 / 分组），存本地 SQLite。
- 远程下可建分组与 SSH / 仅 SFTP 连接，存服务端。
- 新建按当前选中侧决定写本地还是服务端；本机配置不再"点了就开"，而是先保存再双击打开。

### 8.3 本机终端

- 会话只显示终端，不显示「文件」页签。
- 打开后可继续用默认命令（如 `cd ~/apps && ls`）。
