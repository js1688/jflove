**新增 `_rename_item(name, is_dir)`：**

```python
def _rename_item(self, name: str, is_dir: bool) -> None:
    new_name, ok = QInputDialog.getText(self, "重命名", "新名称：", text=name)
    if not ok or not new_name.strip():
        return
    new_name = new_name.strip()
    # 前置客户端校验
    if "/" in new_name or "\\" in new_name:
        self._show_error("名称不能包含 / 或 \\")
        return
    if new_name in (".", ".."):
        self._show_error("名称不合法")
        return
    rel = (self._current_rel_path() + "/" + name).lstrip("/")
    self._worker = Worker(file_service.rename_file, self._current_disk_id, rel, new_name)
    self._worker.finished.connect(lambda _: self._on_rename_done(name, new_name))
    self._worker.error.connect(lambda e: self._show_error(f"重命名失败：{e}"))
    self._worker.start()
```

**新增 `_move_item(name, is_dir)`：**

```python
def _move_item(self, name: str, is_dir: bool) -> None:
    src_rel = (self._current_rel_path() + "/" + name).lstrip("/")
    dlg = MoveTargetDialog(self._current_disk_id, src_rel, parent=self)
    if dlg.exec() != QDialog.DialogCode.Accepted:
        return
    dst = dlg.getSelectedPath()
    if dst is None:
        return
    # 客户端同目录检测
    if dst == self._current_rel_path():
        self._show_info("已在该目录，无需移动")
        return
    self._worker = Worker(file_service.move_file, self._current_disk_id, src_rel, dst)
    self._worker.finished.connect(lambda _: self._on_move_done(name, dst))
    self._worker.error.connect(lambda e: self._show_error(f"移动失败：{e}"))
    self._worker.start()
```

## 七、关键设计思路与取舍

### 7.1 `currentItemChanged` 信号的连接时机

`MoveTargetDialog._setup_ui()` 中先创建按钮并 `setEnabled(False)`，但 `_load_root()` 通过 `addTopLevelItem` 把根节点加入树时，Qt 会自动将其设为 current item 并触发 `currentItemChanged`。如果在 `_setup_ui` 中就连接该信号，按钮会立即被重新启用。

解决方案：在 `__init__` 中先调用 `_setup_ui()` → `_load_root()`，之后再连接 `currentItemChanged`。这样根节点加入时信号尚未连接，按钮保持禁用状态，直到用户真正点击选中某项。

### 7.2 懒加载避免全量预拉取

目录树使用占位子项 + `itemExpanded` 信号实现懒加载：只有用户点击展开时才请求该层子目录，避免打开弹窗时对大型磁盘一次性拉取全部目录结构，减少网络压力和等待时间。

### 7.3 客户端前置校验与后端校验的分工

- 客户端校验（`_rename_item`）：非空、非法字符（`/\`）、保留名（`.` / `..`）→ 减少明显错误触发的无效请求，提升交互响应速度
- 后端校验：路径穿越防护、目标已存在（409）、同名静默跳过 → 权威校验，客户端不信任

### 7.4 `_can_write` 状态管理

`_can_write` 在 `_on_disk_changed` 中根据 `session_manager.role` 与磁盘 `can_write` 字段更新。管理员始终有写权限，普通用户依赖后端返回的磁盘权限字段。切换磁盘时同步更新，防止跨磁盘权限混用。
