# v1.1.0 桌面端开发记录

本次迭代实现流式预览功能：视频/音频通过本地 HTTP 代理（StreamProxy）流式拉取，文本通过 StreamTextLoader 逐帧 append，图片/SVG/Markdown 保持 v1.0 整文件加载。**不再写本地临时文件**。

## 二、新增 / 修改文件详情

### 2.1 `src/utils/http_client.py`

新增 `stream_request(method, path, payload) -> requests.Response` 方法：

- 将 `payload` 注入 token 后加密，放入 JSON body 发送
- 设置 `stream=True`，返回原始 `requests.Response`（调用方负责关闭）
- 连接超时 5s，读取超时 30s
- HTTP 错误状态（≥400）调用已有 `_handle_stream_error()` 抛出 `ApiError`
- 通过 `requests.request(method, ...)` 支持任意 HTTP 方法

### 2.2 `src/services/file_service.py`

新增 `stream_range(disk_id, path, filename, range_start, range_end)` 函数：

```python
stream_range(...) -> tuple[dict, Generator[bytes, None, None]]
```

**逻辑：**

1. 调用 `http_client.stream_request("GET", "/api/v1/files/stream", payload)`
2. 读取第一帧（元数据帧），JSON 解析为 `meta` dict
3. 若 meta["type"] == "error"，关闭连接并 `raise ValueError`
4. 返回 `(meta, frame_iter)`，`frame_iter` 是惰性生成器：
   - 逐帧调用 `parse_stream_frame(raw, session_key)` 解密
   - 对 <512B 的帧额外 JSON 解析，判断是否为服务端错误帧
   - `finally` 块确保连接被关闭

### 2.3 `src/components/stream_proxy.py`（新文件）

`StreamProxy` 本地 HTTP 代理，供 `QMediaPlayer` 直接 HTTP 拉取。

**关键设计：**

| 特性 | 实现 |
|---|---|
| 绑定地址 | `127.0.0.1`（loopback only） |
| 端口 | OS 自动分配（`port=0`），启动后通过 `server_address[1]` 取得 |
| 一次性 Token | `uuid.uuid4().hex`，嵌入 URL；防止其他进程猜测 |
| 服务器实现 | `_TokenTCPServer`（继承 `socketserver.TCPServer`）+ `_ProxyHandler`（继承 `BaseHTTPRequestHandler`） |
| 线程模型 | `daemon=True` 独立线程运行 `serve_forever()` |
| HEAD 请求 | 取 range(0,0) 元数据帧，返回 `Content-Length` + `Accept-Ranges` |
| GET 请求 | 解析 `Range: bytes=X-Y`，两次调用 `stream_range()`（第一次取 meta 拿 file_size，第二次拿数据帧），响应 206 |
| 关闭 | `close()` 设置 `_closed=True`，强制关闭活跃连接写出，在独立线程调 `shutdown()` 防死锁 |
| 线程安全 | `_lock` 保护 `_active_response` 的写入 |

### 2.4 `src/components/stream_text_loader.py`（新文件）

`StreamTextLoader(QThread)` 文本流式加载线程。

**Signals：**

| Signal | 说明 |
|---|---|
| `meta_ready(object)` | 收到元数据帧时 emit（含 file_size / content_type） |
| `chunk_ready(object)` | 每帧解密明文 bytes emit |
| `finished()` | 正常结束 |
| `error(str)` | 出错 |

**方法：**
- `start_loading(disk_id, path, filename, range_start, range_end)` — 配置参数后启动线程
- `cancel()` — 设置 `_cancelled=True`，当前帧完成后退出循环

### 2.5 `src/components/preview_dialog.py`

**移除内容：**
- `import tempfile`（不再写临时文件）
- `QTimer` import（不再需要延迟删除）
- `_tmp_path` 状态字段
- `_fetch_to_tmp_file()` 方法
- `_on_media_ready()` 方法
- `_safe_remove()` 模块级函数

**新增内容：**
- `import QPlainTextEdit`
- `from src.components.stream_proxy import StreamProxy`
- `from src.components.stream_text_loader import StreamTextLoader`
- `_proxy: Optional[StreamProxy]` 状态字段
- `_text_loader: Optional[StreamTextLoader]` 状态字段
- `_TEXT_MAX_BYTES = 8MB`、`_TEXT_KEEP_BYTES = 6MB` 常量
- `_StreamTextView(QWidget)` 内部类：包含 `QPlainTextEdit` + `append_bytes()` 方法，超 8MB 时截断旧内容保留 6MB
- `_MediaView.__init__` 参数从 `local_file` 改为 `media_url` + `display_name`；`setSource` 改为 `QUrl(self._media_url)`

**`_start_loading()` 新逻辑：**

```
kind == "video" / "audio"
  → StreamProxy(disk_id, path_dir, filename)
  → proxy.start()
  → _MediaView(proxy.url, kind, display_name=filename)
  → 立即显示播放器（无需等待下载）

kind == "text"
  → _StreamTextView 加入 content_layout 并切换显示
  → StreamTextLoader(self)
  → loader.chunk_ready → text_view.append_bytes
  → loader.start_loading(...)

其他（image / svg / markdown）
  → Worker(file_service.get_preview_bytes, ...)  [保持 v1.0 行为]
```

**`closeEvent()` 新逻辑：**

```python
media_view.stop_and_release()   # 停止播放，清除 source
proxy.close()                   # 关闭本地代理（中断流）
text_loader.cancel()            # 取消文本加载线程
```
