### 2.2 登录有效期选项改为按天

**背景**：v1.1.2 将登录有效期从「本地提前到期」改为「将 TTL 选项值作为 `requested_ttl_seconds` 上传给服务端」，由服务端按用户选择签发 JWT。v1.1.4 进一步将选项从分钟/小时级扩展为天级。

**具体变更**：

```python
# v1.1.3（小时级）
LOCAL_SESSION_TTL_OPTIONS = [
    (1800, "30 分钟"),
    (3600, "1 小时"),
    (7200, "2 小时"),
    (14400, "4 小时"),
    (28800, "8 小时"),
]
LOCAL_SESSION_TTL_DEFAULT = 3600  # 默认 1 小时

# v1.1.4（天级）
LOCAL_SESSION_TTL_OPTIONS = [
    (86400, "1 天"),
    (604800, "7 天"),
    (2592000, "30 天"),
]
LOCAL_SESSION_TTL_DEFAULT = 2592000  # 默认 30 天
```

### 2.3 服务端地址历史持久化

**新增文件**：`src/services/server_history_service.py`

核心功能：

| 函数 | 功能 |
|------|------|
| `record(url)` | 连接成功时写入历史，LRU 置顶，最多 10 条，原子写入（tmp→os.replace） |
| `list_history()` | 返回所有历史地址（最近使用在前） |
| `get_default()` | 取最近使用的地址；无历史时兜底 `http://localhost:8989` |
| `delete(url)` | 手动删除某条历史记录 |

实现要点：
- 连接成功后**立即**写入磁盘（不依赖程序正常退出流程）
- 规范化比较去重（去尾部斜杠）
- 线程安全（`threading.Lock`）
- 文件损坏时静默降级为空历史
- 不持久化任何 token / session_key / 密码

**修改文件**：`src/ui/login_window.py`

- `_refresh_server_history()`：从缓存加载历史，刷新下拉项
- `_on_delete_history()`：确认弹窗 + 调用 `delete()` + 刷新下拉
- `_on_connect_done()`：连接成功后调用 `record()` + 刷新下拉

### 2.4 重命名/移动 404 错误提示

**修改文件**：`src/ui/pages/file_page.py`

新增 `_on_rename_or_move_error` 方法：
```python
def _on_rename_or_move_error(self, msg: str) -> None:
    if msg.startswith("[404]"):
        self._show_error("目标资源不存在")
    else:
        self._show_error(f"操作失败：{msg}")
```

`_rename_item` 和 `_move_item` 中 Worker 的 `error` 信号连接统一改为 `_on_rename_or_move_error`。

### 2.5 双主窗口 Bug 修复（AC-13/AC-14）

**问题根因**：`_check_token_expiry` 在 QTimer.timeout 回调内直接调用 `self._do_logout()`，导致 Qt 事件循环无法正确处理窗口销毁。`closeEvent` 始终用 `event.ignore()` + `self.hide()` 将关闭转为"隐藏到托盘"，旧窗口永远不被销毁。

**三处修复**：

#### 修复 A：`main_window.py._check_token_expiry` — 延迟执行
```python
# 修改前：MessageBox 后直接调用
box.exec()
self._do_logout()

# 修改后：QTimer.singleShot(0, ...) 跳出定时器上下文
box.exec()
QTimer.singleShot(0, self._perform_expired_logout)
```

新增 `_perform_expired_logout` 方法：
```python
def _perform_expired_logout(self) -> None:
    self._do_logout()
```

#### 修复 B：`main_window.py.closeEvent` — 登出时接受关闭事件
```python
def closeEvent(self, event: QCloseEvent) -> None:
    if self._logout_in_flight:
        self._tray.hide()
        self._tray.deleteLater()
        event.accept()    # 登出 → 真正销毁窗口
        return
    event.ignore()        # 正常关闭 → 隐藏到托盘
    self.hide()
    ...
```

#### 修复 C：`main.py._on_logout` — 强制销毁旧窗口
```python
# 修改前：仅 hide + close
_main_window.hide()
_main_window.close()

# 修改后：设置标志 + 解绑 + close + deleteLater
_main_window._logout_in_flight = True    # 确保 closeEvent 走"接受"分支
_main_window.setParent(None)             # 解绑父子关系
_main_window.close()                     # closeEvent → accept
_main_window.deleteLater()               # Qt 延迟删除
```
