## 2. F40 媒体浮层子窗口化（issue #10，核心）

### 2.1 结构（实现后）

```
QMainWindow（WebShell）
└── QWebEngineView（页面）
    └── MediaOverlay.window = QWidget(view)     ← WA_NativeWindow（native 子控件）
        ├── QVideoWidget（视频/音频）
        └── QLabel（图片）
```

- `_build_window()`：`mode == child` 时取 `get_view()`（生产为 `_shell.view`）作父控件；
  `WA_NativeWindow` 是**关键属性**——普通 `QWidget` 子控件会被 QtWebEngine 的合成层盖住；
- 取不到 view（尚未就绪）或抛异常 ⇒ **自动回退** `mode = window` 并 `logger.warning`（F40.2：
  不得出现无法播放/无法关闭）；
- 几何：渲染层上报的 `rect` 是**相对视口**的 CSS 像素，子控件直接用
  `setGeometry(x, y, w, h)`；**不再 `mapToGlobal`**，也**不做 dpr 换算**（口径与 P0-4 实测一致）。

### 2.2 全屏 / 托盘 / 视口变化

| 场景 | 子控件模式（默认） | 顶层窗口模式（回退） |
|---|---|---|
| 进入全屏 | `setGeometry(0, 0, view.width(), view.height())` | `showFullScreen()`（v1.8.1 行为） |
| 退出全屏 | 按 `_rect` 重新贴合 | `showNormal()` + 按 `_rect` 重贴合 |
| 主窗移动 | 无需动作（Qt 父子关系自动跟随）；`moveEvent` 仍触发一次同值重贴合，服务全屏铺满尺寸 | `moveEvent → refresh_geometry → mapToGlobal` 重新定位 |
| 主窗隐藏到托盘 | 父窗隐藏 + 显式 `hide()`（避免恢复时闪旧位置）+ `_force_repaint()` | 同左（**必需**，顶层窗口不会随主窗隐藏） |
| 托盘恢复 | `WebShell.showEvent → refresh_geometry`，按 `_shell_hidden` 恢复（全屏/矩形两条路径） | 同左 |
| 视口尺寸变化 | `WebShell.eventFilter(view, Resize) → _schedule_overlay_refresh` | 同左 |

> 为什么**保留** `moveEvent/resizeEvent → _schedule_overlay_refresh`：回退模式（顶层窗口）
> 完全依赖它重新计算全局坐标；子控件模式下它是「一帧一次的廉价同值 setGeometry」，
> 且承担全屏铺满后的视口尺寸跟随。设计 §4.1.2 写的「可删除」属可选优化，本次按
> 「保留并降级为兜底」实现，避免回退路径失效。
>
> `_shell_hidden` 不变式（issue #3 / AC-12）完整保留：`setVisible(true)` / `setFullScreen(true)`
> 在隐藏期间只记意图；唯一例外 `open()`；恢复没真的发生则不消费标志（M-5）。

### 2.3 回退开关

| 写法 | 结果 |
|---|---|
| 不设置 `JFLOVE_MEDIA_OVERLAY` | `child`（默认） |
| `JFLOVE_MEDIA_OVERLAY=window`（大小写/空白容错） | `window`（v1.8.1 顶层窗口 + 全局坐标） |
| 其他取值（如 `top`） | 回落 `child` |
| 构造参数 `mode=` 显式传入 | **优先于**环境变量（测试/排障用） |

`state()` 桥返回里新增 `"mode": "child"|"window"`，渲染层无需感知（忽略即可），排障可见。

### 5.1 X11（Xvnc :99 + kwin_x11，当前源码 `ui/dist` 构建产物）

```bash
source scripts/verify/env.sh
DISP=$(jf_start_xvnc :99); jf_start_wm "$DISP"
DISPLAY=$DISP QT_QPA_PLATFORM=xcb QTWEBENGINE_CHROMIUM_FLAGS="--disable-gpu --no-sandbox" \
  jflove-desktop/venv-linux/bin/python scripts/verify/media_overlay_probe.py \
    --shell web --load-ui --json-out /tmp/jf40-x11-web.json --screenshot-prefix /tmp/jf40-x11-web
# → [probe] platform=xcb qt=6.11.0 shell=web mode=child ok=True checks=24 failed=0  (exit 0)
```

关键 JSON（`/tmp/jf40-x11-web.json`）：

| 断言 | 结果 |
|---|---|
| `child_parent_is_view` / `child_not_toplevel_window` | true / false（真正子控件，非顶层窗口） |
| `geometry_is_parent_relative` | `[60, 80, 360, 220]` == 上报矩形 |
| `global_follows_window_x11` | 主窗位移 `[200,120]` ↔ 浮层全局位移 `[200,120]` |
| `relative_geometry_unchanged_after_move` / `_resize` | 移动/缩放后相对几何不变 |
| `fullscreen_fills_view` / `fullscreen_stays_child` | `(0,0,1020,680)` == view；仍为子控件 |
| `exit_fullscreen_restores_rect` | 回到 `[60,80,360,220]` |
| `overlay_painted_on_screen` / `pixel_visible_before/after_move` / `old_position_repainted` | 中心像素 `#e53935`；旧位置恢复页面色 |

### 5.2 独立复核：外部 `ffmpeg x11grab` + 真实 `WebShell` 进程

为避免「探针自证」，另起一个进程把**生产 `MediaOverlay` 挂到真实 `WebShell`**，由外部 bash
用 `jf_capture`（ffmpeg x11grab）抓帧，再用像素分析判定（脚本 `/tmp/jf40_external_check.py`，
临时件不入库）：

```
PHASE before geometry (60, 80, 360, 220) global (120, 120) frame (60, 40, 900, 600)
PHASE after  geometry (60, 80, 360, 220) global (320, 240) frame (260, 160, 900, 600)

before: 主窗白底 bbox (60,40)-(958,638)；红色浮层 bbox (120,120)-(478,338)   # 窗原点 + (60,80)
after : 主窗白底 bbox (260,160)-(1158,758)；红色浮层 bbox (320,240)-(728,458) # 新窗原点 + (60,80)
```

位移 (200,120) 与主窗位移完全一致，且截图中浮层位于登录页（v1.8.2）内容**之上**。
截图：`/tmp/jf40-external-before.png`、`/tmp/jf40-external-after.png`。

> **踩坑记录（重要）**：Xvnc + llvmpipe 下窗口搬移/原生子窗口在**屏幕上生效**可能滞后 Qt 几何
> 更新数百毫秒（固定 `sleep 700ms` 曾抓到旧位置，被误判为「浮层没跟随」）。探针改为
> **轮询像素直到稳定（≤8s）**后再判定，未放宽任何断言。

### 5.4 Wayland（`kwin_wayland --virtual`，结构性判据）

```bash
dbus-run-session -- bash -c '
  kwin_wayland --virtual --socket jfwl42 --width 1440 --height 900 & sleep 2
  WAYLAND_DISPLAY=jfwl42 QT_QPA_PLATFORM=wayland ... media_overlay_probe.py \
    --json-out /tmp/jf40-wayland.json --screenshot-prefix /tmp/jf40-wayland'
# → [probe] platform=wayland qt=6.11.0 shell=plain mode=child ok=True checks=15 failed=0 (exit 0)
```

关键 JSON（`/tmp/jf40-wayland.json`）：

| 状态 | overlay_geometry | view_size | window_frame |
|---|---|---|---|
| before | `[60, 80, 360, 220]` | `[900, 600]` | `[0, 0]` |
| after_move | `[60, 80, 360, 220]` | `[900, 600]` | `[200, 120]` |
| after_resize | `[60, 80, 360, 220]` | `[1020, 680]` | `[200, 120]` |
| fullscreen | `[0, 0, 1020, 680]` | `[1020, 680]` | `[200, 120]` |

即：浮层是 `view` 的子控件（`overlay_parent_is_view=true`、`overlay_is_window=false`），
相对 geometry 恒定，全屏跟随 `view` 尺寸。**Wayland 无法用 `QScreen.grabWindow(0)` 抓屏**
（JSON 中 `screenshots.*.ok=false`），故本会话按需求口径只取结构性证据，不写「像素验证通过」。
