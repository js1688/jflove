## 二、根因分析

### 根因 1：持久化数据写在 PyInstaller 临时目录

[`settings.py`](jflove-desktop/src/config/settings.py:28-34) 在打包后 `BASE_DIR` 指向 `sys._MEIPASS`（`%TEMP%/_MEIxxxxx/`），程序退出后该目录被系统清理。因此：
- `storage/server_history.json` → 每次启动丢失
- `logs/` → 打包后日志文件丢失

### 根因 2：QSettings 存储在 Windows 注册表

[`auth_service.py`](jflove-desktop/src/services/auth_service.py:56-65) 使用 `QSettings(APP_ORG, APP_NAME)`，Windows 上写入 `HKCU\Software\JFLove\JFLove`，用户无法在文件系统中找到。

### 根因 3：键名不一致

[`main.py`](jflove-desktop/src/main.py:137) 读取 `"server_url"`，而 [`auth_service.py`](jflove-desktop/src/services/auth_service.py:26) 保存的键名是 `"session/server_url"`，导致永远读不到。

## 三、修复方案

### 3.1 存储位置：用户数据目录

| 平台 | 路径 |
|------|------|
| Windows | `%APPDATA%/JFLove/` → `C:\Users\<用户名>\AppData\Roaming\JFLove\` |
| Linux | `~/.local/share/JFLove/` |
| macOS | `~/Library/Application Support/JFLove/` |

### 3.2 文件结构

```
%APPDATA%/JFLove/
├── storage/
│   ├── session.json            # 会话信息（token、server_url、username 等）
│   └── server_history.json     # 服务端地址历史
└── logs/
    ├── app.log
    └── error.log
```

### 3.3 关键变更

| 模块 | 旧方案 | 新方案 |
|------|--------|--------|
| 会话持久化 | `QSettings`（注册表） | `session.json` 文件 |
| 地址历史 | `storage/server_history.json`（项目目录） | `%APPDATA%/JFLove/storage/server_history.json` |
| 日志 | `logs/`（项目目录） | `%APPDATA%/JFLove/logs/` |
| 资源文件 | `BASE_DIR/images/` | 不变（只读，可走 _MEIPASS） |

### 3.4 数据迁移

首次启动 v1.1.5 时自动执行一次性迁移：
1. 从旧 QSettings 迁移会话信息（token、server_url、username、role 等）
2. 从旧 `storage/server_history.json` 迁移地址历史
3. 迁移标记 `_migration_completed_v1_1_5` 写入 `session.json`，后续不再重复
