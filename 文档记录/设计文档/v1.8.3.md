> 阶段：Phase 2 ｜ 基线：`文档记录/需求文档/v1.8.3.md`（D21–D23）
> 范围：**仅 `jflove-app`**；服务端/桌面/Web 不动；无 DDL、无接口契约变更。

## 2. 相册备份活动状态机

```dart
enum AlbumBackupPhase { idle, checkingRemote, scanning, uploading }

class AlbumBackupActivity {
  final AlbumBackupPhase phase;
  final String message;      // 中文阶段文案
  final int processed;       // 本轮已处理资源数
  final int total;           // 本轮预计处理数（扫描时=min(总数, 2000)）
  final bool cancellable;
}
```

- **单一活跃流**：`albumBackupService.activityStream`（broadcast），页面 `StreamBuilder` 渲染；
- `scanAndUpload()`：
  1. 若已在跑 → 直接返回（按钮点击不会叠加）；
  2. `idle → checkingRemote`（启用远端比对时）→ `scanning`；
  3. 每处理 1 个资源更新 `processed`；提交上传时 `phase=uploading`（仍有扫描时保持 scanning，文案「扫描并上传」）；
  4. `finally` 复位 `idle`；`_cancelRequested` 置位时在循环边界退出并复位；
- `cancelScan()`：置 `_cancelRequested=true`；不取消已提交的传输任务（用户可在传输页取消）；
- `init()`：不直接扫描；`Future.delayed(2s, scanAndUpload)`，页面首帧显示 `idle`/「待检查」。

## 3. 上传哈希移入 isolate

### 3.1 现状问题

`TransferService._doUpload` 在主 isolate 上按 1MB 读文件并 `SHA256Digest.update`，大视频（数百 MB～GB）阻塞 UI；
同时每 1MB `_updateTask` 一次，高频 rebuild 放大卡顿。

### 3.2 目标实现

```dart
// 顶层函数（isolate 入口，不能捕获闭包）
void _hashFileWorker(List<Object> args) {
  final path = args[0] as String;
  final send = args[1] as SendPort;
  final file = File(path);
  final total = file.lengthSync();
  final raf = file.openSync();
  final digest = SHA256Digest();
  var done = 0;
  var lastReport = 0;
  try {
    while (done < total) {
      final chunk = raf.readSync(1 << 20);
      if (chunk.isEmpty) break;
      digest.update(chunk, 0, chunk.length);
      done += chunk.length;
      if (done - lastReport >= 16 << 20 || done == total) {
        send.send([done, total]);
        lastReport = done;
      }
    }
  } finally {
    raf.closeSync();
  }
  final out = Uint8List(digest.digestSize);
  digest.doFinal(out, 0);
  send.send(out.map((b) => b.toRadixString(16).padLeft(2, '0')).join());
}
```

- `_sha256FileWithProgress(path, onProgress)`：`Isolate.spawn` + `ReceivePort`，主 isolate 只接收 `[done,total]`（≥16MB 一次）与最终 hash；
- `_updateTask` 中 progress 只在 `percent` 变化 ≥1 或状态变化时 `_notify()`（节流）；
- 哈希失败/isolate 异常 → 任务 `failed`，中文「文件校验失败」；
- 哈希阶段文案「校验中」，进度条按哈希进度显示（0→100），进入上传阶段再重置。

### 3.3 视频文件名

`AlbumBackupService._handleAsset` 在拿到 `file` 后：

```dart
var filename = asset.filename;
if (!filename.contains('.')) {
  final ext = p.extension(file.path);
  if (ext.isNotEmpty) filename = '$filename$ext';
}
```

- `title` 为空 → `asset_<id><ext>`；
- 远端路径 `<root>/YYYY/MM/<filename>` 不变。

### 3.4 失败原因

| 场景 | 原因文案 |
|---|---|
| `entity.file` 抛异常 / null | 「视频/照片不在本地（可能仅在云端），无法上传」 |
| 大小 0 / 读取失败 | 「读取文件失败」 |
| 上传失败 | 服务端/网络中文错误 + 可重试 |
| 已取消 | 「已取消」 |

## 4. 最近上传与「查看已上传」

- `AlbumBackupStore.recentBackedUp({int limit = 20})`：
  `SELECT remote_path, size, backed_at FROM album_backup WHERE disk_id=? AND remote_root=? ORDER BY backed_at DESC LIMIT ?`；
- UI 展示文件名（`remote_path.split('/').last`）、大小、时间；
- 「在文件中查看」：`Navigator.push(DiskBrowserPage(diskId:..., initialPath: remoteRoot))`；
  - `DiskBrowserPage` 增加 `initialPath`（默认空），进入时 `_currentPath=initialPath` 并加载；
- 单条失败重试：`albumBackupService.retryOne(assetId)`（清失败记录 + 触发扫描）。

## 7. 风险

| # | 风险 | 应对 |
|---|---|---|
| R1 | isolate 在低端机内存不足 | 1MB 分块读取、只返回 hash；失败回退主 isolate（记录警告） |
| R2 | 相册页状态流频繁刷新 | 节流 4 次/秒；只 rebuild 状态卡 |
| R3 | `DiskBrowserPage` 初始路径不存在 | 回落到磁盘根并提示 |
| R4 | 大视频上传时间长 | 显示「大文件，上传较慢」；可取消；不阻止 |
| R5 | 用户设备 Android 版本差异 | 诊断信息含 SDK；UAT 覆盖 API 36 模拟器 + 用户真机 |


## 7. 远端索引修正（2026-10-25）

- 本地 SQLite v4 持久化 `album_remote_index / album_remote_meta`，保存目标根下全部目录的文件名/大小与建立时间；
- 建立时机：索引缺失、超过 10 分钟、手动检查；建立期间禁止上传，上传期间禁止重建；
- 判定：`dir + filename` 命中即跳过（不读本地文件流）；未命中（含远端删除）重新上传；
- 上传成功后增量 upsert；服务端不缓存、不新增接口。
