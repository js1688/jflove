## 3. 双主窗口 Bug 分析与修复方案

### 3.1 问题根因

当前流程：

```
MainWindow._token_timer timeout
  → _check_token_expiry()
    → MessageBox.exec()          # 弹窗阻塞等待用户确认
    → self._do_logout()
      → auth_service.logout()
      → self.logout_requested.emit()
        └→ main.py._on_logout()
          → _main_window.hide()      # ① 触发 closeEvent
          → _main_window.close()     # ② 再次触发 closeEvent
          → _main_window = None
          → _show_login_window()
```

`closeEvent` 中 `event.ignore()` + `self.hide()` 导致窗口并未销毁，仅隐藏到系统托盘中。

当用户再次登录成功，`_on_login_success` 创建新 `MainWindow` 时，**旧的 MainWindow 仍然存活于内存中（隐藏到托盘）**，两个窗口同时存在。

### 3.2 修复方案

**三步修复**：

#### 步骤 A：`MainWindow._check_token_expiry` — 延迟执行 logout

```python
def _check_token_expiry(self) -> None:
    if self._logout_in_flight:
        return
    effective = session_manager.effective_expire_at()
    if effective and time.time() >= effective:
        self._token_timer.stop()
        self._logout_in_flight = True
        box = MessageBox("登录已过期", "您的登录凭证已过期，请重新登录。", self)
        box.exec()
        # ★ 延迟执行 logout，跳出定时器回调上下文
        from PySide6.QtCore import QTimer
        QTimer.singleShot(0, self._perform_expired_logout)

def _perform_expired_logout(self) -> None:
    """
    在定时器上下文外用单独的 deferred 方法执行过期登出。
    
    QTimer.singleShot(0, ...) 将本调用推迟到当前事件循环迭代之后，
    确保 MessageBox 已完全关闭、MainWindow 可被安全销毁。
    """
    from src.services import auth_service
    auth_service.logout()
    self.logout_requested.emit()
```

#### 步骤 B：`MainWindow.closeEvent` — 登出时接受关闭事件

```python
def closeEvent(self, event: QCloseEvent) -> None:
    """拦截关闭事件，改为最小化到系统托盘（登出时例外）。"""
    if self._logout_in_flight:
        # 登出流程中：彻底关闭并销毁窗口，不接受"隐藏到托盘"
        self._tray.hide()          # 隐藏托盘图标
        self._tray.deleteLater()   # 清理托盘对象
        event.accept()
        return
    event.ignore()
    self.hide()
    self._tray.showMessage(...)
```

#### 步骤 C：`main.py._on_logout` — 强制销毁旧窗口

```python
def _on_logout() -> None:
    global _main_window
    if _main_window is not None:
        try:
            _main_window._logout_in_flight = True     # 确保 closeEvent 接受
            _main_window.setParent(None)               # 解绑父子关系
            _main_window.close()                       # 触发 closeEvent → 接受
            _main_window.deleteLater()                 # 标记为延迟删除
        except RuntimeError:
            pass
        _main_window = None
    _show_login_window()
```

#### 修复后流程：

```
MainWindow._token_timer timeout
  → _check_token_expiry()
    → MessageBox.exec()
    → QTimer.singleShot(0, _perform_expired_logout)  # ★ 跳出定时器上下文
      → auth_service.logout()
      → self.logout_requested.emit()
        └→ main.py._on_logout()
          → _main_window._logout_in_flight = True     # ★ 标记登出
          → _main_window.setParent(None)
          → _main_window.close()                      # ★ closeEvent 接受
          → _main_window.deleteLater()
          → _main_window = None
          → _show_login_window()
            → 登录成功
              → _on_login_success()
                → MainWindow.__init__()                # ★ 新窗口，无残留
```

## 8. 桌面端设计 — 双主窗口修复详情

### 8.1 修复范围

| 文件 | 修改点 |
|------|--------|
| `src/ui/main_window.py:167-190` | `_check_token_expiry` — MessageBox 后改用 `QTimer.singleShot(0, ...)` 延迟执行 logout |
| `src/ui/main_window.py:240-252` | `closeEvent` — 登出时接受关闭事件（`event.accept()`），不再隐藏到托盘 |
| `src/main.py:95-111` | `_on_logout` — 登出前设置 `_logout_in_flight = True`，强制 `setParent(None)` + `deleteLater()` |

### 8.2 互斥保护

现有 `_logout_in_flight` 互斥标志的语义不变。修复后：

- 设置页「退出登录」按钮 → `_on_logout_requested` → 检查 `_logout_in_flight` → 设置标志 → `_do_logout`
- Token 过期定时器 → `_check_token_expiry` → 设置标志 → MessageBox → `QTimer.singleShot(0, _perform_expired_logout)`
- 401 异常路径 → 已在 main.py 中通过 logout_requested 信号触发 → `_on_logout`

三者共享同一个 `_logout_in_flight` 互斥，保证整个进程内始终最多一次登出动作。

### 8.3 详细代码修改

#### `main_window.py` — `_check_token_expiry` 修改
