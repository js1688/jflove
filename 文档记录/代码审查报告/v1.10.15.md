## 4. 轻微问题与处置

| # | 问题 | 处置 |
| --- | --- | --- |
| L1 | 回退仍读取 paramiko 私有属性（`_preferred_pubkeys`、`server_extensions`、`_agreed_pubkey_algorithm`） | 依赖已 pin `paramiko==4.0.0`；`test_remote_legacy_ssh_v1_10_14/15` 作为升级门禁（已写进 README 已知边界） |
| L2 | 「部分认证」永远不放行的服务器会多消耗 1~2 次认证尝试 | 错误文案明确指向「两把私钥」；诊断行给出每步结果，避免用户继续误查 `authorized_keys` |
| L3 | 失败条完整换行后可能占两行高度 | 可接受：失败标签本来不自动关闭，用户需要看到原因；提供「复制详情」便于反馈 |
| L4 | `copyText` 依赖 `local_term.clipboard_write` 桥 | 与终端复制同一通路；桥不可用时 toast 提示「复制失败，可到日志中查看诊断」 |
