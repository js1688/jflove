## 1. 安全宪法逐条核查

| 条款 | 结论 | 证据 |
|---|---|---|
| §9.1 加密信封 | ✅ 合规 | `ssh_controller.py` 全部接口 `decrypt_request_body` + `encrypt_response`；无文件流接口 |
| §9.1 明文白名单未扩大 | ✅ | 未改 `_PLAIN_PATHS` |
| §9.3 JWT 只走 body | ✅ | `_ctx()` 从 `body["token"]` 读取，无 Authorization |
| §9.3 归属校验 | ✅ | 服务端所有查询带 `user_id`；`test_ssh_v1_10_0.py::test_other_user_cannot_read` 钉住（404） |
| §9.4 不暴露内容 | ✅ | 列表不带凭据；桥 `connections_get` 剥离 `password/private_key/passphrase`（`test_terminal_host_v1_10_0.py`） |
| §9.4 日志 | ✅ | 新代码日志只记方法名/阶段；未记录凭据（grep `password` 仅出现在字段处理，不在 logger 调用） |
| §9.5 加密原语 | ✅ | 未引入新算法；配置传输复用既有信封 |
| §9.6 渲染层无网络出口 | ✅ | 桌面端新增页面只走 `callBridge`；终端流是 `127.0.0.1` WebSocket（Python 侧发起） |
| §9.6 文件字节不进渲染层 | ✅ | SFTP 上传/下载全在 Python 侧；渲染层只传路径 |
| §9.7 新增长期密钥 | ✅ 无 | 未新增 |

**未发现可被伪造 ID 绕过的路由**：v1.10.0 全部接口为 POST + body 参数，无路径参数。
