## 问题列表

### 轻微

#### 1. `disk_browser_page.dart:56-70` — `_computeCanWrite()` 异步竞态

**描述**：`_computeCanWrite()` 通过 `accessibleDiskListProvider` 读取磁盘列表，若该 FutureProvider 尚未完成，`whenData` 回调不执行，函数返回 `false`（默认值），导致短暂显示"无写权限"。

**建议**：使用 `ref.watch` 替代 `ref.read` 在 build 中计算，确保 UI 随数据加载自动更新。当前实现可接受但不优雅。

```dart
// 建议改为在 build 中计算（但在 ConsumerStatefulWidget 的 build 中无法直接获取父 provider 的 AsyncValue）
// 当前实现在功能上正确，仅有时序问题；可在 build 方法中 watch accessibleDiskListProvider
```

**影响**：低。磁盘列表通常比页面渲染更快完成，用户感知不到。

#### 2. `move_target_dialog.dart:52-56` — `_isSrcOrChild()` 仅比较顶层路径

**描述**：`_isSrcOrChild()` 只比较 `srcRelPath` 和 `dirPath` 的顶层目录名。对于深层嵌套（如移动 `a/b/c/dir1` 到 `a/d`），只要顶层名 `a` 相同就会禁用目标，过于宽泛。

**建议**：改为比较 `dirPath` 是否为 `srcRelPath` 的前缀（即目标是否为被移动项的祖先）。

```dart
bool _isSrcOrChild(String dirPath) {
  if (widget.srcRelPath.isEmpty) return false;
  // 目标是被移动项的祖先（即目标是被移动项的前缀）
  return widget.srcRelPath.startsWith('$dirPath/') || widget.srcRelPath == dirPath;
}
```

**影响**：低。移动文件时不影响（文件无子目录）；移动目录时，后端也有路径合法性校验作为兜底。
