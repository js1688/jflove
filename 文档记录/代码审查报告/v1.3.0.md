## 总体评价

Web 端代码架构合理，分层清晰（utils → services → stores → hooks → pages），加密栈实现正确（nonce 长度、信封格式、帧格式、HKDF 盐值均与后端一致），API 字段名全部 snake_case 无泄漏。但发现 **3 个严重问题**（CORS 配置冲突、GET 请求不发送 body、PDF 绕过加密通道）和 **3 个中等问题**，均需修复后方可上线。

## 问题列表

### 严重 #1 — CORS `allow_credentials=True` 与 `allow_origins=["*"]` 冲突

- **文件**：`jflove-server/src/main.py:54-59`
- **违反**：CORS 规范 — 当 `Access-Control-Allow-Credentials: true` 时，`Access-Control-Allow-Origin` 不能为 `*`
- **影响**：浏览器**拒绝所有跨域请求**，Web 端完全无法工作
- **修复建议**：

```python
# ❌ 当前
allow_origins=["*"],
allow_credentials=True,

# ✅ 修复：JWT 走加密 body 不依赖 Cookie，无需 credentials
allow_origins=["*"],
allow_credentials=False,
```

---

### 严重 #2 — GET 请求不发送加密 body

- **文件**：`jflove-web/src/utils/http-client.ts:70`
- **违反**：设计文档 §5.2（所有加密请求统一走加密信封）、安全宪法 §9.1.4（GET 请求体也走加密 JSON）
- **影响**：**6 个受保护 GET 端点鉴权失败**（后端 `decrypt_request_body` 取不到 token）

| 端点 | 调用方 |
|------|--------|
| `GET /api/v1/files/disks` | file-service / file-store |
| `GET /api/v1/notes/list` | note-service |
| `GET /api/v1/disks/list` | disk-service |
| `GET /api/v1/users/list` | user-service |
| `GET /api/v1/permissions/list` | permission-service |
| `GET /api/v1/config` | config-service |

- **修复建议**：

```typescript
// ❌ 当前：GET 丢弃加密信封
body: method !== 'GET' ? envelope : undefined,

// ✅ 修复：所有方法均发送加密 body
body: envelope,
```

---

### 严重 #3 — FilePreviewPage PDF 预览绕过加密通道

- **文件**：`jflove-web/src/pages/FilePreviewPage.tsx:79-83`
- **违反**：安全宪法 §9.1.2（文件传输也走端到端加密）、§9.6 web-frontend 行（流式响应通过 stream-frame 解密）
- **影响**：PDF 预览使用裸 `<iframe src="/api/v1/files/stream">`，不带 token、不加密、不走 http-client
- **修复建议**：标记 PDF 为不支持预览并引导下载，或通过 http-client 下载流→解密→Blob URL→iframe

---

### 中等 #4 — RequireAuth 绕过 session 模块

- **文件**：`jflove-web/src/config/routes.tsx:29-36`
- **违反**：设计文档 §2.2（路由守卫应使用 `useAuthStore`）
- **影响**：直接读 `localStorage`，不检查 token 过期、不检查加密状态，与 session 模块脱节
- **修复建议**：使用 `useAuthStore().isLoggedIn` + `isTokenExpired()`

## 审查结论

**不予通过。** 3 个严重问题必须在 Phase 6（测试）之前修复：

1. **CORS `allow_credentials` 改 `False`**（jflove-server/src/main.py）
2. **GET 请求发 body**（jflove-web/src/utils/http-client.ts）
3. **PDF 预览走加密通道或降级为不支持**（jflove-web/src/pages/FilePreviewPage.tsx）

建议修复后重新审查再进入测试阶段。
