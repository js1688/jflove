## 7. 诚实登记（判据强度不足 / 未取证之处）

1. **AC-82①的"滚动到变化处"没有像素级判据**：单测只能断言"未挂载/无变化"这类可观测信号，
   真机 `r22.M4` 读的是**提示文案**；"变化行确实进了视口"这一条**没有独立几何判据**（建议下版补
   `getBoundingClientRect()` 级别的读数）。
2. **AC-92⑨的性能目标（10 标签 / ~1 MB / ≤ 200 ms）无稳定计时判据**（开发记录 U-4）。
3. **AC-95④的"磁盘文件字节零改动"是用"范围外标签页正文逐字符不变 + 本版不新增任何写盘路径"推出来的**，
   不是直接对磁盘文件取 `sha256`（判据强度弱于字面要求）。
4. **跨组同键提示（AC-97④）只有 jsdom 组件用例**，无真机视觉确认（开发记录 U-6）。
5. **本报告的审查者与实现者是同一轮工作**：为降低"自证"风险，本报告**只采信可复现的命令读数**
   （退出码 / 探针 JSON / grep 计数），不采信任何"我认为"的表述；§5 的两条变异与三条真机探针是独立于实现叙事的证据。
