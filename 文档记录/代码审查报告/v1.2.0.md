## 问题列表

### 严重（0 项）

无严重问题。

### 中等（1 项）

#### M1. RemoteDirBrowserPage 和 MoveTargetPage 未实现

- **文件**：[`disk_browser_page.dart`](jflove-app/lib/pages/files/disk_browser_page.dart:263)
- **描述**：「移动到…」功能当前使用 Snackbar 提示"待实现"，设计文档中要求的 RemoteDirBrowserPage 和 MoveTargetPage 全屏页面未实现
- **影响**：用户无法在移动端执行文件移动操作
- **建议**：后续迭代实现目录选择页面，桌面端对标 `MoveTargetDialog` 和 `_RemoteDirBrowserDialog`

### 轻微（4 项）

#### W1. `app.dart` 多处使用 `__` 替代 `_`

- **文件**：[`app.dart`](jflove-app/lib/app.dart:45-93)
- **问题**：9 处使用了 `__`（双下划线）作为未使用参数名，标准做法为 `_`
- **建议**：替换为 `_`

#### W2. `login_page.dart` 已废弃的 `value` 参数

- **文件**：[`login_page.dart`](jflove-app/lib/pages/login/login_page.dart:130)
- **问题**：`Autocomplete` 的 `value` 参数已在 Flutter 3.33+ 废弃，应使用 `initialValue`
- **建议**：替换为 `initialValue`

#### W3. `crypto.dart` 不必要的 cast

- **文件**：[`crypto.dart`](jflove-app/lib/utils/crypto.dart:144)
- **问题**：`x as Uint8List` 是多余的（类型已匹配）
- **建议**：移除 cast

#### W4. `http_service.dart` 未使用的 `dart:typed_data` import

- **文件**：[`http_service.dart`](jflove-app/lib/utils/http_service.dart:2)
- **问题**：`dart:typed_data` 的所有元素已通过 `package:flutter/foundation.dart` 提供
- **建议**：移除该 import
