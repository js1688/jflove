## 2. 关键判据核查

| 判据 | 结论 | 证据 |
| --- | --- | --- |
| 私钥字节不回渲染层 | **通过** | `pick_private_key` 只返回 `token/name/size/encrypted/fingerprint`；内容留在 Python `_pending_private_keys` |
| 错误文案不回显完整路径 | **通过** | 路径错误只回文件名与查找范围（`ssh_session.py:_read_private_key_text`）；安全宪法 §9.13 |
| 连接配置只存内容 | **通过** | `_resolve_private_key_payload` 拒绝无 `BEGIN`/PPK 标记的字段值；token 保存后即清 |
| 双因素两种顺序 | **通过** | 假 transport 单测覆盖 `publickey→password`、`password→publickey`、密钥失败回退密码、只认密钥时不试密码 |
| 私钥格式兼容 | **通过** | BOM / 缩进 / 单行 / 字面量 `\n` / CRLF / PKCS#8 / Ed25519 / 加密口令均有单测 |
| Qt.Edge 位值契约 | **通过** | `titlebar-edge-v1-10-11.test.ts` 锁死 Top=1/Left=2/Right=4/Bottom=8 |
| 无新增网络出口 | **通过** | 渲染层仍只走 `callBridge`；桥没有新出网路径 |
| 无数据库 DDL | **通过** | `auth_type` 为 TEXT 无约束；`private_key` 列长度 64KB 上限不变 |

## 3. 安全宪法逐条（§9）

- §9.1/§9.5 加密：**未改动** HTTP/流式加密原语；新桥方法只在进程内传递数据。
- §9.3 鉴权：连接配置接口沿用原有 JWT/归属校验，未新增路由。
- §9.4 不暴露内容：私钥内容不出 Python 进程；错误文案不含完整路径/密钥片段。
- §9.6 渲染层硬约束：选文件由 Python 读取，渲染层只拿 token；文件内容随保存请求进入服务端数据库
  （与用户裁决 D37 一致：服务端明文列存储）。
- §9.7 新功能自查：无新 URL 参数、无新长期密钥、无新加密算法。

## 4. 轻微项（不阻塞）

| # | 位置 | 问题 | 处置 |
| --- | --- | --- | --- |
| L1 | `bridge/remote.py::_pending_private_keys` | 用户选文件后取消表单，内容会留到进程退出（上限 16 条） | 仅内存、无落盘；后续可加表单卸载清理 |
| L2 | `ssh_session.py::_resolve_private_key_path` | 仍保留旧路径兼容解析 | 有意为之：存量配置不破坏；新保存不再写路径（文档已注明） |
| L3 | `.ppk` | 仍不支持解析（v3 加密需要 Argon2 依赖），只提示改用原始 PEM / 导出 OpenSSH | 用户已确认持有原始 `BEGIN RSA PRIVATE KEY`；错误发生在保存前而非连接时 |
| L4 | `RemoteConnectionForm.tsx` | 若已保存口令、只改口令不改私钥，服务端不会更新口令（既有语义） | 需重新选择私钥文件；后续可加「仅改口令」路径 |
