### 2.4 已核查判定无问题

- **契约**：对照 `winpty/_winpty.pyi` 与 pywinpty 3.1.2 `src/lib.rs`
  （`spawn(appname, cmdline=None, cwd=None, env=None) -> bool`，`env` 为 `name=value` 以 `\0` 分隔、`None`=继承），
  改动后的调用全对齐；`write(str)` 亦符合 stub。
- **`_winpty_cwd()`**：`expandvars → abspath → isdir 校验 → 回退 ~`，绝不把空串交给 CreateProcess。
- **`--add-data` 目标路径**：`pywinpty` wheel 内就是 `winpty/OpenConsole.exe`、`winpty/winpty-agent.exe`；
  父 agent 另用同版本 `pyinstaller==6.20.0` 在 `/tmp/pi-probe` 实测 `--add-data <f>:winpty`
  落点 = `<dist>/<name>/_internal/winpty/<f>`，与门禁判据一致。
- **§9 安全宪法**：不经网络、不碰加密/鉴权/明文白名单；新增日志只含 shell 路径 / args / cwd，
  不含 token / 密码 / 文件内容 ⇒ 无违反。
