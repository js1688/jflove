## 四、风险与应对

| 风险 | 等级 | 应对 |
|------|------|------|
| 修复开关开启时旧客户端（未适配版本）收到 time 流不兼容 | 高 | 声明机制：仅请求携带 `range_start_seconds` 才走 time；旧客户端一律 byte 零回归（已实测） |
| 桌面/移动 time 模式 seek 为平均码率线性近似 | 中 | 恒定码率精确、变码率有偏差；HEAD 不声明字节 seek，播放器顺序流式播放；已记录取舍 |
| 移动端无法本机真机验证 | 中 | analyze 0 + 单测 27 + 与服务端同构的桌面端链路验证；发布后用户真机反馈 |
| 本机无 Docker | 低 | 按用户指示本次不发布后端/Web（不打镜像），发布记录中标注环境未就绪，下次发布 |
| HEVC 健康文件 MSE 回退 Blob | 低 | 行为合理（本地可解码播放），已记录遗留说明 |
