## 与上一版本差异

v1.2.0 是首次新增移动端模块。对比 v1.1.6（桌面端）：
- 新增 Android 客户端（Flutter + Dart + Riverpod）
- 加密实现从 Python cryptography 切换为 Dart pointycastle + x25519
- 14 个页面 + 11 个 Service + 6 个 Provider + 5 个 Widget
- 22 个测试用例覆盖加密/模型/Widget/帧解析
