## 3. 风险

| 风险 | 影响 | 处置 |
| --- | --- | --- |
| Windows 多显示器混合 DPI 无法在本机 KVM 单屏复现 | 下拉问题的「原现象」不能被机器证伪 | 已做结构性消除（不再使用原生 select）；证据写「未覆盖（原因）」，需用户真机复验 |
| paramiko 认证状态机重写可能影响简单密码/密钥场景 | 已有认证连接不可用 | 旧用例全部保留（29 条）+ 真实 paramiko 测试服务覆盖简单密钥、密钥→密码、密钥→keyboard-interactive、密码→密钥 |
| SFTP 操作默认 45s 可能误杀超大目录 | 慢目录被判超时 | 加载中显示已用秒数；`JFLOVE_SFTP_OP_TIMEOUT` 可调；失败后可重试 |
| 清空凭据后连接失败 | 用户清错 | 表单显示「保存后清空」；认证方式的必填校验仍在新建时生效，编辑态允许清空但连接时会给出原因 |
| 本机 sshd 冒烟缺测试密钥 | 缺少一条真实 sshd 证据 | 未擅自修改 `~/.ssh/authorized_keys`；用本地 paramiko 真实 SSH/SFTP 服务用例替代，报告中写「未覆盖（原因）」 |
| 单版本改动面较大 | 回归范围广 | 全量 desktop/server pytest + UI vitest + lint/build 已跑；发布前补审查/测试报告 |
