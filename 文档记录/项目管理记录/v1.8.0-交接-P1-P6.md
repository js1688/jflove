## 4. 硬约束（继续做时必须遵守）

1. **安全宪法 §9**：新接口全加密信封；明文白名单仍 3 条；不新增算法/长期密钥。
2. **D9**：默认目录按账号隔离；必须是该账号有 write 权限的磁盘；无可写磁盘接口拒绝。
3. **D10**：任务/修复/下载记录按账号隔离；列表与详情带 `user_id`；他人 ID 一律 **404**。
4. **I-7**：音视频分离必须合并成一条可下载项，产物必须有声。
5. **出站收敛**：只有 `outbound_http` 直接出网；ffmpeg/ffprobe 只读本地并带
   `-protocol_whitelist file,crypto`；yt-dlp 走策略代理。
6. **I-6**：解析器随版本升级，禁止运行时在线自更新。
7. **版本号**：`version.json` 唯一真相，只走 `python scripts/sync_version.py`。
8. **验证规则（本轮新增，必须遵守）**：
   - 先 `source scripts/verify/env.sh`，再按 `scripts/verify/README.md` + `lessons` L48–L57 探测；
   - **实机验证只用当前版本构建产物**；禁止历史 Release/缓存 zip/旧 APK；
   - `windows_wine.sh` 默认 `VERSION=v1.7.0`，必须显式当前版本；当前包无法构建就写**阻塞**；
   - 跳过必须附真实探测输出，不能拿默认 `PATH` 的 `which` 结果当环境缺失。
9. 临时计划不入库；受控文档不得引用临时计划路径。
