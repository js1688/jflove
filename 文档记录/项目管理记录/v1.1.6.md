# v1.1.6 项目管理记录

## 一、版本目标与范围概述

**版本目标**：将同步配置从服务端存储迁移到客户端本地 JSON 文件管理，使不同客户端可独立配置自己的同步目录、自动同步开关等偏好。

**范围**：

| 模块 | 变更 |
|------|------|
| **jflove-server** | 移除 `sync_configs` 表及全部 CRUD 接口；新增 `POST /api/v1/sync/snapshot`（直接传 `disk_id`+`remote_path`）；移除 `touch` 接口 |
| **jflove-desktop** | `sync_service.py` 全本地 JSON 存储；`sync_engine.py` 适配 str ID + 新 snapshot API |

**版本策略**：小版本迭代（MINOR），服务端 + 桌面端同步升级（breaking change）。
