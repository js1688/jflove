## 1. 日志给出的决定性事实

```text
Server offered these authentication methods: publickey,password
Offer of public key accepted
Server offered these authentication methods: password
Prompt (password, "SSH password", ...)
Sent password
Access granted
```

- 会话配置 `Password: No, Key file: Yes`（**没有预存密码**）却仍被要求密码 → 说明「弹框索取」是标准行为；
- 第二因子就是 **`password` 方法**，全程**没有** `keyboard-interactive`；
- 因此 v1.10.16/18 里「服务器没列 kbd 也发一次」的兜底属于**发送未列出的方法**（不合规），已删除。
