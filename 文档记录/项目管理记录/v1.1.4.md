# v1.1.4 项目管理记录

## 一、版本目标与范围概述

**版本目标**：聚焦三类问题——缺陷修复（rename/move 404 语义 + 双主窗口 Bug）、本地缓存修复（服务端地址历史持久化）、体验优化（TTL 按天选择）。

**范围**：

| 模块 | 变更 |
|------|------|
| **jflove-server** | rename/move 路径不存在→404；JWT 最大有效期 8h→30d；默认 TTL 1h→1d |
| **jflove-desktop** | 双主窗口 Bug 修复；服务端地址历史持久化；TTL 按天选择；rename/move 404 错误提示；笔记目录配置展示修正 |

**版本策略**：补丁版本（PATCH），服务端 + 桌面端双端同步升级。
