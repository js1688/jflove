# v1.1.0 项目管理记录

## 一、版本目标与范围概述

**版本目标**：在保持 v1.0 全部已有功能不变的前提下，新增流式预览能力，解决大文件（视频/音频/日志）预览等待时间过长、预览过程写本地临时文件的问题。

**范围**：
- 服务端新增 `GET /api/v1/files/stream` 接口（Range 支持 + v2 帧加密协议）
- 桌面端新增 `StreamProxy`（本地 HTTP 代理）+ `StreamTextLoader`（文本流加载器）
- 桌面端 `PreviewDialog` 改造：视频/音频/文本改为流式；图片/SVG/Markdown 保持 v1.0
- 不引入新依赖，不变更数据库结构

**版本策略**：硬升级，服务端与桌面端需同步更新。
