## 2. 表结构

- `ssh_groups(id, user_id, name, sort_order, created_at, updated_at, deleted_at)`
- `ssh_connections(...)` 含 `password` / `private_key` / `passphrase` / `init_command` / `host_key_fingerprint`
- 索引 4 个：`ssh_groups_user_id_idx`、`ssh_connections_user_id_idx`、`ssh_connections_group_id_idx`、`ssh_connections_jump_idx`
- **无列级 UNIQUE**（软删除会让名字永久占用）；分组重名由服务层校验（409）

## 3. 接口

`/api/v1/ssh/` 下 11 个 POST 接口（全部加密信封、`token` 在 body）：

`groups/{list,create,update,delete}`、`connections/{list,get,create,update,delete,duplicate,touch}`。

- `list` 不返回凭据，只有 `has_password` / `has_private_key`
- `get` 返回全量（客户端直连需要）+ `private_key_fingerprint`
- `update` 凭据空串 = 不修改；`clear_password` / `clear_private_key` 显式清空
- 保存时校验：端口 1–65535、`init_command` 单行 ≤1024、跳板环（16 级上限）
- 删除被引用连接 → 409

## 5. 已知限制

- 凭据按 D37 明文列存储（用户裁决，信任模型=服务端不可攻破），本版不做静态加密。
- 服务端不校验 SSH 主机可达性（`test connection` 由客户端做）。
- `charset` 仅存档，编码转换在客户端终端层处理。
