# v1.1.6 后端开发记录：同步配置客户端本地化存储

## 一、变更概述

v1.1.6 的核心目标是**服务端完全移除 sync_configs 表及相关 CRUD 接口**，同步配置由客户端本地 JSON 文件管理。不同客户端的同步配置相互独立、互不影响。

### 变更范围

| 方向 | 变更类型 | 说明 |
|------|---------|------|
| 服务端 | **移除** | `sync_configs` 表及相关索引 |
| 服务端 | **移除** | `sync_config_repository.py`（整个文件） |
| 服务端 | **精简** | `sync_service.py`：移除 CRUD + touch，仅保留 `_safe_join` + `list_remote_snapshot` |
| 服务端 | **重构** | `sync_controller.py`：6 个路由 → 1 个路由（`POST /api/v1/sync/snapshot`） |
| 服务端 | **修改** | `database.py`：移除建表语句，新增 DROP TABLE 运行时迁移 |
| 服务端 | **修改** | `main.py`：版本号 1.1.4 → 1.1.6 |
| 服务端 | **修改** | `build.py`：版本号 1.1.4 → 1.1.6 |
| 测试 | **修改** | `test_security_e2e.py`：移除 sync_configs CRUD 相关测试，替换为 snapshot 测试 + 旧接口 404 测试 |

## 二、移除的接口（6 个 → 1 个）

| 旧接口 | 去向 | 说明 |
|---|---|---|
| `GET /api/v1/sync/configs` | ❌ 移除 | 客户端从本地 JSON 读取 |
| `POST /api/v1/sync/configs` | ❌ 移除 | 客户端本地创建，不再需要服务端 |
| `PUT /api/v1/sync/configs/{id}` | ❌ 移除 | 客户端本地编辑 |
| `DELETE /api/v1/sync/configs/{id}` | ❌ 移除 | 客户端本地删除 |
| `GET /api/v1/sync/configs/{id}/snapshot` | ❌ 移除 | 替换为 `POST /api/v1/sync/snapshot` |
| `POST /api/v1/sync/configs/{id}/touch` | ❌ 移除 | `last_synced_at` 改为客户端本地记录 |

### 新增接口：`POST /api/v1/sync/snapshot`

**用途**：递归扫描指定虚拟磁盘子目录，返回文件清单供客户端 diff。

```json
// 请求体（加密前）
{"token": "<JWT>", "disk_id": 1, "remote_path": "alice_notes"}

// 响应体（加密前）
{"files": [{"path": "doc.txt", "size": 1024, "modified_at": 1716300000.0}]}
```

| 条件 | 状态码 |
|---|---|
| 正常返回 | 200 |
| disk_id 不存在 | 400 |
| 无读权限 | 403 |
| JWT 无效/缺失 | 401 |

## 三、涉及文件与改动详情

### 3.1 `database.py` — 数据库表结构

- 移除 `_CREATE_SYNC_CONFIGS` SQL 语句
- 移除 `sync_configs_user_id_idx` 索引定义
- 在 `init_db()` 中添加运行时迁移：检测旧表存在则 DROP TABLE + DROP INDEX
- 新增 `get_logger` 导入用于运行日志

```python
# 运行时迁移（v1.1.6）
async with db.execute(
    "SELECT name FROM sqlite_master"
    " WHERE type='table' AND name='sync_configs'"
) as cur:
    exists = await cur.fetchone()
if exists:
    await db.execute("DROP TABLE IF EXISTS sync_configs")
    await db.execute("DROP INDEX IF EXISTS sync_configs_user_id_idx")
    logger.info("运行时迁移：已删除 sync_configs 表（v1.1.6）")
```

### 3.2 `sync_config_repository.py` — 移除

整个文件替换为注释说明，不再提供服务端存储层。

### 3.3 `sync_service.py` — 精简

**移除的函数**：
- `_row_to_dict`（不再需要，无 sync_configs 行数据）
- `list_user_configs`（客户端本地管理配置列表）
- `get_user_config`（同上）
- `_validate_disk_access`（快照权限校验直接内联到 `list_remote_snapshot`）
- `create_config`（客户端本地创建）
- `update_config`（客户端本地编辑）
- `delete_config`（客户端本地删除）
- `touch_synced`（客户端本地记录 `last_synced_at`）

**保留并修改的函数**：
- `_safe_join`——不变，仍用于路径越界防护
- `list_remote_snapshot`——签名从 `(db, user_id, role, config_id)` 改为 `(db, user_id, role, disk_id, remote_path)`

```python
# 新签名
async def list_remote_snapshot(
    db: aiosqlite.Connection,
    user_id: int,
    role: str,
    disk_id: int,
    remote_path: str = "",
) -> list[dict]:
```

新实现不再通过 `sync_config_repository` 查 config，而是直接查磁盘：
1. 通过 `virtual_disk_repository.find_by_id` 获取磁盘真实路径
2. 调用 `_safe_join` 做路径越界防护
3. 通过 `check_disk_permission` 校验读权限（admin 免检）
4. 递归扫描返回文件清单

### 3.4 `sync_controller.py` — 重构

**旧结构**（6 个路由）：
- `GET /configs` — 列出配置
- `POST /configs` — 创建配置
- `PUT /configs/{id}` — 更新配置
- `DELETE /configs/{id}` — 删除配置
- `GET /configs/{id}/snapshot` — 远端快照
- `POST /configs/{id}/touch` — 标记同步完成

**新结构**（1 个路由）：
- `POST /snapshot` — 获取远端目录快照

所有业务参数（`disk_id`、`remote_path`）都从加密 body 中读取，路由路径上无参数，彻底消除 URL 枚举风险。
