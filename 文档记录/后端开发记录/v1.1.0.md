## 二、新增接口：`GET /api/v1/files/stream`

### 2.1 接口信息

| 项 | 值 |
|---|---|
| 路径 | `GET /api/v1/files/stream` |
| 鉴权 | 加密信封 + JWT（`body["token"]`） |
| 协议版本 | `X-Encrypted-Stream: v2` |
| 响应类型 | `application/octet-stream`（帧序列） |

### 2.2 请求体字段（解密后 JSON）

| 字段 | 类型 | 说明 |
|---|---|---|
| `token` | string | JWT 令牌 |
| `disk_id` | int | 虚拟磁盘 ID |
| `path` | string | 文件所在目录（磁盘内相对路径） |
| `filename` | string | 文件名 |
| `range_start` | int | 字节起点（0=开头；负数=从末尾倒数） |
| `range_end` | int | 字节终点，不含（-1=文件结尾） |

### 2.3 响应帧格式

帧格式与 v1 完全相同：`[4B 大端长度][12B nonce][ChaCha20-Poly1305 密文+16B tag]`

帧内容：
- **帧 0（元数据帧）**：明文为 JSON
  ```json
  {
    "type": "meta",
    "file_size": <文件总字节数>,
    "range_start": <有效起点>,
    "range_end": <有效终点>,
    "content_type": "<MIME 类型>"
  }
  ```
- **帧 1..N（数据帧）**：每帧最大 64KB 原始文件字节

### 2.4 错误帧（文件中途被删除）

若文件在传输中途被 `FileNotFoundError`，生成器发送错误帧后结束：
```json
{"type": "error", "code": "FILE_NOT_FOUND", "message": "文件不存在或已被删除"}
```

## 三、修改文件详情

### 3.1 `src/services/file_service.py`

新增 `import mimetypes`。

新增 `get_stream_range()` 函数（约 50 行）：

```
get_stream_range(db, user_id, role, disk_id, path, filename, range_start, range_end)
  → tuple[str, int, int, int, str]   # (file_path, eff_start, eff_end, file_size, content_type)
```

**关键逻辑：**

1. 权限校验：`check_disk_permission(db, user_id, disk_id, "read")`（admin 跳过）
2. 路径安全：`os.path.join(path.lstrip("/"), filename)` 拼接后整体传入 `_safe_join`，防止分别传入绕过校验
3. Range 规范化：
   ```python
   eff_start = range_start if range_start >= 0 else max(0, file_size + range_start)
   eff_end   = range_end   if range_end   >= 0 else file_size
   eff_start = max(0, min(eff_start, file_size))
   eff_end   = max(eff_start, min(eff_end, file_size))
   ```
4. MIME 类型：`mimetypes.guess_type(filename)`，无法识别时返回 `application/octet-stream`

### 3.2 `src/controllers/file_controller.py`

新增 `import json`（顶部）。

新增 `_build_range_stream_generator()` 同步生成器（约 40 行）：
- 参数：`(file_path, session_key, file_size, eff_start, eff_end, content_type)`
- 先 yield 元数据帧，再 `open(file_path, "rb") → seek(eff_start) → 逐块 read → yield 加密帧`
- `FileNotFoundError` 捕获后 yield 错误帧

新增 `stream_file()` 路由（约 40 行）：
- 参数解析：`disk_id / path / filename / range_start / range_end`
- `filename` 为空时 raise 400
- 调用 `file_service.get_stream_range()` 拿文件信息
- `auth_service.get_session_key()` 取会话密钥
- 日志仅记录 `disk_id / file_size / range`，**不记录 path 和 filename**
- 返回 `StreamingResponse(..., headers={"X-Encrypted-Stream": "v2"})`
