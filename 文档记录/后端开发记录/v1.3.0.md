# v1.3.0 后端开发记录：添加 CORS 中间件

## 一、变更概述

v1.3.0 后端仅一处变更：添加 `CORSMiddleware` 以支持浏览器端 Web 应用跨域请求。

| 文件 | 变更类型 | 说明 |
|------|---------|------|
| `src/main.py` | 修改 | 添加 `CORSMiddleware`（+2 行 import，+6 行配置） |

---

## 二、详细变更

### 2.1 `src/main.py`

**新增 import**：

```python
from fastapi.middleware.cors import CORSMiddleware
```

**新增中间件配置**（在 `app = FastAPI(...)` 之后、`app.include_router(...)` 之前）：

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

---

## 三、变更说明

| 问题 | 根因 | 修复 |
|------|------|------|
| 浏览器报 `Access to fetch ... blocked by CORS policy` | FastAPI 默认不返回 CORS 头，浏览器拦截跨域请求 | 添加 `CORSMiddleware` 全局中间件 |

浏览器同源策略要求：当 `http://localhost:3000`（Web 端）向 `http://server.jflove.cn:8989`（后端）发请求时，后端必须返回 `Access-Control-Allow-Origin` 响应头。`CORSMiddleware` 自动为所有请求添加该头。
