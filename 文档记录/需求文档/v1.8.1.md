# JFLove v1.8.1 需求文档 —— 移动端离线下载补全 + 进度条口径 + 目录选择器

> **本版本是「体验补全 + BUG 修复」小版本**，不新增服务端业务能力（仅新增一个管理员只读目录浏览接口）。
> **范围**：`jflove-app`（离线下载从只读补成完整功能）、`jflove-desktop`（进度条 BUG + 目录选择器）、
> `jflove-web`（进度条同口径 + 目录选择器）、`jflove-server`（管理员服务器目录浏览接口）。
> **数据库**：无表结构变更，不需要 `migrate-1.8.1.sql`。
> 编写角色：product（Phase 1，`AGENTS.md §7.3`）。前序基线：`文档记录/需求文档/v1.8.0.md`。

## 1. 版本概述

### 1.1 一句话定位

**v1.8.1 把移动端补成真正的「离线下载客户端」，让所有需要填目录 / 文件的地方都能点选，并修正桌面端「已完成却不满格」的进度显示。**

### 1.2 与上一版本（v1.8.0）的差异

| 维度 | v1.8.0 | v1.8.1 |
|---|---|---|
| 移动端离线下载 | 只读列表 / 详情 / 进度 | **完整**：新建、分析、勾选、默认目录、开始、取消、重试、删除记录、追加图片页 |
| 移动端默认目录 | 只能去桌面 / Web 配 | 移动端可配置，服务端账号级存储，三端一致 |
| 添加磁盘 | 三端手输服务端路径 | **选择器**：管理员浏览服务器目录；保留手动输入兜底 |
| 移动端相册备份远端目录 | 手写子目录 | **目录选择器**（磁盘 + 目录） |
| 桌面端成功任务进度条 | 可能 99% | **成功一律 100%** |
| Web 端成功任务进度条 | 字节/项数为 0 时才 100% | **成功一律 100%**（同口径） |
| 服务端接口 | 离线下载 10 接口 | **新增 1 个管理员只读接口**：服务器目录浏览 |
| 数据库 | 3 张离线下载表 | **无变更** |

### 1.3 版本号、范围与命名

- 版本号：**1.8.1**（唯一真相 `version.json`）。
- 范围：`jflove-server`（仅新增只读目录接口）+ 桌面 + Web + 移动端。
- 命名：界面仍统一称「离线下载」；移动端新建入口称「新建任务」；目录选择器称「浏览… / 选择目录」。

### 1.4 范围边界（明确不做）

| 不做 | 原因 |
|---|---|
| 服务端新增离线下载业务能力 / 新解析器 | 本版只补客户端与选择器；解析能力沿用 v1.8.0 |
| 移动端本地文件系统目录选择（SAF 选任意本机目录） | 移动端没有「本地缓存目录」配置；上传走系统文件选择器即可 |
| 网页端选择用户本机目录 | 浏览器安全模型不允许；Web 只做远端目录选择 |
| 服务端目录浏览返回文件名 / 文件内容 / 文件大小 | D14 只列目录；避免不必要的信息暴露 |
| 收藏 / 批量播放列表下载 / 转码 / 直播 | 沿用 v1.8.0 §1.4 |
| 修改 v1.8.0 已发布的数据库结构 | 无结构变更 |

## 2. 目标用户与核心场景

### 2.1 目标用户

- 手机用户：希望**只带手机**也能贴链接、选清晰度、下到自己的磁盘，不必先找电脑。
- 管理员：添加磁盘时不想记服务端绝对路径，想从目录树里点选。
- 普通用户：配置相册备份 / 离线目录时，希望点选而不是背相对路径。

### 2.2 核心场景

**场景 A（手机建任务）**：手机上打开「离线下载中心」→「新建任务」→ 粘贴公开视频页 → 分析出 1080P / 720P / 封面 →
勾选 1080P → 目标目录预填自己的默认目录（可改）→ 开始下载 → 返回任务列表看进度；桌面端 2.5 秒内出现同一任务。

**场景 B（手机首次使用，未配目录）**：进入离线下载 → 提示「尚未设置默认目录」→ 点「去设置」→ 选磁盘 + 目录（可自动创建）→ 保存 →
回到新建页，分析按钮可用。

**场景 C（手机管理任务）**：任务下载中可以取消；失败 / 取消后可重试；终态可删除记录（磁盘文件保留）；图片清单可「追加下一页」。

**场景 D（管理员添加磁盘）**：桌面 / Web / 手机进入「磁盘管理」→「添加磁盘」→ 点「浏览…」→ 从 `/` 或 `/storage` 开始逐级进入 →
选中 `/storage/media` → 路径回填 → 填名称 → 创建成功。非管理员调用该浏览接口一律 403。

**场景 E（相册备份目录）**：移动端设置 → 相册自动备份 → 远端目标目录 → 选磁盘 → 点「选择目录」逐级进入 →
选 `手机相册/2026` → 确定。

**场景 F（桌面进度条）**：任务状态「已完成」，进度条铺满、显示 100%；即使 `bytes_done < bytes_total` 也不回落。

## 3. 功能需求

### 3.1 F32 移动端离线下载完整功能（**本版核心**）

**F32.1 入口**：离线下载中心页提供「新建任务」入口；设置页「离线下载」入口可进入任务中心。

**F32.2 新建流程**：
1. 输入网页地址（仅 `http/https`，前端做基本校验，最终以服务端为准）；
2. 点「分析」→ 创建分析任务 → 每 2.5 秒轮询详情，直到 `ready` / `failed` / `canceled`；
3. `ready` 后展示清单：类型、名称、分辨率、时长、大小（估算值带「约」）；
4. 勾选：支持单条勾选、全选、只要音频、只要图片、只要最高清；
5. 目标目录：磁盘下拉（仅当前账号可写磁盘）+ 目录选择器；默认预填账号默认目录，可临时改（不回写默认）；
6. 可选「打包为 zip」；
7. 点「开始下载」→ 成功后返回任务列表并刷新。

**F32.3 任务操作**：
- `queued/analyzing/downloading/merging`：可取消；
- `failed/canceled` 且错误类型可重试：可重试；
- 终态 / `ready`：可删除记录（不删磁盘文件）；
- `ready`：可「去选择」继续勾选；
- 详情展示清单项、失败原因、建议动作（中文）。

**F32.4 默认目录**：移动端可配置 / 清除自己的默认目录；保存后立即生效，桌面 / Web 同账号可见同一份。

**F32.5 图片追加**：详情页当 `has_more_images=true` 时提供「追加下一页」，成功后刷新清单。

**F32.6 无可用条件**：总开关关闭、无可写磁盘、未配置目录、目录失效时，新建入口给出对应中文说明；
未配置 / 失效时提供「去设置」，不发起分析请求。

### 3.2 F33 进度条终态口径（BUG 修复）

**F33.1** 任务 `status=success` 时，桌面端与 Web 端进度条必须为 100%，不得按 `bytes_done/bytes_total` 或项数回退。

**F33.2** 下载中 / 合并中仍按字节优先、项数次之；失败 / 取消保持现有显示。

### 3.3 F34 目录 / 文件输入选择器（**全盘审计**）

**F34.1 原则**：凡需要用户提供「目录」或「文件路径」的字段，必须提供选择器；文本框可作为可选兜底，
但**不能是唯一入口**。文件名、搜索词、URL 不属于本条。

**F34.2 审计与处理**：

| # | 端 | 位置 | 字段 | 现状 | v1.8.1 处理 |
|---|---|---|---|---|---|
| 1 | 桌面 | 磁盘管理 | 服务端真实路径 | 文本框 | 新增服务器目录选择器 |
| 2 | Web | 磁盘管理 | 服务端真实路径 | 文本框 | 新增服务器目录选择器 |
| 3 | 移动 | 磁盘管理 | 服务端真实路径 | 文本框 | 新增服务器目录选择器 |
| 4 | 桌面 | 云盘挂载 | 远端子目录 | 文本框 + 选择 | 保持，复核 |
| 5 | 桌面 | 云盘挂载 | 本地缓存目录 | 文本框 + 系统目录对话框 | 保持，复核 |
| 6 | 桌面 | 设置 | 笔记目录 | 目录树弹窗 | 保持，复核 |
| 7 | Web | 设置 | 笔记目录 | 目录树弹窗 | 保持，复核 |
| 8 | 移动 | 设置 | 笔记目录 | 磁盘 + 目录浏览 | 保持，复核 |
| 9 | 桌面 | 离线下载 | 默认目录 / 任务目录 | 文本框 + 目录树 | 保持，复核 |
| 10 | Web | 离线下载 | 默认目录 / 任务目录 | 文本框 + 目录树 | 保持，复核 |
| 11 | 移动 | 相册备份 | 远端目标目录 | 磁盘下拉 + 手写子目录 | **改为目录选择器** |
| 12 | 移动 | 离线下载 | 任务目录 / 默认目录 | 本版新增 | **直接使用选择器** |
| 13 | 三端 | 上传 / 打开 / 保存文件 | 文件 | 系统原生选择器 / `<input type=file>` | 保持，复核 |
| 14 | 三端 | 笔记新建 / 重命名 | 文件名（非路径） | 文本框 | 保持（不在本条范围） |

**F34.3 服务器目录选择器**：
- 添加 / 编辑磁盘时，可从「根 / 常见根目录（/、/storage、/data、用户目录；Windows 盘符）」开始浏览；
- 支持上级、根目录、roots 快捷入口、逐级进入、选中当前目录；
- 只展示目录，不展示文件；隐藏目录（`.` 开头）不展示；
- 保留手动输入作为兜底（服务器路径可能不在常见 roots 下）。

### 3.4 F35 管理员服务器目录浏览（**新增只读接口**）

**F35.1** 新增管理员接口，返回指定绝对路径下的子目录列表、当前路径、父路径与常见 roots。

**F35.2** 仅管理员可调用；普通用户 / 未登录一律拒绝。

**F35.3** 只返回目录名与绝对路径；不返回文件名、文件内容、文件大小。

**F35.4** 请求 / 响应走加密信封；路径不出现在 URL 明文；错误文案不回显完整路径。

## 4. 非功能需求（体验层面）

- 移动端新建流程分步呈现，避免一屏塞满；分析中给出明确进度与「取消」。
- 所有失败必须有中文原因与下一步建议，不能只显示错误码。
- 目录选择器打开时定位到当前值（添加磁盘默认 roots 第一项；编辑磁盘定位到当前路径）。
- 进度条、状态徽标、目录选择器的加载 / 空 / 错误态齐全。
- 移动端轮询在页面不可见时停止；返回前台立即刷新一次。

## 5. 交互流程

### 5.1 移动端新建任务

```
任务中心 → 新建任务 → 输入 URL → 分析
  ├─ 失败：中文原因 + 重试 / 换地址
  └─ ready：清单 + 快捷选择 + 目标目录（默认预填）+ 打包 zip
        → 开始下载 → 返回任务中心（刷新，任务由服务端排队）
```

### 5.2 移动端默认目录

```
任务中心 / 新建页 → 设置 → 磁盘下拉（仅可写）→ 选择目录 → 自动创建开关 → 保存
  └─ 无可写磁盘：整块禁用 + 中文说明
```

### 5.3 添加磁盘（三端）

```
磁盘管理 → 添加/编辑 → 浏览… → 服务器目录选择器（roots/上级/进入）→ 选中 → 回填路径 → 保存
```

### 5.4 进度条

```
任务 status=success → 进度条 100%
任务 downloading/merging → 字节优先；无字节则项数
```

## 6. 关键决策与最终裁决

| 决策点 | 最终结论 | 推翻过程摘要 | 原因 |
|---|---|---|---|
| 移动端是否只读 | **完整功能** | v1.8.0 §1.4 / F27.5 / AC-231 定为只读；2026-10-22 用户明确要求补全，D12 推翻 | 手机是主要入口，只读导致必须找电脑才能建任务 |
| 目录输入方式 | **选择器为必备，文本框可兜底** | 原先多处只有文本框 | 手输绝对路径易错、体验差 |
| 服务器目录浏览 | **新增管理员只读接口** | 原只有虚拟磁盘内浏览 | 添加磁盘时磁盘尚未存在，无法复用旧接口 |
| 进度条成功口径 | **success 一律 100%** | 桌面按字节算，成功任务可能 99% | 状态已完成却不满格是明显矛盾；移动端口径正确 |
| 版本号 | **1.8.1** | 用户指定 | 小版本修复 + 体验补全 |

### 6.1 硬不变量

1. **I-1**：移动端所有 HTTP 仍走 `http_service.dart` 加密信封；token / session_key 不进日志。
2. **I-2**：服务器目录浏览接口仅管理员；只列目录，不读文件；路径不进 URL 明文。
3. **I-3**：离线下载任务仍按账号隔离（v1.8.0 D10 不变）；移动端不新增跨账号可见能力。
4. **I-4**：默认目录仍须受磁盘写权限约束；移动端下拉只展示服务端下发的可写磁盘。
5. **I-5**：v1.8.0 的 SSRF / 出站抓取约束不变；本版不新增出站能力。
6. **I-6**：不引入新的加密算法 / 密钥 / KDF。
7. **I-7**：progress 的 success 优先是产品口径，不得以「字节更精确」为由改回。

## 7. 验收标准（AC-248 ~ AC-270）

### 7.1 移动端离线下载

| AC | 判据 |
|---|---|
| **AC-248** | 移动端任务中心存在「新建任务」入口；输入公开 URL → 分析 → `ready` 后展示清单；勾选 + 选择目标目录 + 开始下载成功，任务出现在列表 |
| **AC-249** | 移动端可保存 / 清除自己的默认目录；保存后桌面 / Web 同账号在 2.5s 内看到同一配置；无写权限磁盘不出现在下拉 |
| **AC-250** | 移动端可取消进行中任务、重试可重试的失败任务、删除终态记录；失败态显示中文原因与建议 |

## 8. 安全宪法对齐（`AGENTS.md §9`）

| 条款 | 本版落点 |
|---|---|
| §9.1 加密信封 | 移动端新增写接口全部走 `http_service`；服务器目录接口走加密 query 信封 |
| §9.3 鉴权 | 服务器目录接口 admin-only；JWT 只从加密 body 读取；离线任务仍按 token 归属 |
| §9.4 不暴露内容 | 服务器目录接口只返回目录；错误不回显完整路径；日志不记录完整路径 |
| §9.5 加密原语 | 不新增算法；复用现有信封 |
| §9.6 角色约束 | 桌面渲染层无网络出口；移动端 token 不进日志；Web 不把 token 放 DOM |
