# JFLove v1.3.0 需求文档

## 0. 背景说明

v1.3.0 是 jflove-web 浏览器端模块的**首个版本**。此前系统已有服务端（jflove-server）、桌面客户端（jflove-desktop）和移动客户端（jflove-app）。本版本新增浏览器端 Web 应用，功能上**对标桌面端全部模块**。Web 端作为第四个客户端接入现有服务端。

**后端变更**：仅添加 CORS 中间件以允许浏览器跨域请求（`fastapi.middleware.cors.CORSMiddleware`），不涉及 API 接口、数据库、加密协议的任何改动。

**不包含的范围**：本版本桌面端/移动端不做任何更改。

---

## 1. 项目概述

### 1.1 目标

为用户提供浏览器端访问 JFLove 私有文档与笔记系统的能力。功能上与桌面端完全对等，交互上支持 PC 端浏览器（大屏）和移动端浏览器（小屏）双布局自适应。

### 1.2 与桌面端的差异

| 维度 | 桌面端（PySide6） | Web 端（React + TypeScript） |
|------|------------------|---------------------------|
| 平台 | Windows / Linux / macOS 原生 | 任意现代浏览器（Chrome/Firefox/Safari/Edge） |
| 交互 | 鼠标+键盘，原生窗口 | PC 端：鼠标+键盘；移动端：触屏 |
| 导航 | 侧边栏常驻（8 项） | **PC 端**：侧边栏常驻；**移动端**：底部 TabBar（5 Tab） |
| 文件管理 | 树形目录 + 表格视图 | PC 端：表格视图 + 面包屑；移动端：列表视图 + 面包屑 |
| Markdown 编辑 | 三分栏（列表+编辑/预览+大纲） | 两栏（列表+编辑/预览切换）+ 大纲侧边抽屉 |
| 传输任务 | 独立「传输任务」页面 | 独立「传输任务」页面（PC 侧边栏入口 / 移动端 Tab 入口） |
| 安全状态 | 独立「安全状态」页面 | 独立页面（PC 侧边栏入口 / 移动端设置页内卡片） |
| 同步 | 本地文件系统 ↔ 服务端双向 | **浏览器不支持本地文件系统同步**（见 §2.5 说明） |
| 文件上传 | 系统文件选择器 → 分片上传 | `<input type="file">` 或拖拽 → 分片上传 |
| 文件下载 | 保存到本地文件系统 | 浏览器下载（`<a download>` + 内存流式解密） |
| 安全存储 | JSON 文件（用户数据目录） | `sessionStorage`（session_key）+ `localStorage`（token/用户偏好） |
| 文件预览 | QWebEngineView 弹窗 | 浏览器原生能力（`<video>`/`<audio>`/`<img>`/Mermaid.js 等） |
| 管理面板 | 侧边栏独立入口 | PC 端侧边栏独立入口；移动端底部 Tab 内子路由 |

### 1.3 核心原则

- **加密协议不变**：与桌面端完全相同的 X25519 ECDH + ChaCha20-Poly1305 加密栈
- **API 不变**：后端接口零改动，Web 端作为新客户端接入
- **UI 一致性**：现代极简设计，PC 端对标桌面端 Fluent Design 风格，移动端对标移动端 Material Design 风格
- **离线不可用**：Web 端不支持离线模式，所有操作需联网
- **同步降级**：浏览器端不支持本地文件系统同步（见 §2.5），同步页面仅做展示说明

## 2. 功能需求

### 2.1 登录与认证（Auth）

对标桌面端 [`login_window.py`](../../jflove-desktop/src/ui/login_window.py)。

| 功能 | 说明 |
|------|------|
| 服务端地址输入 | 输入服务器地址，支持历史记录下拉（localStorage 持久化，最多 10 条） |
| 密钥交换 | X25519 ECDH 临时密钥交换（Web Crypto API），HKDF-SHA256 派生 session_key |
| 管理员初始化 | 首次连接时若系统无管理员，引导创建管理员账号 |
| 用户登录 | 用户名+密码登录，JWT token 经加密 body 传递 |
| Token 有效期 | 1天 / 7天 / 30天 可选（下拉选择，默认 30 天） |
| 登录状态持久化 | 重启浏览器后自动恢复登录态（token 在 localStorage，session_key 重新密钥交换） |
| 登出 | 清除 token + session_key + 同步配置缓存，返回登录页 |
| Token 过期检测 | 路由切换时检查 token 是否过期；定时器定时检查；过期自动弹窗并跳转登录页 |
| ECDH 静默续约 | 401（会话过期类）自动重新密钥交换并重发请求，用户无感知 |
| 单登录保护 | 同一浏览器标签页内只允许一个登录会话 |

**AC-1**: 用户可从登录页输入服务器地址 → 密钥交换 → 管理员检测 → 登录 → 进入主页，全程加密通信。支持服务器历史记录选择。

**AC-2**: Token 过期后自动弹出提示并跳转登录页，不会出现"白屏"或"无限 loading"。

**AC-3**: 服务端重启后（session_key 丢失），Web 端 401 自动静默续约并重发请求，用户无感知。

### 2.2 文件管理（Files）

对标桌面端 [`file_page.py`](../../jflove-desktop/src/ui/pages/file_page.py) + [`transfer_page.py`](../../jflove-desktop/src/ui/pages/transfer_page.py)。

| 功能 | 说明 |
|------|------|
| 磁盘列表 | 展示用户有权访问的虚拟磁盘（下拉选择器） |
| 文件浏览 | 进入磁盘后以表格（PC）/ 列表（移动端）展示目录和文件（图标 + 名称 + 大小 + 修改时间） |
| 目录导航 | 路径面包屑 + 返回上级按钮 |
| 排序 | 支持按名称/大小/修改时间排序，升序/降序切换 |
| 创建目录 | 输入目录名，在当前路径下创建 |
| 重命名 | 右键菜单（PC）/ 长按弹出菜单（移动端）→ 重命名（弹窗输入新名称） |
| 移动到… | 右键菜单 / 长按菜单 → 移动到…（弹出目录树选择器，支持懒加载子目录，不可选当前目录及子目录） |
| 删除 | 右键菜单 / 长按菜单 → 删除（确认弹窗） |
| 文件上传 | 按钮触发（PC 端支持拖拽上传），支持多文件，分片加密上传（1MB/片），显示进度 |
| 文件下载 | 右键菜单 / 长按菜单 → 下载，浏览器下载，显示下载进度 |
| 文件预览 | 点击文件名进入预览（全屏弹窗/新页面） |
| 写权限控制 | 无写权限时隐藏重命名/移动/删除/上传/新建目录操作入口（通过 `can_write` 字段判断） |

**文件预览类型**（对标桌面端 [`preview_dialog.py`](../../jflove-desktop/src/components/preview_dialog.py)）：

| 文件类型 | 预览方式 |
|---------|---------|
| 图片（jpg/jpeg/png/gif/webp/bmp/svg） | `<img>` 标签渲染，支持放大缩小 |
| 视频（mp4/webm/ogg） | `<video>` 标签，流式零缓存播放（通过 service worker 本地代理或直接流式 URL） |
| 音频（mp3/wav/flac/aac/ogg） | `<audio>` 标签，流式播放 |
| Markdown（.md） | 渲染为 HTML（marked.js + highlight.js + Mermaid.js），支持代码高亮和图表 |
| 纯文本（.txt/.json/.xml/.yaml/.csv 等） | `<pre>` 标签展示，代码高亮 |
| PDF | `<iframe>` 或 `<embed>` 标签内嵌预览 |
| 其他 | 不支持预览，提示下载 |

**AC-4**: 用户可浏览磁盘 → 进入子目录 → 上传文件 → 预览 → 下载，全程加密。

**AC-5**: 无写权限用户无法看到重命名/移动/删除/新建目录/上传按钮。

**AC-6**: 文件拖拽上传可用（PC 端），多文件同时上传各自显示独立进度。

### 2.5 同步管理（Sync）

> **重要说明**：浏览器端由于安全沙箱限制，**不支持**桌面端/移动端的本地文件系统双向同步功能。同步管理页面将做以下适配：

| 功能 | 说明 |
|------|------|
| 功能说明 | 顶部公告卡片说明：浏览器端不支持本地文件同步，请使用桌面端或移动端进行文件同步 |
| 同步配置列表（只读） | 如后端有同步配置 API，展示用户已有的同步配置及上次同步时间 |
| 跳转引导 | 引导用户下载桌面端或移动端进行文件同步 |

**设计决策**：浏览器无法访问本地文件系统做双向增量同步（无文件监听、无后台常驻），因此同步页面不做完整的同步功能，仅做信息展示和引导。

**AC-11**: 同步管理页面展示功能说明和引导，用户清楚浏览器端的局限性。

## 3. 非功能需求

### 3.1 性能

| 指标 | 目标 |
|------|------|
| 首屏加载（登录页） | < 2s（3G 网络） |
| 文件列表加载（100 项） | < 1s |
| 大文件上传（1GB） | 分片加密上传，不阻塞 UI |
| 视频流式播放 | 首帧 < 3s |

### 3.2 兼容性

| 浏览器 | 最低版本 |
|--------|---------|
| Chrome | 90+ |
| Firefox | 90+ |
| Safari | 15+ |
| Edge | 90+ |

> 需要 Web Crypto API（`SubtleCrypto`）支持 X25519，以上版本均支持。

### 3.3 安全性

- 严格遵循 `AGENTS.md §9` 安全宪法
- session_key 仅存 `sessionStorage`（标签页关闭即清除）
- JWT token 可存 `localStorage`（用户偏好持久化）
- 禁止在 URL 参数中携带任何业务数据
- 禁止 `console.log` 输出 token / session_key / 文件内容
- 生产构建 source map 不泄露源代码路径
