> 版本：**1.8.3**（补丁位）｜ 阶段：Phase 1 ｜ 角色：product
> 基线：`文档记录/需求文档/v1.8.2.md`。本版**只改移动端**（`jflove-app`），服务端/桌面/Web 不改。

## 1. 目标

| 目标 | 用户可感知结果 |
|---|---|
| G1 一级入口 | 底部 6 个入口，离线下载 / 相册同步不用再进设置页找 |
| G2 相册同步独立页 | 一页看清：总数/已备份/失败/不在范围/上传中、当前阶段与进度、可取消 |
| G3 不再卡死 | 大视频上传时 UI 仍可操作（滚动/切页/取消）；启动不因扫描卡住 |

| G5 可诊断 | 提供「复制诊断信息」（版本/机型/阶段/失败原因/视频大小），用户能贴给开发 |

## 2. 功能需求

### 2.1 F42 底部导航（6 入口）

- 顺序：**文件 / 笔记 / 传输任务 / 离线下载 / 相册同步 / 设置**；
- 离线下载、相册同步为独立路由页，位于同一 `ShellRoute`，底部栏常驻；
- 现有设置页里的「离线下载」「相册自动同步」入口保留为快捷入口（不重复实现页面）。

### 2.2 F43 相册同步页

- 顶部状态卡：总数 / 已备份 / 上传中 / 失败 / 不在范围 / 远端已存在跳过；
- **当前活动**：`空闲 / 正在核对远端 / 正在扫描 / 正在上传`，带进度（已处理/总数）与「停止」按钮；
- 操作区：立即检查 / 重试失败项 / 重新核对远端 / 在文件中查看 / 最近上传；
- 失败项列表：文件名、大小、中文原因、单条重试；
- 范围与目标：图片/视频开关、仅 Wi-Fi/仅充电、远端目标目录（沿用现有）；
- 「查看已上传」：打开文件页并定位到 `<磁盘>/<相册目标根>`；「最近上传」列出最近 20 条（路径/大小/时间）。

### 2.3 F44 上传可靠性 / 卡死修复

- **哈希隔离**：上传前 SHA256 计算移入后台 isolate，主 isolate 只接收节流后的进度（每 2% 或 16MB）；
- **进度节流**：上传/哈希进度刷新不超过约 4 次/秒，避免高频 rebuild；
- **扫描可取消**：核对/扫描/上传提交阶段可通过「停止」取消；取消后不再提交新任务；
- **启动不阻塞**：`init()` 不在首帧同步做大扫描；延迟到首帧后 2s，且页面显示「待检查」/「正在扫描」；
- **视频文件名**：`asset.title` 为空或无扩展名时，用本地文件扩展名补全，避免远端出现 `asset_<id>` 无后缀文件；
- **失败可见**：`entity.file` 返回 null/异常、大小 0、上传失败分别给出中文原因（含「可能仅在云端」）；
- **大文件提示**：单文件 > 300MB 时在任务上标注「大文件，上传较慢」，不阻止上传。

### 2.4 F45 诊断信息

- 「复制诊断信息」输出：版本、平台、当前阶段、计数、失败项（文件名脱敏为 `***.<ext>`？**不**——用户主动复制给开发，保留文件名；但日志仍不写路径）、视频大小；
- 不自动上传任何诊断数据。

## 3. 范围边界

| 不做 | 原因 |
|---|---|
| 服务端改动 | 本版纯客户端；上传接口契约不变 |
| 云端/仅在线视频下载到本地 | 平台能力限制，明确报原因 |
| 相册备份改后台 Service/WorkManager | 现有前台服务机制不变，仅优化主 isolate |
| 桌面/Web 改动 | 不在本版范围 |

## 4. 验收标准（AC-301～AC-315）

| AC | 判据 |
|---|---|
| **AC-301** | 底部导航 6 项，顺序为 文件/笔记/传输任务/离线下载/相册同步/设置；点亮状态与路由一致 |
| **AC-302** | 相册页「同步明细」按图片/视频分开展示：各含总数、已同步、待同步；另有待备份/上传中/失败/不在范围/远端跳过/等待索引计数 |
| **AC-303** | 点「重新核对远端」立即出现「正在核对/扫描」状态，可点「停止」；停止后不再新增上传任务 |
| **AC-304** | 选择 ≥500MB 视频触发上传：哈希阶段 UI 仍可滚动/切页；进度有更新；无 ANR/卡死 |
| **AC-305** | 「在文件中查看已上传」打开相册目标目录并能看到文件（含扩展名）；上传明细在「传输任务」查看（1.8.3 起移除相册页最近列表） |
| **AC-306** | `title` 为空/无扩展名的视频，远端文件名带正确扩展名 |
| **AC-307** | 视频仅云端/无本地文件：失败原因含「仅在云端/不可用」，不再静默 |
| **AC-308** | 失败项支持单条重试；重试后计数变化 |
| **AC-309** | 启动 App 首帧不被相册扫描阻塞；相册页可见「正在扫描」或「空闲」 |
| **AC-310** | 相册页移除诊断按钮；全局诊断页登记为下个版本候选 C10（`文档记录/项目管理记录/v1.8.2.md` §8） |
| **AC-311** | 1.8.2 已发布功能回归：离线下载新建/分析/下载/取消；文件/笔记/传输/设置可用 |
| **AC-312** | `dart analyze lib/` 零错误；`flutter test` 全通过；新增相册/导航用例 |
| **AC-313** | 模拟器实机：安装启动、进入 6 个入口、相册页截图、大视频上传不卡死 |
| **AC-314** | 版本 9 处 = 1.8.3（versionCode 1008003） |
| **AC-315** | 无服务端 DDL / 接口变更；安全宪法 §9 不降级 |
