# JFLove v1.2.0 需求文档

## 0. 背景说明

v1.2.0 是 jflove-app 移动端模块的 **首个版本**。此前系统仅有服务端（jflove-server）和桌面客户端（jflove-desktop）。本版本新增 Android 移动客户端，功能上**对标桌面端全部模块**，后端 API 已就绪无需变更，移动端作为第三个客户端接入现有服务端。

**不包含的范围**：iOS / 鸿蒙 / Web（均预留接口，条件成熟后启用）。

---

## 1. 项目概述

### 1.1 目标

为用户提供 Android 手机端访问 JFLove 私有文档与笔记系统的能力。功能上与桌面端对等，交互上适配触屏操作。

### 1.2 与桌面端的差异

| 维度 | 桌面端 | 移动端（v1.2.0） |
|------|--------|-----------------|
| 平台 | Windows / Linux / macOS | Android only |
| 交互 | 鼠标+键盘，大屏（≥900px） | 触屏，小屏（360-480dp） |
| 导航 | 侧边栏常驻（8 项） | 底部导航栏 5 Tab（首页/文件/笔记/同步/设置） |
| 文件管理 | 树形目录 + 表格视图 | 列表视图 + 滑动操作 + 路径面包屑 |
| Markdown 编辑 | 三分栏（列表+编辑/预览+大纲） | 全屏编辑，切换预览，大纲底部抽屉 |
| 传输任务 | 独立「传输任务」页面 | 首页任务浮窗 + 文件页内联进度条 |
| 安全状态 | 独立「安全状态」页面 | 合并到设置页 |
| 同步 | 本地文件系统 ↔ 服务端双向 | App 内部存储 ↔ 服务端双向 |
| 安全存储 | JSON 文件（用户数据目录） | Android Keystore（flutter_secure_storage） |
| 文件预览 | 弹窗式（PreviewDialog） | 全屏沉浸式预览 |
| 管理面板 | 侧边栏独立入口 | 设置页内入口（仅 admin 可见） |

### 1.3 核心原则

- **加密协议不变**：与桌面端完全相同的 X25519 ECDH + ChaCha20-Poly1305 加密栈
- **API 不变**：后端接口零改动，移动端作为新客户端接入
- **UI 一致性**：Material Design 3，与桌面端 Fluent Design 风格统一
- **离线不可用**：移动端不支持离线模式，所有操作需联网
- **双向同步**：移动端同步与桌面端对齐，支持 App 内部存储 ↔ 服务端双向同步

## 2. 功能需求

### 2.1 登录与注册（Auth）

对标桌面端 [`login_window.py`](../../jflove-desktop/src/ui/login_window.py)。

| 功能 | 说明 |
|------|------|
| 服务器地址输入 | 输入服务器地址，支持历史记录下拉（复用桌面端 server_history.json 格式） |
| 密钥交换 | X25519 ECDH 临时密钥交换，派生 session_key |
| 管理员初始化 | 首次连接时若系统无管理员，引导创建管理员账号 |
| 用户登录 | 用户名+密码登录，JWT token 存储于 Android Keystore |
| Token 有效期 | 1天 / 7天 / 30天 可选（下拉选择） |
| 登录状态持久化 | 重启 App 自动恢复登录态（token 有效期内） |
| 登出 | 清除 token + session_key + 同步配置缓存，返回登录页 |
| Token 过期检测 | 每次路由切换时检查 token 是否过期，过期自动跳转登录页 |

**AC-1**: 用户可从登录页输入服务器地址→密钥交换→管理员检测→登录→进入首页，全程加密通信。支持服务器历史记录选择。

**AC-2**: token 过期后自动弹出提示并跳转登录页，不会出现"白屏"或"无限 loading"。

| 功能 | 说明 |

| 移动到… | 长按文件/目录 → 弹出菜单 → 移动到…（弹出目录选择器，支持懒加载子目录） |
| 删除 | 长按文件/目录 → 弹出菜单 → 删除（确认弹窗） |
| 文件上传 | FAB 按钮触发，支持从相册/文件管理器选择文件，分片加密上传 |
| 文件下载 | 长按文件 → 下载，选择本地存储路径，显示下载进度 |
| 文件预览 | 点击文件进入全屏预览 |
| 流式预览 | 大文本文件逐帧加载，视频/音频流式零缓存播放 |
| 传输进度 | 文件列表页底部显示进行中的传输任务进度条 |
| 写权限控制 | 无写权限时隐藏重命名/移动/删除/上传/新建目录操作入口 |

**文件预览类型**（对标 [`preview_dialog.py`](../../jflove-desktop/src/components/preview_dialog.py)）：

| 文件类型 | 预览方式 |
|---------|---------|
| 图片（jpg/png/gif/webp/bmp） | 全屏看图，支持双指缩放、滑动切换 |
| SVG | 渲染显示 |
| 视频（mp4/mkv/webm） | 流式播放（video_player），不缓存完整文件 |
| 音频（mp3/wav/flac/aac） | 后台播放 + 通知栏控制 |
| Markdown（.md） | Markdown 渲染显示（代码高亮 + Mermaid 图表） |
| 纯文本（.txt/.json/.xml 等） | 代码高亮只读显示 |
| 其他 | 不支持预览，提示下载 |

**AC-4**: 用户可浏览磁盘→进入子目录→上传图片→长按文件预览→下载到本地，全程加密。

**AC-5**: 无写权限用户无法看到重命名/移动/删除/新建目录/上传按钮。

### 2.5 同步管理（Sync）

对标桌面端 [`sync_page.py`](../../jflove-desktop/src/ui/pages/sync_page.py)。

**双向同步**：移动端与桌面端对齐，支持 App 内部存储 ↔ 服务端双向同步。

| 功能 | 说明 |
|------|------|
| 同步配置列表 | 展示本地 `sync_configs.json` 中的配置（卡片列表） |
| 新建配置 | 创建同步配置：名称、本地目录（App 内部存储路径）、远端磁盘+子目录（浏览选择）、自动同步开关、同步间隔 |
| 编辑配置 | 修改已有配置的任意字段 |
| 删除配置 | 确认后删除映射关系（不删除实际文件） |
| 远端目录浏览 | 选择磁盘后浏览远端子目录（双击进入），类似桌面端 `_RemoteDirBrowserDialog` |
| 本地目录选择 | 使用文件选择器选择 App 内部存储目录 |
| 手动同步 | 每行配置的「立即同步」按钮 |
| 自动同步 | 可配置间隔（最小 30 秒），后台定时执行 |
| 同步状态 | 实时显示：空闲 / 正在同步… / 完成 ↑n ↓m ⏭k / 失败信息 |
| 同步规则 | 本地有远端无→上传；本地无远端有→下载；两边都有按修改时间取新者；不自动删除 |

**AC-8**: 用户可创建同步配置→选择远端目录→手动同步→查看同步结果（上传/下载/跳过数量）。

**AC-9**: 自动同步按配置间隔执行，手机照片目录自动备份到服务端。

## 3. 非功能需求

### 3.1 安全性

- 全部遵守 [AGENTS.md §9 安全宪法](../../AGENTS.md#9-安全宪法强制条款不可降级)
- 加密原语：pointycastle 纯 Dart，X25519 + ChaCha20-Poly1305 + HKDF-SHA256
- session_key 仅存内存，不落盘
- JWT token 存 Android Keystore（flutter_secure_storage）
- 调试日志禁止输出 session_key / token / 密码

### 3.2 性能

- 大文件加解密使用 Isolate，不阻塞 UI 线程
- 流式响应使用异步 Stream 逐帧解析
- 图片预览使用缓存策略（cached_network_image）
- 文件列表分页加载（每页 50 条）

### 3.3 兼容性

- 最低 Android 7.0（API 24）
- 目标 Android 14（API 34）
- 屏幕适配：360dp ~ 480dp 宽度

### 3.4 用户体验

- 加载状态：所有网络请求显示 loading 指示器
- 错误处理：网络异常/超时/服务端错误以 Snackbar 友好提示
- 空状态：列表为空时显示引导文案
- 暗黑模式：跟随系统设置
- 下拉刷新：列表页支持下拉刷新
- 滑动操作：列表项支持左右滑动（如删除）
