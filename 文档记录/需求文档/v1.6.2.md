# JFLove v1.6.2 需求文档

> **本版本是一次「编辑器可用性修复 + 工具箱能力扩展」版本**：修掉让**工具箱 10 项共约 29 个按钮点下去完全没反应**的缺陷，修掉**两段文本对比打不开/打开也只有一条缝**的缺陷，给**工具箱 12 项各配一条快捷键（作用域 = 编辑面板聚焦）**，给**查找/替换加"跨已打开标签页"的范围**，把**编辑器区右击菜单汉化**（并移除其它区域那份没用的英文菜单），把**快捷键配置按「应用级 / 文本编辑器级」两组隔离**。
> 计划与取证来源：`plans/desktop-v1.6.2-editor-toolbox.md`；基线：`文档记录/需求文档/v1.6.1.md`。
> **范围**：仅 `jflove-desktop/`（`ui/` 渲染层 + `src/ui/web_shell.py` 外壳）。**服务端 / Web 端 / 移动端零改动**，**数据库无结构变更** ⇒ 本次**没有 Phase 3 / Phase 4b / Phase 4c**。
> 编写角色：product（Phase 1，`AGENTS.md §7.3`）。

## 2. 目标用户与使用场景

### 2.1 目标用户

**沿用 v1.6.1 §2.1**（程序员 / 开发者；"处理一段文本、就地改一个本地文件"）。

### 2.2 核心场景

| 场景 | 用户动作 | 痛点 / 说明 |
|------|---------|-----------|
| **一次性处理一段文本**（**修复**） | 打开工具箱 → 点「排序」/「去重」/「Base64 编码」/「JSON 格式化」… → 正文当场变化，变化处滚到眼前 | 现在点下去**什么都不会发生**（E-1）；修好后还要**看得见**（否则"作用文字不明显"仍在） |
| **键盘流处理**（**新增**） | 光标在编辑面板里 → 按该项快捷键（如「排序」）→ 当场生效；焦点不在编辑器里时**按键不生效、也不会被吞** | 用户原话"工具箱里面的能力应该要支持快捷键，**只作用在当前的框内**" |
| **一次改多个文件里的同一处**（**新增**） | `Ctrl+F` → 范围切到「所有已打开的标签页」→ 搜索 → 逐个命中点过去 / 一次性「全部替换」 | 用户原话"**有些场景是要搜多个文件**……默认还是当前输入框内" |
| **两段文本比对**（**修复**） | 工具箱「打开对比」或 `Ctrl+Shift+D` → 覆盖层**铺满编辑面板** → 选第二段来源（另一标签页 / 本地文件 / 剪贴板） | 现在**点不动**（E-1），且即便打开也只有一条缝（E-5） |
| **编辑器里右击**（**修复**） | 在正文里右击 → 弹出**中文**菜单（撤销/重做/剪切/复制/粘贴/删除/全选） | 现在弹的是 Chromium 英文菜单，还带 `Back`/`Reload`/`Save page`/`Inspect` 等桌面端用不到的项 |
| **改键**（**改进**） | 设置 → 快捷键 → **先看到两组**（应用级 / 文本编辑器级）→ 知道每条键在哪生效 | 现在 18 项挤在一起、工具箱一条键都没有，"混合在一起" |
| 其余场景 | **沿用 v1.6.1 §2.2**（本机文件小改一处、多标签来回看、草稿留档） | 本版不动这些流程 |

### 2.3 判断这次做成功的标准（用户口径）

1. **"点下去真的动"**：工具箱任何一项的任何按钮点下去，要么正文/视图/覆盖层**真的变了**，要么给出**中文原因**（只读 / 未挂载 / 能力不适用）——**不允许**"点了完全没反应"。
2. **"能看出动了"**：改正文的动作执行后，**变化处自动滚到眼前**，并给出中文结果提示（处理了多少行 / 多少字符）。
3. **"键盘也能干"**：工具箱 12 项各有一条快捷键；**焦点在编辑器里才生效**，焦点在左侧菜单或别的页面上时按键既**不生效也不被吞**。
4. **"能一次搜多个文件"**：查找替换可以切到"所有已打开的标签页"，命中逐条列出、点一下就跳过去；**默认仍是当前这一份**。
5. **"对比真的能用"**：打开后**铺满编辑面板**（不是一条缝），两侧只读，第二段来源三种都按既有口径。
6. **"右击是中文"**：编辑器里右击弹出的是中文菜单，**没有任何英文残留**、没有任何浏览器导航类项；别处那份没用的菜单不再出现。
7. **"配置分得清"**：设置里快捷键**分成两组**，每一行都写清作用域，改键时不会把"应用级"和"编辑器级"搞混。
8. **不丢内容、不出本机**：**沿用 v1.6.1 §2.3 第 4/6 条**（编辑器与远端零交互；本机能力不依赖服务端；草稿保护不变）。

## 3. 功能需求

> 编号体系：v1.6.0 / v1.6.1 用 F1 ~ F10；本版**新增 F11 ~ F15**。F1 ~ F10 **全部继续有效**（全文见 `文档记录/需求文档/v1.6.1.md` §3 与其引用的 v1.6.0 §3.3~§3.10）。

### 3.1 F11 工具箱可用性与反馈（**新增**）

**用户故事**：作为使用者，我点工具箱里的一项，就是要它**立刻作用到我这段文字上**；如果因为只读、没挂载或类型不适用而做不了，请**用中文告诉我为什么**，别让我以为程序坏了。

**功能规则**：

1. **动作必须真的执行**：工具箱 12 项的每个动作按钮（含弹框内的子动作）被点击后，**必须**发生它所声明的那件事 —— 改正文类改变正文；视图类切换视图；覆盖层类打开覆盖层；字号线号类改变显示偏好。**不允许**"点了什么都没发生"。
2. **关框语义不变**：v1.6.1 的 AC-76 全部继续有效（10 项选完即关；`sql` / `font` 保持打开；`Esc` 关闭；点弹框外部关闭），且**关框不得吞掉这次动作**。
3. **动作结果可见**（针对"作用文字不明显"）：
   - 改**正文**类的动作执行后：① 把**变化发生的范围滚动到视口内**（含光标/选区落到变化处附近）；② 在工具栏给出**中文结果提示**，至少含**处理规模**（如「已排序（12 行）」/「已去重（删除 3 行）」/「已 Base64 解码（96 字符）」）；
   - 改**视图**类的动作执行后：视图真的切换（判据 = 面板的视图模式变了且界面随之变）；
   - **覆盖层**类：覆盖层真的出现且**盖住整个编辑面板**（AC-83）。
4. **做不了必须说清**（不得静默）：只读标签页上的改正文类动作 → 沿用既有中文提示；标签页未挂载 → 中文提示；动作的前置条件不满足（非法 JSON / 非法 XML / 不适合美化的 SQL / 剪贴板不可用）→ **落点处的中文原因**（不得只给英文异常原文）。
5. **12 项逐项可用**：`search` / `lines` / `case` / `escape` / `base64` / `json` / `markdown` / `csv` / `sql` / `xml` / `diff` / `font` 逐项给出"首选动作真的生效"的判据（§8 的 AC-80）。
6. **语言/类型门禁的呈现**：因**文档类型**而不可用的动作（如纯文本标签页的「表格视图」「树形视图」）按钮**保持禁用**，但必须给**中文 `title` 说明原因**（如「仅 CSV / TSV 可用」），不得表现为"点了没反应"。

### 3.2 F12 两段文本对比可用性（**新增**）

**用户故事**：我要比两段文本，点开对比就该看见左右两栏差异铺满整个编辑区。

**功能规则**：

1. **覆盖层铺满编辑面板**：打开对比后，对比视图占满**编辑面板的内容区域**（至少覆盖工具栏以下的正文区），**不得**只覆盖工具栏那一行。
2. **三条来源沿用 v1.6.0 §4.1.6 第 11 项 / v1.6.1 §0.5.4 C-1**：剪贴板 / 另一标签页 / 本地文件；剪贴板不可用时给**唯一中文提示**并指明替代来源，且**不清空**已载入的第二段（C-1 不回归）。
3. **「另一标签页」候选完整**：下拉列出**所有已挂载**的其它标签页（不含自己）；候选为空时给中文说明，不得给空下拉。
4. **关闭路径**：覆盖层上的「关闭对比」可用；关闭后编辑面板恢复原视图（正文、光标、滚动位置不因开关对比而改变）。
5. **快捷键**：`view.diff`（默认 `Ctrl+Shift+D`）打开对比；工具箱「打开对比」打开对比 —— 两条通路**都真的生效**。
6. **只读**：两侧只读（不得通过对比视图改正文）。

### 3.3 F13 编辑器区右击菜单（**新增**）

**用户故事**：我在编辑器里点右键，要的是中文的编辑动作；别处那份带 `Back`/`Reload`/`Inspect` 的英文菜单对我没用。

**功能规则**：

1. **范围**：**只有文本编辑器的可编辑区**（CM6 正文）给右击菜单；**页面其它区域一律不弹菜单**（含标签条、工具栏、状态栏、预览 / 表格 / 树形等只读视图、以及设置 / 文件管理 / 笔记等其它页面）。
2. **菜单内容（中文标准编辑动作）**：撤销 / 重做 / 剪切 / 复制 / 粘贴 / 全选；**按当前上下文启用或禁用**（无选中时「剪切」「复制」禁用；剪贴板为空时「粘贴」禁用）。
   > ⚠ **2026-10-16 实现期就地更正（收窄一项）**：原稿含「删除」项。**Qt 6 的 `QWebEnginePage.WebAction` 不暴露 Delete**
   > （枚举里只有 `Cut/Copy/Paste/Undo/Redo/SelectAll/Unselect…`）⇒ 要做"删除"只能由外壳执行
   > `runJavaScript("document.execCommand('delete')")`，那会**新增一条"外壳 → 渲染层执行 JS"的能力面**
   > （本模块此前零 `runJavaScript`），与安全宪法 §9.6 的能力面最小化相悖。
   > **最终结论：不做「删除」项**；"删掉选中的内容"由「剪切」覆盖。**判据 AC-85 相应改为 6 项**（不含「删除」）。
3. **零英文残留**：菜单里**不得**出现 `Copy` / `Paste` / `Cut` / `Undo` / `Redo` / `Select all` / `Delete` 等英文项。
4. **零浏览器项**：**不得**出现 `Back` / `Forward` / `Reload` / `Save page` / `View page source` / `Inspect` / `Copy image` 等与桌面应用无关的项。
5. **能力面不扩大**：不得为此打开渲染层的剪贴板权限（`JavascriptCanAccessClipboard` 保持未开）；不得给渲染层新增剪贴板读取点；不得新增桥方法。
6. **唯一例外（我方拍板，可一句话推翻，见 §7.1 D35②）**：应用内**文本输入框**（登录用户名 / 密码、重命名输入框、搜索框等）右击时**仍给同一份中文标准编辑菜单** —— 否则这些地方会连"右键粘贴"一起消失（可用性倒退）。
7. **平台一致**：Windows 与 Linux 行为一致（菜单文案与启用条件相同）。

### 3.4 F14 工具箱快捷键（**新增**）

**用户故事**：我天天用「排序」「去重」「格式化」，不想每次都点开弹框找按钮；而且这些键**只该在我正编辑的那个框里**起作用。

**功能规则**：

1. **12 条快捷键**：`TOOLBOX_ITEMS` 的 **12 项各有一条可配置快捷键**（默认键见 §8 AC-88 表）。
2. **作用域 = 编辑面板聚焦**：
   - **生效**：键盘事件的目标位于某个编辑面板 DOM 内（`[data-editor-panel]`，含正文、工具栏、状态栏）；
   - **不生效且不 `preventDefault`**：目标不在任何编辑面板内（左侧菜单、标签条、其它页面）—— 不得吞掉用户的按键。
3. **语义 = 执行该项的「首选动作」**：每项的首选动作**唯一且写在唯一真相表**里（`TOOLBOX_PRIMARY_ACTION`，12 项与设计表逐条一致）；一项里的**其它**动作仍通过工具箱弹框使用（本版**不做**"每个按钮一条键"，用户裁决 5）。
4. **不得静默**：目标标签页未挂载 ⇒ 中文提示；只读标签页 + 改正文类首选动作 ⇒ 既有中文提示；未登录 ⇒ 一律不响应（承接 AC-63 ②）。
5. **与既有快捷键不冲突**：12 条新键与既有 18 项**不得同键**（组内唯一，AC-97）；与"编辑器内核保留键"（`Ctrl+Enter` / `Ctrl+Space`）不得相同。
6. **可发现性**：设置页「文本编辑器级」组里逐条列出，且工具箱弹框里对应项显示其当前键位（让用户知道"这项有快捷键"）。

### 3.5 F15 跨标签页搜索 / 替换（**新增**）

**用户故事**：同一处改动往往散在好几个文件里；我想一次搜出来、点一下跳过去，确认后一次替换掉。

**功能规则**：

1. **范围可选，默认为当前标签页**：查找/替换面板增加「搜索范围」选择：
   - **当前标签页（默认）**：行为与 v1.6.1 **逐字不变**（CM6 自带面板，`Ctrl+F` 直接可用）；
   - **所有已打开的标签页**：在**已打开的标签页之间**搜索。
2. **搜索范围的定义（硬口径）**：仅限**已打开且已挂载**的标签页（正文只活在 CM6 会话里）；**不读磁盘、不搜未打开的文件、不新增桥能力**（用户裁决 4；`AGENTS.md §9`）。
3. **未挂载标签页不得静默漏掉**：范围面板明示"仅搜索已打开的标签页（N 个）"，并对**未挂载**的标签页给出**中文说明**（如「有 1 个标签页尚未挂载，未参与搜索」）。
4. **结果列表**：按标签页分组列出命中（**标签页标题 + 行号 + 该行文本摘要**），并显示总命中数与涉及标签页数；命中数超过阈值时给出中文提示与可滚动列表（阈值由设计文档定）。
5. **点击结果 = 跳过去**：切换激活标签页 → 把命中处滚动到视口内 → **选中命中文本**。
6. **替换**：
   - 「替换当前」：替换当前激活标签页里的当前命中；
   - 「全部替换」：作用于**当前选定范围**内的全部命中；执行前给出**中文确认**（含"将替换 N 处、涉及 M 个标签页"），执行后给出中文结果提示（实际替换处数）；
   - 替换**只影响已打开的标签页**；未打开 / 未挂载的标签页**零改动**。
7. **选项沿用**：大小写敏感 / 正则 / 整词等选项与 CM6 面板**同一套口径**（跨标签搜索复用同一组选项语义）。
8. **零新增能力面**：不新增桥方法、不新增后端接口、渲染层不新增网络出口、不写入任何文件（替换结果仍由用户按既有保存语义落盘）。
9. **性能**：10 个已打开标签页、合计约 1 MB 正文时，一次跨标签搜索的界面可响应时间 **≤ 200 ms**（判据：设计文档给出的可测口径）。

## 6. 交互流程

### 6.1 流程 J：工具箱动作（**修复后的目标行为**）

1. 用户在编辑面板里点工具栏「工具箱（12 项）」→ 弹框展开（12 项逐项列出）。
2. 用户点第 2 项「行操作」的「排序」按钮 → **正文当场按 Unicode 码点升序排好**；变化处**滚进视口**；工具栏出现中文提示「已排序（12 行）」；弹框**关闭**。
3. 用户再开弹框点第 12 项「字号 / 行号 / 自动换行」的「A+」→ 字号变大、**弹框保持打开**（`font` 属保持打开组），可连续点。
4. 用户在**只读**标签页（大文件降级 / `.diff` 预览）上点「大写」→ 弹框关闭、**正文不变**、工具栏出现中文提示「只读标签页（大文件降级 / diff 预览）禁止修改内容」。
5. 用户在**纯文本**标签页上把鼠标停在「表格视图」上 → 按钮**禁用**且 `title` 说明「CSV / TSV 只读表格（自动识别分隔符）」类中文原因（不出现"点了没反应"）。

### 6.2 流程 K：工具箱快捷键（**新增**）

1. 用户焦点在编辑面板正文里，按「排序」的快捷键（默认 `Ctrl+Shift+L`，最终以 §8 表为准）→ 正文排序、变化处滚进视口、中文提示出现。
2. 用户焦点移到左侧菜单（或切到「设置」页面）再按同一组合键 → **什么都不发生**，且事件**不被 `preventDefault`**（宿主/浏览器默认动作不受影响）。
3. 用户在 `sql` / `font` 之外的一项上按快捷键，而该标签页**尚未挂载**（懒挂载未命中）→ 出现中文提示（不得静默）。
4. 未登录状态下按同一组合键 → **不响应、不报错、不 `preventDefault`**（承接 AC-63 ②）。

### 6.3 流程 L：跨标签页搜索与替换（**新增**）

1. 用户在工作区开着 4 个标签页（`A` 已挂载、`B` 已挂载、`C` 未挂载、`D` 已挂载），焦点在 `A`。
2. 用户 `Ctrl+F`（或工具箱「查找 / 替换面板」）→ 打开查找面板，**范围 = 当前标签页**（默认）。
3. 用户把范围切到「所有已打开的标签页」→ 界面明示「仅搜索已打开的标签页（3 个）」并提示 `C` 未挂载、未参与搜索。
4. 用户输入 `foo` 回车 → 结果按标签页分组列出（`A`：第 3 行 / 第 9 行；`B`：第 12 行；`D`：第 1 行），顶部显示「共 4 处命中，涉及 3 个标签页」。
5. 用户点 `B` 的第 12 行结果 → 激活 `B`、滚动到第 12 行、**选中** `foo`。
6. 用户在替换框输入 `bar` → 点「全部替换」→ 中文确认「将替换 4 处、涉及 3 个标签页」→ 确定 → 4 处全部替换完毕，界面提示「已替换 4 处」；`C` 与磁盘文件**一字未动**；`A` / `B` / `D` 因正文变化而变为**脏**（可保存）。

### 6.4 流程 M：右击菜单（**新增**）

1. 用户在编辑器**正文**里右击 → 弹出**中文**菜单：撤销 / 重做 / 剪切 / 复制 / 粘贴 / 删除 / 全选（按上下文启用/禁用）。
2. 用户在编辑器**工具栏**或**标签条**上右击 → **不弹菜单**。
3. 用户在「设置」页的普通区域右击 → **不弹菜单**；在设置页的**文本输入框**里右击 → 弹出**同一份中文**菜单（唯一例外，D35②）。
4. 菜单里**不出现**任何英文字样与任何浏览器导航项。

### 6.5 流程 N：改键与作用域（**新增**）

1. 用户进入设置 → 快捷键 → 看到**两组**：「应用级（任意页面生效）」、「文本编辑器级（仅编辑面板聚焦时生效）」。
2. 用户在「文本编辑器级」里找到「工具箱 · 排序」→ 行内显示作用域「编辑面板聚焦」+ 默认键 + 当前键 → 点「修改」→ 按新组合键 → 保存。
3. 用户把「工具箱 · 排序」改成与「应用级」里某项**相同的键** → 界面**提示**"该键已被『<应用级功能名>』使用；两者作用域不同，不会同时触发"，**允许保存**（组内仍保持唯一）。
4. 用户把同一组内的两条改成**同一个键** → **拒绝保存**并指出冲突项。

> 决策日期 **2026-10-16**（1 轮 6 项问答 + 本轮取证）。

### 7.1 用户裁决与我方拍板项（D33 ~ D39）

| 决策点 | 最终结论 | 取代 / 权衡 | 原因 |
|--------|---------|-----------|------|
