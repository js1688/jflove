# JFLove 1.0 需求文档

## 1. 项目概述

JFLove 是一款面向个人使用的私有桌面与服务端协同管理软件，主要服务于文件文档管理和笔记本管理场景。系统要求支持大文件传输、断点续传以及端到端加密通信，并且客户端与服务端的会话密钥每次连接都动态交换。

## 2. 目标用户

- 个人用户，追求本地与私有服务器数据管理一体化
- 需要统一管理文档、笔记与容器服务的技术爱好者
- 希望通过加密通信保障配置参数与响应数据安全的用户

## 3. 核心价值

- 提供简洁流畅的文件与笔记管理体验
- 支持稳定的大文件传输与断点续传
- 实现每次会话密钥交换的安全通信机制

## 4. 用户角色

- **管理员用户**（仅限一个）：首次启动客户端时由用户创建，拥有完全管理权限，包括：
  - 添加普通用户账号
  - 配置服务端磁盘目录，生成虚拟磁盘根路径
  - 控制普通用户对虚拟磁盘的访问权限
  - 查看系统日志和连接状态

- **普通用户**（多个）：由管理员添加，权限受限，可以：
  - 上传、下载、浏览管理员分配的虚拟磁盘目录中的文件
  - 编辑笔记（在管理员分配的笔记目录内）
  - 不能访问管理功能

## 5. 功能需求

### 5.1 文档管理

- 管理服务端磁盘目录，当作网盘根目录，完全依赖服务端磁盘结构，不在数据库存储文件目录信息。
- 支持远程文档目录浏览（树形结构展示服务端磁盘目录）。
- 支持大文件上传/下载，文件体积可达数 GB。
- 支持分片上传、断点续传和上传失败重试。
- 支持多格式文档预览：
  - 图片：png / jpg / jpeg / gif / bmp / webp / tiff / tif / ico
  - 矢量图：svg
  - 视频：mp4 / mkv / avi / mov / webm / flv / wmv / m4v / mpg / mpeg / ts / 3gp（可播放、暂停、跳转、调音量）
  - 音频：mp3 / wav / ogg / flac / m4a / aac / wma / opus
  - Markdown：md / markdown / mdown / mkd（渲染为 HTML，支持代码块、表格）
  - 文本与源代码：txt / log / json / xml / yaml / ini / csv / 常见编程语言文件等
- 支持文件名/内容搜索和版本历史（基于文件修改时间）。
- 支持文档标签、收藏及归档（通过客户端本地标记，不存储到服务端）。

### 5.2 笔记本管理

- 用户可在设置页面选择一个虚拟磁盘，并在磁盘目录树中浏览选择具体子目录作为笔记存放目录（不强制使用磁盘根目录）。每个用户独立配置。笔记本功能通过加载该目录下的所有 Markdown (.md) 文件实现。
- 支持 Markdown 编辑和实时预览，提供现代化阅读体验：
  - 排版：GitHub 风格 CSS，支持暗黑模式（跟随系统 prefers-color-scheme）
  - 代码块：语法高亮（highlight.js）+ 等宽字体 + 圆角边框
  - 图表：内置 mermaid 支持，` ```mermaid ` 代码块直接渲染为流程图/时序图/甘特图等
  - 表格 / 任务列表 / 引用块 / 标题层级 / 锚点跳转均美化
- 编辑器使用等宽字体提升 Markdown / 代码 / mermaid 编写体验
- 支持笔记新建、编辑、删除（直接操作 md 文件）。
- 支持笔记搜索（文件名/内容）、标签（通过文件内容标记）、收藏。
- 支持笔记同步至服务端目录（上传/下载 md 文件）。
- 不支持多级文件夹结构，笔记以目录下的 md 文件列表展示。

### 5.3 用户与权限管理（管理员功能）

- 支持添加普通用户账号，设置用户名与密码
- 支持删除普通用户账号，级联删除其权限记录
- 支持添加/删除服务端磁盘目录，生成虚拟磁盘根路径
- 支持配置普通用户对虚拟磁盘目录的访问权限（读/写/删除）
- 支持查看用户活动日志和连接历史

### 5.4 安全与加密

- 所有请求参数与响应内容必须经过加密处理
- 客户端与服务端间不使用固定密钥，必须每次重新交换临时会话密钥
- 支持会话密钥刷新机制
- 支持通信加密状态展示与异常告警

### 5.5 系统配置与设置

- 支持服务端地址与证书配置
- 支持本地缓存路径、上传策略、传输并发配置
- 支持安全策略设定，如强制会话密钥刷新频率

### 5.6 同步目录

每个用户可以为自己创建多条「本地目录 ↔ 远端虚拟磁盘子目录」的同步映射，用于把本地常用工作目录与远端文档库保持一致。

**核心规则**：

- 支持手动同步与自动同步两种模式（每条配置独立设置间隔，最小 30 秒）
- 同步算法（双向、增量）：
  - 本地有 / 远端无 → 自动上传到远端
  - 本地无 / 远端有 → 自动下载到本地
  - 两边都有 → 按文件修改时间取新者覆盖（容差 2 秒，避免反复来回同步）
- **删除安全约束**（产品强制要求）：
  - 同步过程**永远不会**自动删除文件，无论本地还是远端
  - 用户在本地手动删除一个文件后，下一次同步会从远端重新下载该文件
  - 要真正删除一个文件，必须前往「文档管理」页面手动删除（仅文档管理页提供删除入口）
- 配置粒度：
  - 一个用户可配置多条映射，每条对应不同的本地目录与远端目标
  - 仅创建者可见、可编辑、可删除自己的映射
  - 配置软删除仅取消映射关系，不影响实际文件
- 权限：用户对目标虚拟磁盘必须同时具备读 + 写权限

## 6. 交互流程

### 6.1 应用启动与登录

1. 用户启动客户端，系统自动尝试免登录恢复：若本地保存的 JWT token 仍在有效期内，自动重新执行密钥交换并直接进入主界面，无需再次输入密码。
2. 若 token 已过期或不存在，显示登录界面。
3. 系统检查是否存在管理员账号：若无管理员，显示"创建管理员账号"对话框。
4. 用户输入凭证并连接服务端，客户端与服务端完成身份校验与临时会话密钥交换。
5. 连接成功后显示主界面；JWT token 及用户信息将本地持久化，下次启动可免登录。
6. Token 在主界面使用过程中到期时，系统自动检测并提示用户重新登录，跳转回登录页。
7. 用户主动退出登录后，清除本地持久化的 token，跳转回登录页（不需要重启应用）。

### 6.2 文档上传与下载流程

上传流程：

1. 用户进入"文档管理"模块，系统展示管理员分配的虚拟磁盘根目录树形结构。
2. 用户选择目标目录后，点击"上传文件"可一次性选择**多个本地文件**。
3. 客户端将每个选中的文件作为独立任务提交到全局**传输任务管理器**，立即返回让用户继续操作；任务在后台并行执行（默认最多 3 个并发）。
4. 每个上传任务依次经历：
   - **校验阶段**：流式读取文件并计算 SHA256，期间持续上报字节级进度（避免大文件长时间无反馈）。
   - **上传阶段**：将文件按 1 MB 分片，每片用当前会话密钥加密后发送至服务端，期间持续上报字节级进度。
   - **合并阶段**：服务端收到所有分片后合并为最终文件并校验 SHA256。
5. 用户随时可在"传输任务"页面查看每个任务的状态、进度条、已传输字节数；可对任意进行中或等待中的任务点击"取消"。
6. 上传完成后，"文档管理"页面刷新当前目录会展示新文件。

下载流程：

1. 用户在目录树中右键选择目标文件，点击"下载"，选择本地保存路径。
2. 客户端将下载请求作为任务提交到传输任务管理器。
3. 任务以流式方式接收数据并直接写入到本地临时文件 `xxx.part`，避免占用大量内存；下载完成后原子重命名为目标文件名。
4. 用户可在"传输任务"页面查看进度并随时取消（取消后客户端自动清理临时文件）。

并发与任务管理：

- 上传与下载共享同一个并发配额（默认 3）；超出的任务自动进入 PENDING 队列等待调度。
- "传输任务"页面顶部展示总览：总数 / 进行中 / 等待 / 完成 / 失败 / 取消，并提供"清除已完成"按钮。
- 任务状态包括：等待中、校验中、传输中、已完成、失败、已取消；UI 实时反映状态变化。

### 6.3 笔记本编辑与同步流程

1. 用户进入"笔记本管理"模块，系统加载管理员分配的笔记目录下的所有 .md 文件列表。
2. 用户新建或选择现有 md 文件打开（受权限限制）。
3. 在编辑器中进行 Markdown 编写，右侧实时预览渲染结果。
4. 用户保存时，客户端将 md 内容加密后上传至服务端指定目录。
5. 服务端检验用户权限，写入文件，返回确认，客户端更新文件列表。
6. 用户可搜索笔记内容或文件名，快速定位。

### 6.4 管理员用户与权限管理流程

1. 管理员进入"系统管理"模块。
2. 在"用户管理"页面，管理员可：
   - 添加普通用户（设置用户名、密码）
   - 删除普通用户（级联删除其权限）
   - 修改用户密码或启用/禁用用户
3. 在"磁盘管理"页面，管理员可：
   - 添加服务端磁盘目录，生成虚拟磁盘根路径名称
   - 编辑虚拟磁盘根路径的访问权限，分配给不同用户
   - 删除虚拟磁盘根路径（警告级联删除其权限）
4. 在"权限配置"页面，管理员可为每个普通用户配置：
   - 可访问的虚拟磁盘目录及操作权限（读/写/删除）
   - 笔记功能不再单独配置权限：所有登录用户均可使用笔记本，每个用户的笔记目录由用户在「设置」页面独立选择（互不可见）
5. 系统记录所有管理操作和用户活动日志。

### 6.5 目录同步流程

1. 用户进入"同步目录"模块，点击"新建配置"。
2. 在表单中：填写配置名称、选择本地目录、选择远端虚拟磁盘 + 子目录、设置自动同步开关与间隔。
3. 客户端校验本地目录可读、远端磁盘有读+写权限后保存配置。
4. 用户可点击"立即同步"触发一次手动同步；若开启了自动同步，客户端定时器会按间隔自动触发。
5. 每次同步流程：
   - 客户端递归扫描本地目录，构建 `{相对路径: (size, mtime)}` 索引
   - 客户端调用 `GET /api/v1/sync/configs/{id}/snapshot` 拉取远端递归扫描结果
   - 计算差集：本地多 → 提交上传任务；远端多 → 提交下载任务；两边都有则按 mtime 取新者
   - 所有任务进入「传输任务」队列，按 3 并发上限执行
   - 一轮提交完成后调用 `POST /touch` 更新服务端 `last_synced_at`
6. 用户随时可在"传输任务"页面查看具体上传/下载进度并取消单个任务。
7. **删除约束**：客户端在任何方向都不会触发删除操作。本地误删后下次同步会从远端补回；要真正删除一个远端文件，须前往"文档管理"页面手动删除。

### 6.6 会话密钥刷新与异常处理

1. 用户在设置中选择“刷新连接密钥”或系统自动触发策略刷新。
2. 客户端与服务端再次进行临时密钥交换，重新生成会话密钥。
3. 当前会话继续使用新密钥，所有后续请求与响应都基于新会话进行加密。
4. 若密钥交换失败，客户端提示“连接不可用”，并建议用户重新登录或检查服务端配置。

## 7. 非功能需求

- 可用性：系统应在普通网络环境下稳定运行，支持大文件分片与断点续传。
- 安全性：所有传输数据必须加密，且会话密钥不可重用。
- 性能：文档管理模块可处理 GB 级文件上传/下载。
- 可维护性：模块划分清晰，便于后续扩展文档搜索、权限管理等功能。

## 8. 版本规划

### 1.0 版本范围
- 文档管理：目录浏览、大文件上传/下载、断点续传、搜索、预览
- 笔记管理：笔记编辑、同步、搜索
- 用户与权限管理：管理员创建、普通用户管理、虚拟磁盘配置、权限分配
- 加密通信：临时会话密钥交换、参数与响应加密、会话状态展示
- 基础设置：服务端配置、上传策略、加密策略

### 1.1+ 版本建议
- 文档全文索引与智能搜索
- 用户权限与多用户支持
- 设备信任管理与多端同步
- 离线编辑与全量同步策略

  - 快速搜索

  - 操作按钮区域
  - 右侧详情/日志面板

### 9.2 界面原型流程图（文字版）

1. 启动应用
   - 首次启动检查是否存在管理员
   - 若无管理员，显示"创建管理员账号"对话框
   - 若有管理员，显示"用户登录"界面
2. 创建或登录
   - 创建管理员：设置用户名、密码

4. 进入模块（权限-aware）
   - 管理员可见全部模块（包括系统管理）

5. 安全提醒
   - 顶部显示当前用户角色和会话状态
   - 若密钥过期或连接异常，弹窗提示并提供“刷新密钥”

### 9.3 关键页面交互文案

  - 用户名
  - 密码
  - 密码确认
- 按钮：
  - 创建管理员
  - 后退（如果不是首次）
- 规则提示：
  - "用户名长度 3-20 个字符"
  - "密码长度至少 8 个字符"
- 创建成功提示：
  - "管理员账号创建成功，请登录。"

#### 9.3.2 用户登录页
- 标题：登录 JFLove
- 输入框：

- 按钮：
  - 连接

#### 9.3.4 同步目录页

- 页面头部：同步目录
- 顶部说明卡片：明示同步规则与"同步永不删除文件"的安全约束
- 操作栏：
  - "新建配置"按钮：弹出表单（配置名 / 本地目录 / 远端磁盘 / 子目录 / 自动同步 / 间隔 / 启用开关）
  - 刷新按钮：重新拉取配置列表
- 配置列表（表格）：
  - 列：名称 / 本地目录 / 远端目标（磁盘+路径）/ 自动同步 / 间隔 / 上次同步 / 状态 / 操作
  - 操作按钮：立即同步、编辑、删除
  - 状态实时反映：空闲 / 正在同步… / 完成 ↑X ↓Y ⏭Z / 失败:原因
- 行为规则：
  - 同步算法：本地多→上传；远端多→下载；两边都有→按 mtime 取新者（容差 2 秒）
  - 删除任意一端的文件都不会被同步触发，必须经文档管理页删除远端
  - 删除"同步配置"仅取消映射关系，不影响实际文件
- 表单字段提示：
  - "起一个便于识别的名称，如：照片备份"
  - "磁盘内子目录（留空表示根目录）"
  - "同步间隔最小 30 秒，开启自动同步后客户端定时器会按此间隔触发"

#### 9.3.5 传输任务页

- 页面头部：传输任务
- 顶部统计区：总数 / 进行中 / 等待 / 完成 / 失败 / 取消，并提供"清除已完成"按钮。
- 任务列表（每行一个任务）：
  - 上传/下载方向图标
  - 文件名（鼠标悬停显示完整本地路径）
  - 进度条（0-100%）
  - 状态文字：等待中 / 校验中 / 传输中 / 已完成 / 失败 / 已取消
  - 已传输字节 / 总字节（人类可读单位）
  - 失败任务额外显示错误信息
  - 操作按钮：进行中 / 等待中 → 取消；已结束 → 不可点
- 行为规则：
  - 同时最多并行 3 个任务，超出的进入等待队列
  - 任务一结束就空出并发槽位，自动调度下一个等待任务
  - 用户取消进行中的任务后，客户端清理服务端临时分片或本地半成品文件

### 9.4 关键页面交互行为

- 在“文档管理”页上传大文件时，系统应展示“分片上传进度”并允许“暂停/恢复”。
