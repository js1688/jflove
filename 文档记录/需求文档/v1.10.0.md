## 0. 背景与需求来源

### 0.1 用户原话映射

| # | 用户要求 | 本版落地 |
|---|---|---|
| U1 | 加一个 SSH/SFTP 客户端，支持多端 | 桌面端 + App，Web 端不做 |
| U2 | 账号密码、连接配置存服务端，客户端每次连接时拉取 | 服务端表持久化，客户端零本地缓存（内存即用即弃） |
| U3 | SSH/SFTP 网络不经过服务端 | 两端均**直连**，服务端只做配置 CRUD |
| U4 | 客户端可以添加连接配置 | 桌面端与 App 均可新增/编辑/删除 |
| U5 | 一条连接可以当另一条的跳板机（终端与 SFTP 都适用） | `jump_connection_id` 自引用，任意级，共用链路 |
| U6 | 终端输出、SFTP 上传下载体验友好 | 见 F63 / F64 的体验清单 |
| U7 | 多窗口同时工作；不要弹框，用多标签 | 工作区内多标签，每个标签一个会话 |
| U8 | 多个配置、配置分组存放 | 服务端分组表，三端共享 |
| U9 | 客户端**本机终端**：识别本机系统，打开对应终端 | 桌面端内嵌本机终端，自动探测 shell |
| U10 | 本机终端没有配置信息，但窗口/配置可存本地，支持分组与持久化 | 本地 SQLite，仅 `jflove-desktop` 使用 |
| U11 | 远程配置服务端持久化，本机配置本地持久化 | 两套存储，互不干扰 |
| U12 | 本机终端、远程终端连接/打开后先执行指定命令，直接到工作环境 | 两类终端都新增「连接后执行」字段 |
| U13 | App 底部导航迁移时别把能力搞坏 | 离线下载能力整体保留，只换入口 |

### 0.2 本次裁决清单

| # | 决策点 | 用户裁决 |
|---|---|---|
| **D36** | 端范围 | 桌面端 + App 同版本；**Web 端完全不做**，不出现入口、不写代码 |

| **D46** | App 底部导航 | 新增「远程」；「离线下载」并入「传输任务」页，**能力不丢失**（新建/分析/勾选/下载/取消/删除/进度全部保留）；桌面端侧栏不变 |

### 0.3 术语

| 术语 | 含义 |
|---|---|
| 远程连接 | 一条 SSH 配置：主机、端口、用户、认证方式、凭据、跳板、分组 |
| 本机终端 | 在本机启动 shell 的终端，无远程主机概念 |
| 跳板连接 | 被另一条连接引用的远程连接，建连时先连它再用通道转发 |
| 会话 | 一次实际建立的 SSH/SFTP/本机终端连接，对应工作区一个标签 |
| 工作区 | 「远程连接」下的会话页，承载多标签 |

## 1. 目标用户与场景

**目标用户**：已经用 JFLove 管理文件与笔记、经常需要登录自己几台服务器（NAS、小主机、云主机）的用户。

**典型场景**：

1. 在公司电脑打开桌面端 → 远程连接 → 双击「家里 NAS」→ 直接进终端，改配置、看日志。
2. 家里有台机器只能从内网跳板进 → 配置「内网数据库」的跳板为「家里 NAS」→ 双击即连，不用手打 `ssh -J`。
3. 传一个文件到服务器 → 会话标签内切到「SFTP」→ 拖进去，看进度。
4. 想在本地跑个命令 → 切到「本机终端」→ 自动是当前系统的 shell（Windows PowerShell / Linux bash）。
5. 手机在外面 → App 打开同一条连接（配置已从服务端同步）→ 终端里重启服务。

**非目标**：多用户共享连接、连接分享给他人、端口转发/隧道、X11 转发、会话录制、Web 端。

## 2. 功能需求

### F60 连接配置管理（服务端持久化）

- 字段：名称、主机、端口（默认 22）、用户名、认证方式、密码、私钥内容（PEM 文本）、私钥口令、跳板连接、分组、备注。
- 认证方式枚举：
  - `password`：仅密码
  - `publickey`：私钥（可选口令）
  - `password_keyboard`：密码 + 键盘交互（OTP / 二次验证）
- 终端参数：终端类型（默认 `xterm-256color`）、字符编码（默认 UTF-8）。
- **连接后执行**（可选）：单行命令，连接成功后自动发送到 shell（见 F69）。
- 操作：新建、编辑、复制一条为新连接、删除（软删除）、搜索（名称/主机/用户名）。
- 列表默认不返回密码/私钥（`list` 精简字段），点「连接」时才 `get` 全量；编辑时也 `get`。
- 删除连接时，若有其他连接以它为跳板：**阻止删除**并提示「被 N 条连接引用」，或提供「一并把引用清空」确认。默认阻止。

### F61 分组

- 分组字段：名称、排序。
- 连接可属于一个分组或「未分组」。
- 分组操作：新建、重命名、删除（删除后组内连接落入「未分组」，不删连接）、拖拽排序（桌面端；App 用长按菜单上移/下移）。
- 分组为空时显示但可折叠；「未分组」为系统保留组，不可重命名/删除。

### F62 跳板机

- 每条连接可选一条「跳板连接」（下拉选择已保存连接，排除自身）。
- 链路展开：目标 B 的跳板是 A，A 的跳板是 C → 实际链路 `客户端 → C → A → B`。
- 任一环节失败，错误提示需定位到具体哪一跳（如「跳板 C 认证失败」）。
- **逐跳状态可见**：连接过程中与连接后，界面展示完整链路与每一跳的状态（等待/连接中/已认证/失败）。
- **禁止循环引用**：保存时校验链路，出现环则拒绝并在表单上提示。
- 跳板连接的凭据同样从服务端拉取；UI 上不重复展示跳板的密码。
- 终端与 SFTP 共用同一条链路（同一会话内复用连接）。

### F63 内嵌终端

体验要求（验收口径）：

- 支持 16 色 / 256 色 / truecolor。
- 窗口变化时终端尺寸（cols/rows）跟随，远端 `vim`、`htop` 不错位。
- 滚屏缓冲 ≥ 5000 行，可回看。
- 复制/粘贴：选中即复制可选；`Ctrl+Shift+C` / `Ctrl+Shift+V`；右键菜单含复制、粘贴、全选、清屏。
- 终端内搜索（`Ctrl+F`），上一个/下一个。
- 字号缩放（`Ctrl+=` / `Ctrl+-` / `Ctrl+0` 复位）。
- 中文宽字符对齐，emoji / Powerline 字形有回退字体。
- 连接中显示「正在连接…」状态；首次连接弹出**主机指纹确认**（展示 SHA256 指纹 + 接受/拒绝）。
- 断线显示「连接已断开，重连」按钮，重连不丢标签。
- 粘贴多行时提示「将粘贴 N 行，可能直接执行」确认。
- 标签标题默认 `user@host`，可重命名。

### F64 SFTP 文件面板

- 同一会话标签内，通过「终端 / 文件」分段控件切换；切换不重建连接。
- 布局：左右双栏（本地目录 | 远端目录），各自有路径面包屑、刷新、上级目录、新建目录、重命名、删除。
- 上传：拖拽到远端栏、或「上传」按钮选文件/文件夹；显示进度、速度、剩余时间、取消。
- 下载：双击文件下载到本地当前目录；或右键「下载」；同样有进度与取消。
- 冲突处理：目标已存在时提供「覆盖 / 跳过 / 重命名」；可勾选「对全部应用」。
- 传输队列：底部可折叠面板，展示进行中/已完成/失败，可重试失败项。
- 文件打开：双击已下载文件用系统默认应用打开（桌面端）。
- 大目录：虚拟滚动，不一次性渲染全部行；软链接按远端类型展示。
- 权限：列表显示权限位与大小、修改时间；不提供 chmod 编辑（v1 不做）。
- 断点续传：v1 不做（整文件 + 进度 + 取消即可）。

### F65 会话与多标签

- 工作区顶部标签栏：每个标签一个会话（SSH 终端 / SFTP / 本机终端）。
- 标签可关闭（关闭即断开连接）、可切换；标签过多时横向滚动。
- 「新建标签」下拉：最近连接 / 全部连接 / 本机终端。
- 同一连接可开多个标签（如两个终端会话）。
- 关闭标签时若有未完成的 SFTP 传输，提示「有 N 个传输进行中」。
- 标签栏右侧显示当前会话状态点（已连接/连接中/已断开）。

### F66 本机终端（仅桌面端）

- 自动识别系统：
  - Windows：PowerShell（优先 `pwsh`，回退 `powershell.exe`）、CMD、WSL（若检测到）。
  - Linux/macOS：读取 `/etc/shells`，默认登录 shell。
- 本机终端条目字段：名称、Shell 类型、可执行路径、启动参数、工作目录、环境变量、初始命令、分组。
- 分组：与远程分组独立的一套本地分组。
- 持久化：桌面端本地 SQLite（App 数据目录），服务端不可见、不参与同步。
- 多标签、复制粘贴、搜索、字号等终端能力与 F63 一致。
- **不校验主机指纹、不需要认证**（本地进程）。

### F67 App 端

- 与桌面端共享服务端连接与分组（同账号即同数据）。
- 列表页：分组折叠 + 连接卡片；下拉刷新；搜索。
- 编辑页：字段与桌面端一致；私钥支持「粘贴文本」与「从文件选择」。
- 终端页：全屏终端 + 顶部栏（返回、名称、状态、更多菜单）；底部工具条（Ctrl、Alt、Tab、Esc、方向键、粘贴、键盘）。
- SFTP 页：窄屏下「本地 / 远端」分段切换；上传下载、进度、取消、新建目录、重命名、删除。
- 跳板：与桌面端行为一致。
- **不支持本机终端**（Android 无本地 shell）。
- 底部导航调整为 6 项：**文件 / 笔记 / 传输 / 远程 / 相册 / 设置**。
  - 「离线下载」从底部导航移入「传输」页，作为页内 Tab（传输任务 / 离线下载 / 修复中心）。
  - **迁移不降能力**：离线下载的新建、解析、清单勾选、下载、取消、删除、进度展示全部保留；仅入口位置变化。
  - 桌面端侧栏保持不变（仍保留独立「离线下载」项）。

### F69 连接后自动执行命令

- 适用范围：**远程终端**与**本机终端**都支持，语义一致——会话建立后，把一条命令写进 shell 并回车。
- 存储字段：远程 `ssh_connections.init_command`；本机 `local_terminal_profiles.init_command`。
- 规则：
  - 只允许**单行**，最大 1024 字符；保存时含换行直接拒绝（换行会被 shell 拆成多条，属误执行风险）。
  - 空值 = 不执行。
  - 执行前在终端里**原样回显**该命令，用户能看见执行了什么。
  - 命令在交互式 shell 内执行（支持 `cd /app && ls`、`source ~/.bashrc` 等），执行完仍停留在 shell，**不关闭会话**。
  - 命令失败（非零退出）不报错弹窗，正常回到提示符。
  - 不提供变量替换、超时控制、多命令编排（v1 不做）。
  - 允许 `exec` 等会替换 shell 的写法，但 UI 提示「该命令可能替换当前 shell」。
- UI：编辑表单「连接后执行（可选）」单行输入 + 说明；列表/会话信息里不重复展示命令全文。

### F68 错误与状态

- 服务端不可达：远程连接列表显示错误与重试；**本机终端仍可用**（本地数据）。
- 认证失败、主机指纹不匹配、超时、跳板失败：分别给出可区分的中文提示，不裸露堆栈。
- 凭据任何情况下不进入日志与错误提示。

## 3. 数据模型（需求层，DDL 细节交 Phase 2）

### 3.1 服务端（新增）

```
ssh_groups(id, user_id, name, sort_order, created_at, updated_at, deleted_at)
ssh_connections(
  id, user_id, group_id, name, host, port, username,
  auth_type, password, private_key, passphrase,
  jump_connection_id, terminal_type, charset, init_command,
  host_key_fingerprint, last_connected_at,
  created_at, updated_at, deleted_at
)
```

- 全部按 `user_id` 过滤；`deleted_at` 软删除。
- 唯一性：同一用户下分组名唯一（仅活跃行）；连接名允许重复。

### 3.2 桌面端本地（新增）

```
local_terminal_groups(id, name, sort_order, created_at, updated_at)
local_terminal_profiles(
  id, group_id, name, shell_kind, shell_path, args,
  cwd, env_json, init_command, created_at, updated_at
)
```

- 存 `<AppData>/jflove/local.db`，不随账号同步。

## 4. 交互流程

### 4.1 首次使用远程连接

1. 侧栏点「远程连接」→ 空状态「还没有连接」+「新建连接」。
2. 新建 → 右侧抽屉表单 → 填主机/端口/用户/认证方式/密码或私钥 → 可选分组、跳板 → 保存。
3. 列表出现卡片 → 双击 → 进入工作区，新建标签并开始连接。
4. 首次连接弹主机指纹确认 → 接受后写入 `host_key_fingerprint`。
5. 若配置了「连接后执行」，登录完成后终端回显并执行该命令，随后停在提示符。

### 4.2 配跳板

1. 编辑「内网数据库」→ 跳板下拉选「家里 NAS」（列表来自已保存连接，排除自身）。
2. 保存时校验链路无环。
3. 双击连接 → 工作区标签标题显示 `内网数据库 ← 家里 NAS`，连接过程显示两跳状态。

### 4.3 本机终端

1. 工作区「新建标签」→「本机终端」→ 若本地无条目，直接按系统默认 shell 打开一个「本机终端」标签；若已有条目，弹出小菜单选择。
2. 打开时若该条目配置了「连接后执行」，先执行再停留。
3. 「管理本机终端」→ 进入本地配置页（分组 + 条目 CRUD），只改本地库。

### 4.4 App

1. 底部「远程」→ 列表 → 点卡片直接连接（不走详情）。
2. 长按卡片 → 编辑 / 复制 / 删除。
3. 终端页 → 底部工具条补特殊键 → 右上「文件」进 SFTP。

## 5. 安全标注（按项目宪法，仅列必做项，不展开论证）

| 项 | 要求 |
|---|---|
| 加密信封 | 所有新增 `/api/v1/ssh/*` 接口走 `decrypt_request_body` + `encrypt_response`，`token` 在 body |
| 归属校验 | 列表/详情/更新/删除/跳板引用全部校验 `user_id`，伪造 ID 应 403 |
| 日志 | 密码/私钥/口令不得出现在日志与异常 message |
| 静态存储 | 按 D37 明文列存储；**信任模型 = 服务端不可攻破**，文档内不再展开 |
| 客户端 | 凭据只进内存，不写临时文件；桌面端渲染层不接触凭据原文（Python 侧直接用） |
| 主机指纹 | 首次确认，之后不匹配必须拒绝并提示 |

## 6. 关键决策与最终裁决

| 决策点 | 最终结论 | 原因 | 影响 |
|---|---|---|---|
| Web 端 | 不做 | 浏览器无法直连 TCP，中继会与「不经过服务端」冲突 | `jflove-web` 零改动 |
| 静态加密 | 不做，明文存 DB | 用户信任模型明确 | 不设 KEK、不设主口令 |
| 客户端缓存 | 不做 | 用户要求「每次连接从服务端拉取」 | 离线不可用（本机终端除外） |
| 多窗口 | 多标签 | 用户明确「不要弹框」 | 桌面端单窗口 |
| 本机终端 | 内嵌 | 用户明确选 A | Windows 需 ConPTY 依赖 |
| 跳板 | 复用已保存连接 | 用户表述「一个配置当另一个的跳板」 | 需要循环检测 |
| 版本 | 两端同批 v1.10.0 | 用户要求一起上 | 后端接口一次到位 |

**被废弃的方案（禁止下游实现）**：

| 废弃方案 | 废弃原因 | 现行结论 |
|---|---|---|
| Web 端做 SSH（含 WS 中继） | 用户 2026-11-13 明确排除 | 不做 |
| 服务端做 TCP 转发/中继 | 与「网络不经过服务端」冲突 | 不做 |
| 客户端主口令零知识加密 | 用户明确「不要想太多」 | 明文列 |
| 唤起外部系统终端 | 用户要内嵌 | 内嵌 PTY |

## 7. 与上一版本差异

- 新增完整功能域「远程连接」，桌面端侧栏新增入口，App 底部导航调整。

## 8. 验收标准

| AC | 判据（可观测） |
|---|---|
| AC-1 | 桌面端新建一条连接，App 同账号下拉可见，字段一致 |
| AC-2 | 新建分组并把连接拖入，重启两端后分组与归属保持 |
| AC-3 | 删除分组后连接出现在「未分组」，连接本身未被删 |
| AC-4 | B 的跳板设为 A，双击 B 能登录目标主机（终端可执行 `whoami`） |
| AC-5 | 三级跳板（C→A→B）可连通；链路任一跳失败时提示指出具体跳 |
| AC-6 | 构造循环引用（A 指 B、B 指 A）保存被拒绝并提示 |
| AC-7 | 终端显示 256 色；改变窗口大小后远端 `vim` 不错位 |
| AC-8 | 同一连接开 3 个标签，命令互不干扰；关闭标签后连接释放 |
| AC-9 | SFTP 上传 100MB 文件显示进度，可取消；下载可双击打开 |
| AC-10 | 同一会话终端与 SFTP 切换不重新认证 |
| AC-11 | Windows 本机终端默认 PowerShell，Linux 默认登录 shell；可执行命令 |
| AC-12 | 本机终端分组与条目重启桌面端后仍在；服务端数据库无对应记录 |
| AC-13 | 服务端停机时远程列表报错可重试，本机终端仍可打开 |
| AC-14 | 首次连接弹主机指纹确认；指纹变化后连接被拒绝 |
| AC-15 | 伪造他人连接 ID 调详情/更新/删除，返回 403 |
| AC-16 | 提交密码/私钥后检索服务端日志与错误响应，无明文泄露 |
| AC-17 | App 底部导航入口数量 ≤ 6 且「远程」可进入列表 |
| AC-18 | Web 端不存在任何「远程连接」入口与代码路径 |
| AC-19 | 远程连接配置 `cd /opt/app && pwd`，登录后终端回显该命令并输出 `/opt/app`，随后可继续输入 |
| AC-20 | 本机终端配置启动命令，打开后同样回显并执行，结束时仍停在 shell |
| AC-21 | 启动命令含换行时保存被拒绝并提示原因 |
| AC-22 | App「传输」页内可完成离线下载的全部既有操作（新建、勾选、下载、取消、删除），无能力缺失 |
| AC-23 | 跳板连接时界面逐跳展示链路与每跳状态；任一跳失败能指出具体跳 |

## 9. 已确认项（本轮对话）

| 项 | 结论 |
|---|---|
| App 底部导航 | 接受「离线下载并入传输任务」，保持 6 项；能力不得丢失（AC-22） |
| 桌面侧栏位置 | 无所谓，按原型放在「离线下载」下方 |
