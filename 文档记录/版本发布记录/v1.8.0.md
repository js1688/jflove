## 七、部署步骤

```bash
# 1) 服务端（8989）；/data 持久化数据库，/storage 映射大容量磁盘
docker pull ghcr.io/js1688/jflove-server:1.8.0
docker run -d --name jflove-server -p 8989:8989 --restart=always \
  -v /opt/jflove/data:/data \
  -v /mnt/big-disk:/storage \
  ghcr.io/js1688/jflove-server:1.8.0
curl -s http://127.0.0.1:8989/health          # 期望 200，版本 1.8.0

# 2) Web 端（8080）
docker pull ghcr.io/js1688/jflove-web:1.8.0
docker run -d --name jflove-web -p 8080:80 --restart=always \
  ghcr.io/js1688/jflove-web:1.8.0

# 3) 从 v1.7.x 升级：先跑升级 DDL（幂等）
sqlite3 /opt/jflove/data/jflove-prod.db < jflove-db/migrate-v1.8.0.sql
python scripts/check_db_schema.py            # 期望 exit 0
```

桌面端：Windows 装 `*-setup.exe`、Fedora `sudo dnf install ./jflove-desktop-1.8.0-1.fc*.x86_64.rpm`；
Android 装 `app-release.apk`。首次启动填同一服务端地址。

**冒烟判据**：服务端 `/health` 200 → Web 登录页渲染 + `key-exchange 200` → 桌面端登录后进入「离线下载」页
→ 移动端「离线下载中心」只读页可见 → 管理员「系统设置 → 离线下载」开关可保存并即时生效。

## 八、已知限制（如实登记）

1. **Windows 媒体渲染 / 拖拽**：wine 下视频区抓屏为黑（GPU/媒体不在 wine 覆盖内，L52），测试报告 §10.2 记为**未覆盖**；需真机复核。
2. **AC-200 入口置灰**：总开关关闭时「离线下载」入口仍常显，仅页面内禁用并给中文说明（审查 M-3，登记台账）。
3. **`max_items` 口径**：只约束非图片项，图片另受 `max_images` 约束（H-11，待设计确认）。
4. **图片分页游标未持久化**：`next_page()` 从第 1 页逐页推进，最多 20 次请求（H-10）。
5. **L3 媒体嗅探**未在公网站点抽查（仅本地注入样本）。
6. **站点前端 AES 加密图片**不可保存，服务端明确报「图片内容无法识别（可能经过站点加密）」。
7. **CI 只构建 release APK**：debug APK 不在 CI 产物内（设备冒烟用的 debug 包需本地 `flutter build apk --debug`）。
8. 审查遗留 M-1（`select_items` 副作用）、M-2（DASH 分片数估算）不阻断，已登记下个版本台账。
