# v1.3.1 版本发布记录：服务端 + Web 端 + 移动端版本号升级

## 八、部署步骤

```bash
# 服务端（挂载持久化 + 物理盘；Fedora/SELinux 需加 :Z）
docker run -d --name jflove-server -p 8989:8989 \
  -v /your/data:/data:Z -v /mnt/your-big-disk:/storage:Z \
  --restart=always jflove-server:1.3.1

# Web 端
docker run -d --name jflove-web -p 8080:80 --restart=always jflove-web:1.3.1
# 镜像推送到仓库由人工执行：docker push <registry>/jflove-server:1.3.1 / <registry>/jflove-web:1.3.1
```
