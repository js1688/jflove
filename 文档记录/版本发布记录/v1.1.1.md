# v1.1.1 版本发布记录

## 一、发布概述

本版本是 v1.1.0 之后的桌面端补丁版本，专门修复用户反馈的"会话频繁过期"体验问题，并提供"登录有效期"UI 配置项。**仅桌面端二进制升级**，服务端镜像保持 v1.1.0，无须重打。

### 核心改动

- **桌面端 ECDH 加密会话失效自动续约**：服务端重启等场景不再弹"会话已过期"，HTTP 客户端在后台静默重做密钥交换并重发原请求；
- **登录界面新增"登录有效期"下拉**（30分/1小时/2小时/4小时/8小时，默认 1 小时，记忆上次选择）；
- **JWT 真到期严格踢出，且仅产生一次提示与一个登录窗**（`_logout_in_flight` 互斥 + main.py 单实例切换）；
- 顺手修复 v1.1.0 测试报告 BUG-1 与代码审查 L-2 / L-3 / L-4。

## 八、加密协议版本

| 项 | v1.1.0 | v1.1.1 |
|---|---|---|
| 加密信封（普通 JSON 接口）| ChaCha20-Poly1305 + base64 nonce/ciphertext | 一致 |

| ECDH 续约触发方式 | 仅设置页"刷新会话密钥"按钮手动触发 | **新增**：客户端在 ECDH 类 401 时自动调用 `/api/v1/auth/key-exchange`（明文白名单内），服务端无须改动 |

向后兼容性：**完全兼容 v1.1.0 服务端**。v1.1.1 桌面端连接 v1.1.0 服务端，所有功能正常工作；ECDH 静默续约的 `key-exchange` 调用是 v1.0 起就存在的接口。

## 九、部署步骤

### 9.1 桌面端用户

1. 关闭运行中的 v1.1.0 客户端；
2. 用 `JFLove.exe` 替换原有可执行文件（同目录覆盖即可，无须卸载）；

4. 第一次启动会自动完成密钥交换 + 免登录恢复（如有保存的会话）；
5. 在登录页可看到新的"登录有效期"下拉项，默认值 1 小时。
