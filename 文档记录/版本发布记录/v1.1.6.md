## 三、生产库表结构变更

### 升级 DDL

```sql
-- v1.1.6：移除 sync_configs 表（同步配置改为客户端本地存储）
DROP TABLE IF EXISTS sync_configs;
DROP INDEX IF EXISTS sync_configs_user_id_idx;
```

### 回滚 DDL

```sql
-- 回滚 v1.1.6：重建 sync_configs 表（v1.1.5 结构）
CREATE TABLE IF NOT EXISTS sync_configs (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id         INTEGER NOT NULL,
    name            TEXT    NOT NULL,
    local_path      TEXT    NOT NULL,
    disk_id         INTEGER NOT NULL,
    remote_path     TEXT    NOT NULL DEFAULT '',
    auto_sync       INTEGER NOT NULL DEFAULT 0,
    sync_interval   INTEGER NOT NULL DEFAULT 300,
    last_synced_at  TEXT,
    enabled         INTEGER NOT NULL DEFAULT 1,
    created_at      TEXT    NOT NULL,
    updated_at      TEXT    NOT NULL,
    deleted_at      TEXT
);
CREATE INDEX IF NOT EXISTS sync_configs_user_id_idx ON sync_configs(user_id);
```

## 十、后续 BUG 修复（2026-07-21）

### ② 同步配置按账号隔离

**问题**：所有登录用户共用 `sync_configs.json` 文件，A 账号退出登录后 B 账号登录会看到 A 的同步配置。

**修复文件**：
- `src/services/sync_service.py` — 配置文件名改为 `sync_configs_{username}.json`

**验证**：`flake8 src/ tests/` ✅ 0 警告 | `pytest tests/` ✅ 98 passed

### ③ 笔记本目录配置 UI 优化

**问题**：设置页中的笔记目录浏览器内联在页面中，占用 220px+ 空间，布局拥挤。

**修复**：内联目录浏览器改为弹出式 `_NotesDirBrowserDialog` 对话框，通过按钮触发。

**修复文件**：
- `src/ui/pages/settings_page.py` — 新增 `_NotesDirBrowserDialog` 类，替换内联目录浏览器

**验证**：`flake8 src/ tests/` ✅ 0 警告 | `pytest tests/` ✅ 98 passed
