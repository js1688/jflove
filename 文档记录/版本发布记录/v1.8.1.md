## 七、部署步骤

### 7.1 服务端（GHCR）

```bash
docker pull ghcr.io/js1688/jflove-server:1.8.1
docker run -d --name jflove-server -p 8989:8989 \
  -v /path/to/jflove-db:/app/jflove-db \
  ghcr.io/js1688/jflove-server:1.8.1
```

- 生产库**只同步表结构**（本版无变更），不要用开发库覆盖；
- 首次启动后确认 `/health` 200，再验证一次「密钥交换 → 登录」。

### 7.2 Web（GHCR）

```bash
docker pull ghcr.io/js1688/jflove-web:1.8.1
docker run -d --name jflove-web -p 8080:80 ghcr.io/js1688/jflove-web:1.8.1
```

### 7.3 桌面端

- Windows：`JFLove-1.8.1-win64-setup.exe`（安装包），便携版 `JFLove-1.8.1-win64-portable.zip`；
- Linux：`jflove-desktop-1.8.1-1.fc<N>.x86_64.rpm`。

### 7.4 Android

- Release APK 从 CI artifact 下载安装；iOS / 鸿蒙仍为预留方向。
