## 六、部署与升级说明

1. **服务端**：Docker 镜像在有 Docker 的机器执行 `cd jflove-server && python build.py`（自动校验 3 处版本号一致性）；升级后首次启动自动建表 + 把未终态修复任务标记失败并清理半成品。
2. **桌面端**：分发 `JFLove.exe`（PyInstaller 单文件）。
3. **移动端**：安装 `app-debug.apk`（正式发布可 `flutter build apk` 出 release 包）。
4. **Web 端**：`dist/` 部署到 Nginx（SPA fallback 配置见 `nginx.conf`）；或 Docker 构建 `jflove-web:1.4.2`。
5. **生产库**：已同步表结构；回退时执行 `jflove-db/rollback-v1.4.2.sql`。

## 七、已知限制（与测试报告一致）

1. Web 前向 seek 为字节估算（误差 < 1 分片），失败回退全流重建不劣化。
2. 修复队列并发数修改需重启生效（启动时定 worker 数）。
3. verifying 阶段取消无检查点（验证极快，可接受）。
