## 1. 范围

修复 v1.10.0/v1.10.1 Windows 实机反馈的 12 条问题，并重构「新建连接」流程：

1. 应用内 Modal 替换 `window.prompt`（分组 / 新建目录 / 重命名 / 路径跳转）
2. 新建统一入口：远程 SSH / 仅 SFTP / 本机终端
3. 纯 SFTP 连接（`mode=sftp`，不建立 shell）
4. 本机终端去掉文件页签；修 Windows 空串读循环导致的闪屏
5. 终端通道显式绑定 `127.0.0.1` + 连接/断开/异常日志
6. SFTP 传输中文状态、字节/速率/百分比、下载按钮、多选批量下载

## 6. 已知问题

- Windows 崩溃若仍存在，需要用户提供 `%APPDATA%\JFLove\logs` 日志再定位。
- 本机终端仍依赖 `pywinpty 3.1.2`；缺失时入口报错，不影响远程连接。
- 多选下载为逐个文件串行，未做队列并发。
