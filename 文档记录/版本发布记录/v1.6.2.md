## 八、版本变化 / 功能特性（供根 `README.md` 引用）

### 8.1 工具箱真的能用了（本版核心修复）

- **根因**：「选完即关」挂在弹框容器的 `pointerup` **捕获**阶段 ⇒ 被点的按钮在 `click` 派发**之前**被卸载 ⇒ Chromium **不再派发**该 `click`
  ⇒ 受害面 = 白名单（`sql` / `font`）之外的 **10 项、约 29 个按钮**，表现为「点了完全没反应、正文一个字符都没变」。
- **修法**：关框搬到容器的 `onClick`（冒泡）—— 被点按钮的 `onClick` 先执行、随后关框；**关框语义（选完即关 / `sql`·`font` 保持打开 / `Esc` / 点外部）逐条不变**。
- **顺带治「作用不明显」**：改正文的动作执行后，**变化处滚进视口**并给出**中文结果提示**（含处理规模，如「已排序（12 行）」）；只读 / 未挂载 / 能力不适用都给中文原因。
- **真机证据**：`r21`（机制）+ `r22.M2`（真 OS 鼠标点「排序」⇒ 正文 `b\na` → `a\nb`）+ 注入式变异（搬回 `pointerup` ⇒ 新增用例 **11 failed**，而 v1.6.1 的旧用例**照样全绿** ⇒ 假通过的现场证据）。

### 8.2 两段文本对比：能打开，而且铺满面板

- **两层原因叠加**：①「打开对比」按钮本身在上述受害面内（**从未成功打开过**）；② 即使打开，覆盖层的定位祖先被**工具栏自己的 `relative`** 抢走 ⇒ 只有工具栏一行高。
- **修法**：定位祖先归还**编辑面板根元素**；工具箱弹框的定位祖先另行安排在"内容层"。
- **判据**：真机 `r22.M3` 覆盖层高度 ≥ 面板内容区的 **90%**；把 `relative` 放回根 ⇒ 该判据**必红**（变异轮 `heightRatio=0.045`）。

### 8.3 工具箱 12 项各有快捷键（只在编辑面板聚焦时生效）

- **语义**：每项一条键，**键的作用 = 该项在弹框里排第一的动作**（唯一真相表 `TOOLBOX_PRIMARY_ACTION`，与按钮走**同一个动作函数**，不可能两处漂移）。
- **作用域**：事件目标必须在 `[data-editor-panel]` 内才响应；面板外**不接管、不吞键**（`preventDefault === false`）；未登录 / 窗口失焦同样不响应。
- **默认键**（`AC-88` 表）：`toolbox.search`=`Ctrl+Shift+F`、`toolbox.lines`=**`Ctrl+Shift+P`**、`toolbox.case`=`Ctrl+Shift+U`、`toolbox.escape`=`Ctrl+Shift+E`、
  `toolbox.base64`=`Ctrl+Shift+B`、`toolbox.json`=`Ctrl+Shift+J`、`toolbox.markdown`=`Ctrl+Shift+M`、`toolbox.csv`=`Ctrl+Shift+T`、`toolbox.sql`=`Ctrl+Shift+Q`、
  `toolbox.xml`=`Ctrl+Shift+X`、`toolbox.diff`=**沿用 `Ctrl+Shift+D`**（不重复登记）、`toolbox.font`=`Ctrl+Shift+O`。
- **键位纪律（本版立了机械化判据）**：新增/修改快捷键**必须**跑 `poc/editor-probes/r23-keymap-collision.py`
  —— 我们的接管点在 window **捕获**阶段 `preventDefault`，与编辑器内核已装配 keymap 撞车就会**静默抢掉**编辑器功能。
  本版就因此把 `toolbox.lines` 从 `Ctrl+Shift+L`（撞 `selectSelectionMatches`）改成 `Ctrl+Shift+P`（同一纪律见 v1.6.1 把 `Ctrl+D` 让回内核）。

### 8.4 查找 / 替换可跨已打开的标签页

- **范围可选**：默认「当前标签页」（`Ctrl+F` 行为与上一版**逐字不变**）／「所有已打开的标签页」。
- **结果分组**：按标签页列出**标题 + 行号 + 行文本摘要**，并显示总命中数与涉及标签页数；点一条 ⇒ **激活该标签页 + 滚到该行 + 选中命中文本**。
- **未挂载明示**：懒挂载未命中的标签页**明示数量**且不参与搜索（不静默）。
- **全部替换**：执行前中文确认（将替换 N 处、涉及 M 个标签页）⇒ 恰好替换范围内全部命中 ⇒ 提示「已替换 N 处」；被改动的标签页变**脏**（保存后才落盘）。
- **零新增能力面**：只读**内存里已有的正文**（不新增桥方法、不读磁盘、不新增网络出口）；用例用"桥替身一调即抛"证明 **0 桥调用**。

### 8.5 编辑器区右击菜单中文化，其它区域不再弹

- **只在可编辑区**（`isContentEditable()` 为真）弹**中文**标准编辑菜单：撤销 / 重做 / 剪切 / 复制 / 粘贴 / 全选（可用性跟随上下文）；
  **0 英文项**、**0 浏览器导航项**（`Back` / `Reload` / `Save page` / `Inspect` 等一概没有）。
- **其它区域不弹**：页面背景 / 工具栏 / 标签条右击 **无菜单**。唯一例外是应用内**文本输入框**（登录框、重命名框）—— 否则会连右键粘贴都消失（设计 D35②，用户一句话可推翻）。
- **能力面不扩大**：走 Qt 既有 `WebAction` 转发，**不**开渲染层剪贴板权限、**不**新增"外壳→渲染层执行 JS"通道（`§9.6`）。
  ⚠ 已知缺口：**右键菜单的"粘贴"不经过 v1.6.1 的剪贴板归一化**（它走 `WebAction` 而非按键）⇒ 登记在台账 **BL-56**。

### 8.6 快捷键配置分成两组

- **应用级（任意页面生效）** 与 **文本编辑器级（仅编辑面板聚焦时生效）** 两个分组，**每行标注作用域**。
- **冲突口径**：**组内同键 ⇒ 拒绝保存**并指出冲突项；**跨组同键 ⇒ 允许保存**并提示"该键已被 X 使用；两者作用域不同，不会同时触发"（运行时行为确定：面板聚焦时面板作用域优先）。
- **旧配置零迁移**：缺新条目取默认值，`SHORTCUTS_VERSION` 仍为 `1`。

## 十三、同版本重发（v1.6.2，2026-10-17 晚）

### 13.1 为什么重发

用户 Fedora 装 RPM 后启动即 `SIGSEGV`（coredump：PID 8560、`Signal: 11`；
栈顶 `PySide::getWrapperForQObject` ← `sendThroughApplicationEventFilters` ← 窗口激活 focus 事件）。

- **根因**：v1.6.1 为 F6（「IDEA 复制代码贴不进来」）引入的**应用级 Python 事件过滤器**
  （`_app.installEventFilter(self.paste_normalizer)`）。应用级过滤器让 PySide6 为 QtWebEngine 内部每个
  事件接收者生成 Python 包装，Linux/X11 窗口激活时在 `getWrapperForQObject` 段错误。
- **修法**：过滤器只挂渲染 widget（`QWebEngineView.focusProxy()`，`QWidget`）+ 非 Win32 不安装；
  详见 `文档记录/桌面端开发记录/v1.6.2.md` §8。
