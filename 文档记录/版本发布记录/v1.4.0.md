### 部署步骤（后端 + Web 端，2026-08-16）

```bash
# 服务端（挂载数据目录 /data 持久化，内置空表结构 DB 兜底）
docker run -d -p 8989:8989 -v /your/data:/data --restart=always jflove-server:1.4.0

# Web 端
docker run -d -p 8080:80 --restart=always jflove-web:1.4.0
```

> 镜像为本地构建产物，需人工推送镜像仓库（`docker tag` + `docker push`）后在生产拉取部署。

## 五、加密协议与安全

- 加密协议版本：`X-Encrypted-Stream: v2`（流式帧：`[4B 长度][12B nonce][密文+16B tag]`）
- 请求/响应全程 ChaCha20-Poly1305；URL 无业务明文（桌面端 GET 走加密 body，Web/移动 URL 仅 nonce/ciphertext 密文）
- 明文白名单 `_PLAIN_PATHS` 未扩大（仍为 health / key-exchange / admin-exists）
- 安全核查报告：视频流、文件名、路径、token 链路全程密文（见测试报告 §五）
