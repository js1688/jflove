## 八、回滚预案

若 v1.1.4 部署后出现严重问题，回滚操作如下：

### 服务端回滚

```bash
# 方法一：使用上一版本的 Docker 镜像启动
docker run -d -p 8989:8989 \
  -v /opt/jflove/data:/data \
  --restart=always \
  jflove-server:1.1.3

# 方法二：如果已构建 v1.1.3 的 tar 文件
docker load -i jflove-server-1.1.3.tar
docker run -d -p 8989:8989 -v /opt/jflove/data:/data --restart=always jflove-server:1.1.3
```

### 桌面端回滚

使用上一版本的构建产物重新安装。数据库无需回滚（本版本无 schema 变更）。

### 注意事项

- v1.1.4 签发的 JWT 最长为 30 天，回滚到 v1.1.3 后这些 token 会被 clamp 到 8 小时，客户端会在 8 小时内过期后重新登录，不影响使用。
- 地址历史文件（`storage/server_history.json`）向下兼容，v1.1.3 客户端可以正常读取。

## 九、部署步骤

### 服务端

```bash
# 1. 确保 docker 已安装
docker --version

# 2. 加载或构建镜像
# 从构建产物加载：
# docker load -i jflove-server-1.1.4.tar
# 或直接 run 自动 pull（上传到仓库后）：
# docker run -d ...

# 3. 创建数据目录
mkdir -p /opt/jflove/data
mkdir -p /mnt/big-disk

# 4. 启动容器（自动重启策略）
docker run -d \
  --name jflove-server \
  -p 8989:8989 \
  -v /opt/jflove/data:/data \
  -v /mnt/big-disk:/storage \
  --restart=always \
  jflove-server:1.1.4

# 5. 验证启动
sleep 5 && curl -s http://127.0.0.1:8989/health
# 期望输出: {"status":"ok"}

# 6. 查看日志
docker logs -f jflove-server
```

### 桌面端

直接运行构建产物 `build/dist/JFLove`（Linux）或 `build/dist/JFLove.exe`（Windows）。
