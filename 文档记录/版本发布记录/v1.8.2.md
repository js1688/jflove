## 八、部署步骤

### 8.1 服务端（GHCR）

```bash
docker pull ghcr.io/js1688/jflove-server:1.8.2
docker run -d --name jflove-server -p 8989:8989 \
  -v /path/to/jflove-db:/app/jflove-db \
  ghcr.io/js1688/jflove-server:1.8.2
```

- 生产库**只同步表结构**（本版无变更），不要用开发库覆盖；
- 首次启动后确认 `/health` 200，再验证一次「密钥交换 → 登录」。

### 8.2 Web（GHCR）

```bash
docker pull ghcr.io/js1688/jflove-web:1.8.2
docker run -d --name jflove-web -p 8080:80 ghcr.io/js1688/jflove-web:1.8.2
```

### 8.3 桌面 / 移动

- Windows：`JFLove-1.8.2-win64-setup.exe`（或便携 zip）；
- Linux：`jflove-desktop-1.8.2-1.fc*.x86_64.rpm`；
- Android：`app-release.apk`（versionName 1.8.2 / versionCode 1008002）。
