## 五、安装与部署

### 桌面端

- **Windows 安装版**：`JFLove-1.5.0-win64-setup.exe` —— 双击安装（开始菜单 + 可选桌面快捷方式 + 卸载器；卸载时询问是否删除用户数据，默认保留）
- **Windows 免安装版**：`JFLove-1.5.0-win64-portable.zip` —— 解压即用，不写注册表
- **Fedora / RHEL**：`jflove-desktop-1.5.0-*.x86_64.rpm`（Linux 侧由用户环境构建/验证）

### 移动端

```bash
adb install -r app-release.apk
```

### 服务端 / Web 端（需 Docker）

```bash
docker pull ghcr.io/<owner>/jflove-server:1.5.0
docker run -d --name jflove-server -p 8989:8989 \
  -v /opt/jflove/data:/data -v /mnt/disk-a:/storage/disk-a --restart=always \
  ghcr.io/<owner>/jflove-server:1.5.0

docker pull ghcr.io/<owner>/jflove-web:1.5.0
docker run -d --name jflove-web -p 18080:80 --restart=always \
  ghcr.io/<owner>/jflove-web:1.5.0
```
