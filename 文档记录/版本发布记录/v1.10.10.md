> 版本：1.10.10｜发布日期：2026-11-16｜角色：devops

## 1. 发布范围

本版只改 `jflove-desktop/ui/`：

1. 远程/本机配置表单移除「分组」字段（旧数据保留）；
2. 会话结束（`exit` / 链路断开 / 本机进程退出）自动关闭标签；连接失败标签保留；
3. 左侧树新增置顶「会话」节点（计数 / 状态点 / 点击进入 / 悬停关闭）。

服务端、数据库、Web、App **无功能改动**，仅版本号同步。

## 7. 部署步骤

```bash
# 服务端
docker pull ghcr.io/js1688/jflove-server:1.10.10
docker run -d --name jflove-server -p 8989:8989 \
  -v /path/to/data:/app/jflove-db ghcr.io/js1688/jflove-server:1.10.10

# Web
docker pull ghcr.io/js1688/jflove-web:1.10.10
docker run -d --name jflove-web -p 8080:80 ghcr.io/js1688/jflove-web:1.10.10
```

桌面端：下载 `JFLove-1.10.10-win64-setup.exe` 安装，或 Fedora 安装 rpm；
Android：安装 `app-release.apk`（versionCode 1010010）。

## 8. 回滚预案

- 服务端/Web：切回 `ghcr.io/js1688/jflove-server:1.10.9` / `web:1.10.9` 镜像即可；
- 桌面端：重新安装 v1.10.9 安装包（覆盖安装）；
- 数据库：本版无 DDL，**无需回滚数据库**；
- 客户端配置：本版只移除分组 UI，旧数据未删除，回滚 v1.10.9 后分组数据仍可用。

## 9. 已知边界

- 仅 SFTP 标签在 SSH 传输层静默掉线时没有 `closed` 事件，仍需手动关闭（设计 §8）。
- 连接失败标签保留是产品裁决（D2），不是缺陷。
- 主机指纹/OTP 弹层仍是会话页局部（审查 M1，属 v1.10.7 遗留），本版未改。
