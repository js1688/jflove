## 6. 发布操作

```bash
git tag v1.8.3
git push origin v1.8.3
```

- tag 指向 `main` 最新发布提交；
- 触发 `build-server.yml` / `build-web.yml` / `build-desktop.yml` / `build-app.yml` / `ci-guards.yml` / `release.yml`；
- CI 完成后回填 run 链接与产物哈希。

## 7. 回滚预案

- 应用：回退到 `v1.8.2` tag 的 APK；
- 服务端/Web：继续使用 v1.8.2 镜像（本版无业务变更）；
- 数据库：本版无 DDL，无需回滚；
- 索引：移动端本地 `album_backup.db` v4 只新增表，降级回 v1.8.2 不影响原有表。

## 8. 安全

- `_PLAIN_PATHS` 未扩大；JWT 仍只走加密 body；
- 移动端日志不含 token/session_key/完整路径/文件名；
- 无新增加密原语。
