# v1.1.0 版本发布记录

## 一、发布概述

本版本核心新增「流式预览」功能：桌面端视频/音频/文本文件支持不下载直接在线预览，通过服务端帧加密流 + 本地 StreamProxy（代理） + StreamTextLoader（文本加载器）实现端到端加密预览。

## 七、加密协议版本

| 接口 | 响应头 | 说明 |
|---|---|---|
| 下载/预览 v1（`/api/v1/files/download`、`/api/v1/files/preview`） | `X-Encrypted-Stream: v1` | 沿用 v1.0 帧格式 |
| 流式预览 v2（`GET /api/v1/files/stream`） | `X-Encrypted-Stream: v2` | 新增，同样为 `[4B len][12B nonce][ChaCha20-Poly1305 密文+16B tag]` 帧格式 |

v1 与 v2 帧格式完全相同，区别仅在于 v2 额外包含元数据帧（帧 0）。向后兼容，不影响 v1.0 客户端。

## 九、部署步骤

### 9.1 服务端部署（Docker）

**方式 A：挂载外部数据库（推荐生产环境）**

```bash
# 首次部署（/opt/jflove/data 为宿主机数据目录，首次启动会自动初始化空 DB）
docker run -d \
  --name jflove-server \
  --restart=always \
  -p 8989:8989 \
  -v /opt/jflove/data:/data \
  -v /mnt/your-storage:/storage \
  jflove-server:1.1.0
```

**方式 B：使用镜像内置空表结构 DB（演示/测试）**

```bash
# 容器销毁后数据丢失，仅演示用
docker run -d \
  --name jflove-server \
  --restart=always \
  -p 8989:8989 \
  jflove-server:1.1.0
```

**从 v1.0 升级**

若已有挂载 `/data` 的 v1.0 容器，升级步骤：

```bash
# 1. 停止旧容器
docker stop jflove-server && docker rm jflove-server

# 2. 启动新版（/data 下的数据库会被自动使用，表结构由 init_db 自动对齐）
docker run -d \
  --name jflove-server \
  --restart=always \
  -p 8989:8989 \
  -v /opt/jflove/data:/data \
  -v /mnt/your-storage:/storage \
  jflove-server:1.1.0

# 3. 确认健康检查
docker inspect --format='{{.State.Health.Status}}' jflove-server
```

### 9.2 桌面端部署

将 `jflove-desktop/build/dist/JFLove`（Linux）发送给用户，直接运行即可。首次启动需配置服务端地址。

## 十一、回滚预案

### 11.1 服务端回滚

```bash
# 停止新版，启动旧版镜像
docker stop jflove-server && docker rm jflove-server
docker run -d \
  --name jflove-server \
  --restart=always \
  -p 8989:8989 \
  -v /opt/jflove/data:/data \
  jflove-server:1.0.0
```

若需回滚数据库（删除 notes_permissions 表）：

```sql
DROP INDEX IF EXISTS notes_permissions_user_id_idx;
DROP TABLE IF EXISTS notes_permissions;
```

> **注意**：notes_permissions 在 v1.0 服务端代码中不存在，表中不会有业务数据，回滚删表无数据损失风险。

### 11.2 桌面端回滚

替换客户端安装包为 v1.0 对应产物即可。桌面端不保存加密 session_key，无状态迁移问题。
