# JFLove v1.10.0 版本发布记录

> 角色：devops｜阶段：Phase 8｜日期：2026-11-13
> 发布方式：**真实发布**（用户明确授权 commit / push / tag，由 GitHub Actions 构建并创建 Release）
> 发布前状态：Phase 1~7 完成；UAT 由用户在 CI 构建物上进行，问题进 GitHub issue。

## 1. 版本范围

- **新增**：远程 SSH/SFTP 客户端（桌面端 + App）、本机终端（桌面端）、跳板机、分组、连接后执行命令。
- **调整**：App 底部导航 6 项（离线下载并入传输页三页签）；桌面侧栏新增「远程连接」。
- **Web 端**：不参与本版本功能（仅版本号同步）。

## 2. 加密协议

- 应用层：X25519 ECDH + ChaCha20-Poly1305 信封（沿用，未变更）。
- 文件流：`X-Encrypted-Stream: v1`（本版本无新增文件流接口）。
- 终端通道：本机 `127.0.0.1` WebSocket（不经过服务端，不参与信封）。
