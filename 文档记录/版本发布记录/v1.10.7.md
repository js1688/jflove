# JFLove v1.10.7 版本发布记录

> 角色：devops｜日期：2026-11-15｜tag：`v1.10.7`（commit `5567e4d`）
> 类型：**代码 BUG 快速修复**（`AGENTS.md §7.5.3`，版本号递增以承载"必须重新出包"的修复）

## 1. 修了什么

Windows 安装包打开「本机终端」全黑（v1.10.6 遗留，根因见
`文档记录/测试报告/v1.10.6.md` §12）：PyInstaller 只收了 pywinpty 的 dll/`.pyd`，
**漏了 `OpenConsole.exe` 与 `winpty-agent.exe`** → ConPTY 起不来 →
`PTY.spawn()` 返回 `False`（不抛异常）→ 旧实现忽略返回值并打印"已启动" → 前端绿点 + 黑屏。

修复（`文档记录/桌面端开发记录/v1.10.7.md`）：

- 打包：`build.py` 在 Windows 分支 `--add-data` 收两个助手 exe，**打包后复查产物**，缺文件直接失败；
- 调用：`_open_windows()` 按 pywinpty 契约 `spawn(appname, cmdline, cwd, env)` 并**检查返回值**，失败抛错；
- 可见性：失败留痕 + 新桥方法 `local_term.session_status`，渲染层建标签页后补查（失败不再被丢弃）；
- 回归：新增 13 条用例（含打包门禁的反向用例）。
