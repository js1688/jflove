## 1. 发布范围

1. **复杂认证「已连接」但 SFTP 不出目录**：按 paramiko 真实语义处理「部分认证返回剩余方式列表」，
   支持密钥→密码 / 密钥→keyboard-interactive / 密码→密钥；认证结束硬校验 `is_authenticated()`，
   未完成绝不显示「已连接」。
2. **SFTP 一直加载中**：打开子系统 15s、单次操作 45s 有界超时（可用环境变量调整）；
   元数据操作按会话串行；传输使用独立 subsystem 通道；UI 显示已用秒数并支持取消/重试。
3. **凭据无法清空**：密码 / 私钥 / 私钥口令提供「清空」，保存时发送 `clear_password` /
   `clear_private_key` / `clear_passphrase`，服务端把列真正写为空串；新增口令单独更新。
4. **跳板下拉越开越大**：移除原生 `<select>`（Windows 多显示器混合 DPI 下系统弹层持续变大），
   改为页内列表（按 id 去重、排除成环下游连接、限高滚动、外部点击/Esc 关闭）。
5. **文档口径**：根 README 与 App README 修正「移动端提供远程连接」的过时表述；
   App 远程页面代码标注为未接入预留代码（删除列入下个版本候选）。

数据库 **无 DDL**（`check_db_schema.py` 退出码 0，dev=代码、dev/prod 一致）；Web / App 仅版本号同步；
服务端仅补 `clear_passphrase` 语义，无新路由。

## 7. 已知边界

- Windows 多显示器混合 DPI 无法在 KVM 单屏复现；已结构性去掉原生 `<select>`，需用户真机复验。
- SFTP 默认 45s 操作超时；超大目录在极高延迟链路可调 `JFLOVE_SFTP_OP_TIMEOUT`。
- 移动端远程连接仍为未接入代码（本版仅改文档），删除列入下个版本候选。
- 发布前本机 sshd 冒烟因测试密钥未授权未跑通；真实 SSH/SFTP 链路由 paramiko 测试服务与桌面实机验证覆盖。
