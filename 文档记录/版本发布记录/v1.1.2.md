# v1.1.2 版本发布记录

## 一、发布概述

本版本在 v1.1.1 基础上，让"登录有效期"下拉选项**真正生效**。v1.1.1 已实现 UI 选项记忆，但 4h/8h 等选项仍按默认 1h 签发 JWT；v1.1.2 打通了从桌面端下拉 → HTTP 请求 body → 服务端 JWT 签发 → 响应 `expires_in` 的完整链路。

### 核心改动

- **服务端 JWT 有效期客户端可控**：`POST /api/v1/auth/login` 支持 `requested_ttl_seconds` 字段；`jwt_utils.create_token` 新增 `ttl_seconds` 参数并做 clamp（60s ~ 28800s），返回 `(token, effective_ttl)` 二元组，消除 `expires_in` 与 JWT exp 两边计算偏差；
- **桌面端注入 TTL**：`auth_service.login()` 在 `local_max_seconds is not None` 时注入 `requested_ttl_seconds`，向后兼容老服务端（不带字段时服务端默认 1h）；
- **登录页布局重排**：`QHBoxLayout` 让"有效期标签+下拉"同行、"返回+登录"同行，符合 Material Design 主次清晰原则；
- **向后兼容**：v1.1.1 客户端连 v1.1.2 服务端默认 1h 不受影响；v1.1.2 服务端接受恶意超界值并 clamp 到安全范围；
- **服务端 + 桌面端双模块同步升级**：均打 1.1.2 版本号。

## 八、部署步骤与启动命令

### 8.1 服务端 Docker 部署

#### 方式一：挂载外部数据库（生产推荐）

```bash
docker run -d \
  --name jflove-server \
  -p 8989:8989 \
  -v /opt/jflove/data:/data \
  -v /mnt/big-disk:/storage \
  --restart=always \
  jflove-server:1.1.2
```

说明：
- `/opt/jflove/data` ：SQLite 数据库持久化目录（首次自动从镜像内空表结构初始化）
- `/mnt/big-disk` ：大容量磁盘挂载点（可选，创建虚拟磁盘时使用）
- `--restart=always` ：Docker 启动时自动重启

#### 方式二：使用镜像内置数据库（演示/测试）

```bash
docker run -d \
  --name jflove-server \
  -p 8989:8989 \
  --restart=always \
  jflove-server:1.1.2
```

注意：容器销毁后数据丢失，仅用于临时演示。

#### 从 v1.1.0/v1.1.1 升级

```bash
# 1. 停止旧容器
docker stop jflove-server && docker rm jflove-server

# 2. 加载新镜像（如已 push 到仓库则 docker pull）
# docker pull your-registry/jflove-server:1.1.2

# 3. 用新镜像启动（-v 挂载路径与之前保持一致）
docker run -d \
  --name jflove-server \
  -p 8989:8989 \
  -v /opt/jflove/data:/data \
  -v /mnt/big-disk:/storage \
  --restart=always \
  jflove-server:1.1.2
```

### 8.2 桌面端部署

将 `build/dist/JFLove` 分发到目标 Linux 机器，赋予执行权限直接运行：

```bash
chmod +x JFLove && ./JFLove
```

## 十一、回滚预案

### 服务端回滚到 v1.1.0

```bash
# 停止 1.1.2 容器
docker stop jflove-server && docker rm jflove-server

# 回滚到 v1.1.0 镜像（本地已有 jflove-server:1.1.0）
docker run -d \
  --name jflove-server \
  -p 8989:8989 \
  -v /opt/jflove/data:/data \
  -v /mnt/big-disk:/storage \
  --restart=always \
  jflove-server:1.1.0
```

注：本版本无数据库表结构变更，回滚无需 DDL 回滚脚本，数据库文件可直接复用。

### 桌面端回滚

保留旧版 `JFLove` 二进制，替换新版即可。会话会因服务端重启（如果回滚了服务端）自动重做密钥交换（v1.1.1 已有 ECDH 续约机制）。

### 向后兼容说明

v1.1.1 桌面端客户端连接 v1.1.2 服务端：不传 `requested_ttl_seconds` 字段，服务端默认签发 1h JWT，行为与 v1.1.1 完全一致。如仅回滚服务端，桌面端无需同步回滚。

## 十二、与上一版本（v1.1.1）的主要差异

| 变更点 | v1.1.1 | v1.1.2 |
|---|---|---|
| JWT 有效期 | 固定 1h（忽略桌面端下拉选项） | 客户端可控（clamp 60s ~ 28800s，默认 1h） |
| `create_token` 返回 | `str` | `tuple[str, int]` 二元组（token + effective_ttl） |
| `/login` body | 无 `requested_ttl_seconds` 字段 | 支持 `requested_ttl_seconds`（可选，非法值容错） |
| 桌面端登录页布局 | 标签/下拉独占行，按钮独占行 | 标签+下拉同行，返回+登录同行（Material Design） |
| 测试用例数 | 112 | 120（+8 新增） |
| 服务端镜像 | v1.1.0 沿用 | **v1.1.2 新镜像（须重打）** |
| 桌面端二进制 | v1.1.1 | **v1.1.2 新构建** |
