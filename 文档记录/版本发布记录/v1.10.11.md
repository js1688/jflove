## 1. 发布范围

1. **私钥内容入库**：桌面端「选择文件…」由 Python 读取内容、预校验后暂存，保存连接时把**内容**
   写入服务端数据库；配置里不再保存本机路径。粘贴文本兼容 BOM / 缩进 / 单行 / 字面量 `\n` / CRLF，
   并支持 PKCS#8；`.ppk` 保存前明确提示改用原始 PEM 或导出 OpenSSH。
2. **「密码 + 密钥」双因素认证**：新增 `auth_type=password_publickey`（服务端白名单 + 客户端
   `publickey→password` / `password→publickey` 两种顺序 + 表单/列表展示）。
3. **窗口边缘缩放**：修正 `Qt.Edge` 位值（Top=1 / Left=2 / Right=4 / Bottom=8），缩放放到捕获阶段
   并优先于标题栏拖拽；拖边缘不再变成拖窗口。

数据库 **无 DDL**（`auth_type` 为 TEXT 无约束）；Web / App 仅版本号同步。

## 6. 部署

```bash
# 服务端
docker pull ghcr.io/js1688/jflove-server:1.10.11
docker run -d --name jflove-server -p 8989:8989 \
  -v /path/to/data:/app/jflove-db ghcr.io/js1688/jflove-server:1.10.11

# Web
docker pull ghcr.io/js1688/jflove-web:1.10.11
docker run -d --name jflove-web -p 8080:80 ghcr.io/js1688/jflove-web:1.10.11
```

桌面端：下载 `JFLove-1.10.11-win64-setup.exe` 安装，或 Fedora 安装 rpm；
Android：安装 `app-release.apk`（versionName 1.10.11 / versionCode 1010011）。

> ⚠ 服务端与桌面端需**一起升级**：旧服务端不认 `password_publickey`，新建「密码 + 密钥」会返回 400。

## 7. 回滚预案

- 服务端/Web：切回 `ghcr.io/js1688/jflove-server:1.10.10` / `web:1.10.10` 镜像；
- 桌面端：重新安装 v1.10.10 安装包（覆盖安装）；
- 数据库：本版无 DDL，**无需回滚数据库**；
- 客户端配置：本版只是把新保存的私钥存成内容；旧版本读取 `private_key` 字段不受影响。

## 8. 已知边界

- PuTTY `.ppk` 不做解析：保存前明确提示改用原始 PEM（`-----BEGIN RSA PRIVATE KEY-----`）
  或 PuTTYgen 导出 OpenSSH；
- 真实 Fiserv 网关的端到端登录仍需用户实测（本机无该网关访问条件）；
- App 端暂不支持 `password_publickey`（模块边界）；
- 已保存连接若历史遗留本机路径，桌面端仍做兼容解析，但新保存的连接只存内容。
