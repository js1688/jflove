> 角色：devops｜阶段：Phase 8｜日期：2026-11-14｜基线：v1.10.2

## 1. 范围

1. **修复 SSH 终端闪屏**：`TerminalView` 的 `onReady` 进 effect 依赖 → 连接成功后 `patchTab`
   触发重渲染 → effect 重跑 → WS 断开重连，无限循环。改为 `useRef`，依赖固定。
2. **本地/远程合并树**：根节点固定「本地 / 远程」；各自可建分组；本地配置存本地库。
3. **本机配置**：名称 / shell / 工作目录 / 默认命令 / 分组；不再点击即开。
4. 新增回归测试 `src/__tests__/terminal-view-v1-10-3.test.ts`。
