> ⚠️ **镜像构建需在具备 Docker 的机器上执行**。本机已准备全部构建前置（`build.py` / `Dockerfile` / `nginx.conf` / `package-lock.json`），用户将在可构建机器上执行发布流程。

### 在目标机器上一键构建命令

```bash
# 构建服务端镜像（含 CORS 变更）
cd jflove-server && python build.py            # → jflove-server:1.3.0

# 构建 Web 端镜像
cd jflove-web && python build.py               # → jflove-web:1.3.0
# 可选离线包
cd jflove-web && python build.py --save        # → build/jflove-web-1.3.0.tar

# 冒烟：启动 Web 端
docker run -p 8080:80 jflove-web:1.3.0
# 访问 http://localhost:8080 验证登录页 + SPA fallback
```

## 七、部署步骤

### jflove-server（含 CORS 变更）

```bash
docker pull jflove-server:1.3.0   # 人工推送后拉取
docker run -d \
  -p 8989:8989 \
  -v /your/data:/data \
  --restart=always \
  jflove-server:1.3.0
```

### jflove-web

```bash
docker pull jflove-web:1.3.0      # 人工推送后拉取
docker run -d \
  -p 8080:80 \
  --restart=always \
  jflove-web:1.3.0
# 浏览器访问 http://<host>:8080
```

> **CORS 说明**：Web 端部署后可直连服务端地址（CORS 已放开），或通过反向代理同域访问。

## 九、回滚预案

| 场景 | 操作 |
|------|------|
| Web 端异常 | 回滚到上一镜像版本（如有）或 `docker stop jflove-web`，服务端不受影响 |
| 服务端 CORS 异常 | 回滚 `jflove-server:1.1.6` 镜像（CORS 变更不影响桌面端/移动端） |
| 数据库 | 无 DDL 变更，无需回滚 |
