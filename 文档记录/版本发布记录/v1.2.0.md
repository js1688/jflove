3. **login_page.dart 手动创建 HttpService** - 重构为使用 Riverpod provider
4. **flutter analyze 17 个警告** - 全部修复为 0 issues

**修复的文件**：

- `pubspec.yaml` - 添加 logging 依赖

- `lib/pages/login/login_page.dart` - 使用 provider 替代手动创建

- `lib/app.dart` - 代码风格优化
- `lib/widgets/transfer_floating_card.dart` - 代码风格优化

## 本次 BUG 修复（v1.2.0-hotfix2 — 2026-07-21）

**问题**：Release APK 闪退/白屏，Debug APK 正常。

**根因**：hotfix1 中 `android/app/build.gradle.kts` 为 release 构建启用了 `isMinifyEnabled = true` + `isShrinkResources = true` + `proguard-android-optimize.txt`。R8 的激进优化破坏了 Flutter 引擎和插件的反射/FFI 调用链。

**修复**：
- `android/app/build.gradle.kts`：关闭 `isMinifyEnabled` / `isShrinkResources`，移除 `proguardFiles` 配置
- `.claude/skills/devops/SKILL.md`：新增 R8 禁令环境检查项（发布阻塞项）、release APK 构建步骤、双 APK 冒烟测试要求

## 本次 BUG 修复（hotfix3 — 2026-07-21）

**问题**：
1. **移动端设置页缺少笔记本目录配置** — 设置页未提供笔记存储磁盘和子目录的配置入口
2. **同步配置未按账号隔离** — 桌面端和移动端共用 `sync_configs.json`，A 账号能看到 B 账号的配置
3. **桌面端笔记本目录配置 UI 过于笨重** — 内联目录浏览器占用 220px+ 空间
4. **移动端权限管理页交互不合理** — 权限配置弹框无法正常更改和点击

**修复方案**：

### 移动端 (jflove-app)

| Bug | 修复文件 | 说明 |
|-----|---------|------|
| ① 设置页添加笔记本目录配置 | `lib/pages/settings/settings_page.dart` | 新增 `_NotesDirConfigCard` 卡片 + `_NotesDirDialog` 对话框式目录选择 |
| ① NoteService 新增方法 | `lib/services/note_service.dart` | 新增 `getNotesDiskConfig()` / `setNotesDiskConfig()` |
| ② 同步配置账号隔离 | `lib/services/sync_service.dart` | 配置文件名改为 `sync_configs_{username}.json` |
| ④ 权限管理页重写 | `lib/pages/admin/admin_permissions_page.dart` | 改为底部弹窗交互，CheckboxListTile 替代 DataTable |
| ④ Widget 测试修复 | `test/widget_test.dart` | 修复因 Autocomplete 改造导致失败的服务端地址测试 |

### 桌面端 (jflove-desktop)

| Bug | 修复文件 | 说明 |
|-----|---------|------|
| ② 同步配置账号隔离 | `src/services/sync_service.py` | 配置文件名改为 `sync_configs_{username}.json` |
| ③ 目录配置 UI 优化 | `src/ui/pages/settings_page.py` | 内联目录浏览器改为弹出 `_NotesDirBrowserDialog` 对话框 |
