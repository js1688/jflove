# 版本发布记录 v1.2.0-hotfix1

## 版本信息
- **版本号**：`1.2.0+1`（移动端）
- **发布日期**：2026-07-20
- **发布类型**：代码 BUG 修复（快速修复通道）
- **涉及模块**：`jflove-app`（移动端 Android）

## 修复内容

### 移动端 (jflove-app)

| # | 问题 | 根因 | 修复方式 |
|---|------|------|---------|
| 1 | **普通用户看不到磁盘列表**、文件操作全部失效 | `disk_service.listDisks()` 调用了 admin-only 端点 `GET /api/v1/virtual-disks` | 新增 `listAccessibleDisks()` 调用 `GET /api/v1/files/disks` |
| 2 | **图片/视频/音频/PDF 预览失败** | `FilePreviewPage` 仅支持图片和纯文本格式 | 增加 `_MediaPreview` 组件，支持 mp4/mov/avi/mkv/webm/3gp/flv 视频 + mp3/wav/ogg/flac/aac/m4a/wma 音频，通过 `video_player` 包播放 |
| 3 | **笔记/文件删除偶发失败** | DELETE 请求路径尾部多了一个 `/` 导致 307 重定向 | `file_service.delete`、`note_service.deleteNote` 路径去除尾部斜杠 |
| 4 | **用户管理页不可用** | `user_service.listUsers` 用了 POST + `/list`，服务端是 GET + `""`；`createUser` 路径多 `/create` | 修正 method 和路径 |
| 5 | **系统配置页不可用** | `config_service.getConfig` 用了 POST + `/get`，服务端是 GET + `""` | 修正 method 和路径 |
| 6 | **权限管理页不可用** | `permission_service` 三个端点路径完全错误 | 全部重写为路径参数格式，字段名对齐 `can_read/can_write/can_delete` |
| 7 | **登录页服务器地址无法修改** | `main.dart` 未在启动时从 `flutter_secure_storage` 加载会话状态，且设置页无修改服务器地址功能 | 修复 `main.dart` 启动初始化 + 设置页新增"修改服务器地址"功能 |
