## 6. 发布操作

1. 提交（`main`）：`fix(v1.8.4): …`（code+docs）、`docs(uat): …`（UAT 记录）、`docs(pmo): …`（PMO + 发布记录）；
2. 打 tag 并推送：

```bash
git tag -a v1.8.4 -m "v1.8.4: 大文件校验进度与两段式传输管线"
git push origin v1.8.4
```

3. tag 触发的 CI：`release.yml`（创建 Draft Release）+ `build-server` / `build-web` / `build-desktop` / `build-app`
   （构建并挂 Assets，桌面/Android）；
4. CI 结果与产物 → 回填 §3 与 §7。

> 与 UAT 构建的区别：UAT 用 `workflow_dispatch`（ref=main，`head_sha=22f0d7d`）；发布用 tag `v1.8.4`
> （tag 指向发布提交）。二者不混用。

## 8. 回滚预案

| 场景 | 处置 |
|---|---|
| 移动端新版本异常 | 用户回退安装 v1.8.3 APK；本地库 v5 向后兼容（旧版忽略新增列） |
| 服务端 / Web 镜像异常 | 无业务变更，回退到 v1.8.3 镜像 tag 即可 |
| 桌面端异常 | 重新下载 v1.8.3 安装包（无业务变更） |
| Release 内容有误 | Draft Release 直接删除并重新打 tag（tag 删除需谨慎，属对外可见操作） |

## 9. 安全

- 加密协议未变（`X-Encrypted-Stream: v1`）；`_PLAIN_PATHS` 白名单未扩大（无接口变更）；
- 本版新增的唯一本地持久化文件是**哈希缓存**（`<应用支持目录>/transfer-hash-cache.json`）：
  键 = 路径 SHA256，值 = size / mtime / 摘要，**不含文件内容、文件名、token 或 session_key**，不上传；
- 新增日志只含阶段/计数/异常类型，不含路径与文件名（`AGENTS.md §9.4`）。
