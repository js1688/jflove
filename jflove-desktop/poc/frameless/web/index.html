P0-1：无边框窗口 + Web 自绘标题栏

上方标题栏（含最小化 / 最大化 / 关闭）完全由 Web 绘制，Qt 原生外框已移除。 左侧 248px 侧栏与 56px 标题栏高度取自 Web 端设计令牌，仅作视觉占位。

请手动验收以下 6 项
  1. 拖动标题栏空白处 → 窗口跟随移动（松手后仍在该位置）
  2. 把鼠标移到窗口 4 条边 / 4 个角 → 光标变为缩放光标，拖动可改变窗口大小
  3. 双击标题栏空白处 → 最大化；再双击 → 还原（右上角图标同步切换）
  4. 点「最大化」按钮 → 最大化；再点 → 还原
  5. 点「最小化」按钮 → 最小化到任务栏
  6. 点「关闭」按钮 → 窗口关闭
